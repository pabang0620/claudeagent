# 에이전트 레지스트리 감사 기록

이 파일은 **점수표가 아니다.** 90점 목표로 반복 재평가하는 점수 루프는 금지되어 있다(메모리 `feedback_no_agent_score_loop`). 여기에는 감사 시점의 실측 사실과 그때 내린 결정만 남긴다.

## 절대 제약 (영구)

- 모든 에이전트 정의파일의 `model:` 은 **`sonnet` 고정**. opus/haiku/fable 금지.
  (막혔을 때 `Agent` 도구의 `model` 파라미터로 그 작업 1건만 승인 후 상향하는 것은 별개로 허용 - `rules/performance.md`)
- 신규 에이전트 생성 시 `rules/agents.md` "에이전트 모델 제약" 체크리스트 필수
- 정의파일은 500줄 이하. 초과 시 코드 예제를 `.claude/agent-refs/` 로 분리하고 정의파일에는 판단 규칙만 남긴다.

## 실사용량 실측 방법

이름 grep은 근거가 되지 않는다. 실제 스폰 증거는 트랜스크립트의 `subagent_type` 필드뿐이다.

```bash
cd ~/.claude/projects/-home-lee-project
grep -oh '"subagent_type":"[^"]*"' *.jsonl | sed 's/.*:"//;s/"//' | sort | uniq -c | sort -rn
```

주의: 트랜스크립트는 PC 이관(2026-07) 이후분만 남아 있다. "0회"는 **로그 보존 구간 내 0회**이지 전체 기간 0회가 아니다.

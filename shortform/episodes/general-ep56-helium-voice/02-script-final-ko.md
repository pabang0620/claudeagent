# 확정 타임코드 (한국어판, 실측 기반)

TTS 실측(`public/audio/ko_words.json`) + 프로필 기본 여백(0.2초, 전 구간 동일)을 반영한 최종
프레임 수치. `assets/timeline.ts`의 `sceneFrames`/`sceneStarts`로 계산했고 손으로 다시 계산하지
않았다. 이 화는 s1~s7 전부 3인칭 설명 내레이션이라(캐릭터가 자기 대사를 말하는 리액션 구간이
없음) 리액션 전용 TTS 오버라이드(rate/pitch)를 쓰지 않았다.

인트로 69프레임(2.30s) + 제목카드 54프레임(1.80s) + 본편 1224프레임(40.80s) + 아웃트로
90프레임(3.00s) = 총 1437프레임(47.90s, ffprobe 실측 47.957333s - 반올림 오차).

## TTS 설정 (프로필 general 기본값 그대로, 오버라이드 없음)

- voice: `ko-KR-SunHiNeural`
- rate `+20%` / pitch `+30Hz` (s1~s7 전 구간 동일)

## 전환 여백

- 전 구간 프로필 기본 0.2초. 리액션+훅 질문 구간이 없어 원칙 4의 5번(0.5~0.7초 확장)을
  적용할 전환이 없다.

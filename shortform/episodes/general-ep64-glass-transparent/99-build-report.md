- **등장 전 요소가 점처럼 남아있는가**: LightScatterDiagram의 화살/경로는 전부
  `reveal<=0.02`일 때 `null` 반환(내부 opacity=0 아님, 실제로 안 그림) - 잔점 없음을
  f382(s3 시작 직후)에서 확인.

  "젖빛 유리"(s8) 라벨 전부 화면 폭 안에서 중앙정렬, 잘림 없음.
- **요소끼리 겹치는가**: s1에서 캐릭터가 두 블록 사이 간격에 서서 몸통 일부가 블록 하단과

  중앙~하단까지 요소가 채워져 있음을 f123/f382 등에서 확인.
- **음량이 충분한가**: 전체 믹스 loudnorm 실측 Input Integrated -13.6 LUFS, Input True
  Peak -2.4 dBTP(클리핑 없음). 내레이션(volume=1.6 적용 후 개별 피크 -0.32~+0.56dB) vs

  s1(효과음 구간)에는 내레이션 오디오가 없어(무성 구간) 겹침 없이 각각 개별 측정으로

- **자막 스타일이 프로필을 따르는가**: `assets/theme.ts`의 `CAPTION_STYLE`/`FS.caption`

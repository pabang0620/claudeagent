## 검수

### 스틸 선점검(원칙 5 "렌더 전 스틸 선점검")에서 잡은 결함 (렌더 전에 고침, 렌더 재실행 없음)
- **s1 다이어그램이 화면 오른쪽 가장자리에 딱 붙어 잘려 보이는 좁은 카드였다.** 1차 시도
  (다이어그램 폭 560, x=520 -> 오른쪽 끝이 화면 경계 1080과 거의 일치)를 `remotion still`로
  찍어보니 카드가 화면 구석에 붕 뜬 채 캐릭터와 분리돼 보였다. 다이어그램 폭을 650으로,
  캐릭터 크기를 460 -> 560으로 키우고 카드에 50px 여백을 주는 배치로 수정한 뒤 다시 스틸을
  찍어 확인했다("21화 이후 반복된 결함" B절과 같은 종류 - 작은 요소가 캔버스 가장자리에
  붙어 잘려 보임). 이 수정은 렌더를 태우기 전(스틸 단계)에 끝났으므로 재렌더가 발생하지
  않았다.
- 그 외 s2~s7, TitleCard, Outro 스틸은 1차 시도에서 결함 없이 통과했다(관찰: s2 지표
  냉각색이 밤 배경과 자연스럽게 어울림, s3 물방울 패치가 좁고 낮게 형성, s4 "표면 비부착"
  배지가 우상단에서 안개 면과 겹치지 않음, s5 안개가 카드 폭 전체로 두껍게 번짐, s6 구름
  실루엣-점선-안개 패널이 서로 겹치지 않고 세로로 정리됨, s7 해가 뜨며 안개가 완전히
  사라지고 지표색이 따뜻하게 복귀).

### 렌더 후에 발견한 결함
- 없음. 최종 mp4에서 뽑은 f001~f024(인트로 시작~아웃트로 끝, 각 구간 시작·중간·끝 프레임)를
  `remotion still`로 미리 본 것과 대조한 결과 시각적으로 동일했고, 크로스페이드 경계
  프레임(s2 끝 428 등)에서도 잔상이 관찰되지 않았다.

### 기술 점검 항목별 관찰 기록
- **자막 화면이탈**: f001~f024 전체 확인. 모든 구간에서 자막 박스가 좌우 여백을 두고 화면
  안에 들어온다. 가장 긴 줄(s7 "물방울이 도로 수증기로 돌아가면서")도 화면 폭 안에서
  줄바꿈됨.
- **장면 전환 잔상**: s1(캐릭터 있는 유일한 장면) -> s2(캐릭터 없는 장면) 전환 프레임(138
  부근)을 포함해 6프레임 크로스페이드 구간에서 캐릭터 잔상 관찰되지 않음.
- **등장 전 요소 잔상**: 모든 progress 레이어를 opacity 조건부 렌더(`opacity > 0.02 ? ... :
  null`)로 처리해 scale-0 점 잔상 방식을 쓰지 않았다. 렌더 결과에서도 점 잔상 없음.
  s6의 CloudFloatDiagram도 `cloudT > 0.02` 조건부로 등장 전엔 아예 안 그려짐을 확인.
  s7의 sun 아이콘도 `sunT > 0.02` 조건부로 확인.
  s4의 배지도 `floatT > 0.04` 조건부로 확인.
- **라벨 화면 밖 잘림**: s2~s6 라벨(지표면 냉각/물방울로 응결/공중에 떠 있음/안개/구름/
  같음,높이만 다름/안개) 전부 화면 안, 다이어그램과 안 겹침 확인.
- **요소 겹침**: s1 캐릭터(centerX 190, size 560)와 다이어그램(x 380~1030) 사이 약 40px
  간격 확인, 안 겹침. s4 배지(우상단)와 안개 면(중앙) 겹치지 않음. s6 구름/점선/안개 패널
  세로로 순서대로 배치돼 서로 안 겹침.
- **화면 아래쪽 여백**: 다이어그램(카드 하단 y=1025) + 라벨(y=1065~1100) 이후 자막
  박스(y~1420 시작) 사이에 여백이 있으나, 기존 화(예: general-ep63)의 카드-자막 간격과
  비슷한 비율이라 과다하지 않다고 판단.
- **음량**: `ffmpeg loudnorm` 측정 - Input Integrated -13.6 LUFS, Input True Peak -2.2 dBTP.
  클리핑 없음, 다른 화와 비슷한 수준.
- **자막 스타일**: 프로필 지정 폰트 크기(50px)·하단 위치·흰 배경/검은 글자(밝은 장면),
  어두운 배경(s2)에서는 `dark` prop으로 어두운 박스+크림색 글자로 자동 전환 확인.
- **한 줄 글자수 상한**: `wrapCounts`(한국어 20자)로 자동 처리, 육안 확인 결과 전 구간
  1~2줄 안에 자연스럽게 들어감.
- **캐릭터 윤곽선 대비**: 이 화는 어두운 배경(s2, 밤)에 캐릭터가 등장하지 않아(다이어그램만
  있음) 해당 없음.
- **precheck.mjs**: 에러 0, 경고 1(`SHAREDOUT`). 경고는 공용 루트 `shortform/out/`에
  `frames-en/`·`frames-ko/`가 있다는 것인데, 타임스탬프(2026-08-20, 3주 이상 전)로 확인한
  결과 이 화와 무관한 과거 잔존 파일이라 판단해 손대지 않았다.

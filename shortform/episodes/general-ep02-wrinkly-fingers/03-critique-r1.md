## 근거 대조 (01-research.md)

- 대본에 새로 등장한, `01-research.md`에 없는 수치·사실 주장은 발견되지 않았다. s3의 두 축(통설 반박 + 능동적 반응)은 A등급 주장 1·2번과 정확히 대응하고, s4-s5의 그립 기능 설명은 B등급 주장 3번(정성적 서술만 허용)과 대응하며 실제로 숫자(12% 등, C등급 미채택)를 전혀 쓰지 않았다. **통과.**
- 다만 참고할 점: `01-research.md`는 그립 기능(B등급)을 "가설"이며 "재현 실패 연구가 있어 확립된 정설이라기엔 이르다"고 명시했는데, s4-s5 내레이션("헛손질하지 말라고" / "몸이 일부러 ~ 해주는 거예요")은 헤지 없이 완전히 확정된 사실처럼 서술한다. 원칙 1의 "B등급을 확정 수치처럼 단정한다"는 지적은 **숫자 기준**이라 엄밀히는 위반이 아니지만(수치는 안 씀), 어조 자체는 A등급 사실(s3, "~거더라고요" 발견체)과 B등급 가설(s4-s5, "~예요" 단정체) 사이에 확신도 차이가 없다. planner가 이미 알고 결정한 것인지 확인이 필요한 지점으로만 남긴다 - critic이 대신 문장을 고치지는 않는다.

## 전문용어(쉬운 단어) 재검증

사용자가 오늘 명시적으로 지적한 "자율신경계", "삼투압", "혈관수축" 등 전문용어를 대본 전체(장면 지시·화면 문자·내레이션 대조표 모두)에서 재검색했다.

- **"자율신경계"**: 대본 본문(화면 문자·내레이션)에 없음. 대본 파일 48행에 planner가 남긴 메모("전문용어를 화면 자막·내레이션에 그대로 쓰지 말 것에 맞춰 '삼투압'·'자율신경계'·'혈관수축' 같은 명사형 전문용어를 쓰지 않고 전부 동사구로 풀어썼다")에만 등장하며, 이는 planner의 작업 설명이지 시청자에게 노출되는 화면·음성 콘텐츠가 아니다
- **"삼투압"**: 대본 본문에 없음(연구 문서 `01-research.md`의 출처 인용문에만 등장 - 원문 그대로 옮긴 것이라 정상)
- **"혈관수축"**: 대본 본문에 없음. 대신 "혈관을 좁힌다"/"혈관을 좁혀서"라는 동사구로 전부 풀려 있음(s3 화면 라벨, s3 내레이션)
- **그 외 잠재 전문용어**: "능동적 반응"(research.md 표현)도 대본에는 그대로 쓰지 않고 "몸이 스스로/일부러 만드는"으로 풀었음. "진화적 적응"(research.md B등급 표현)도 대본에는 등장하지 않음

**결론**: v1 대본은 실제로 이 요구를 충족하고 있다. 화면·음성에 노출되는 텍스트 기준으로 전문용어 잔존 사례는 발견되지 않았다. planner의 "쉬운 말로 풀었다"는 보고는 이번 재검증에서 확인됨(단, 위 s3/s5 압축 판정과는 별개 사안 - 쉬운 말 여부와 화면 중복 여부는 서로 다른 문제다).

## 길이 재계산

계산 기준: 한국어 낭독 초당 5.5음절 x TTS rate +20% = 초당 약 6.6음절(어림값). `01-research.md`가 밝힌 v1 총 길이(약 28초 = 인트로 2.3초 + 제목카드 1.8초 + s1 2.0초 + 내레이션 발화시간 + 문장부호 무음 + 구간 간 여백 0.8초 + 아웃트로 3.0초)를 같은 방식으로 재계산해 검증했다.

- **v1 내레이션 음절 수(공백·문장부호 제외)**: s2 15음절 + s3 38음절 + s4 16음절 + s5 26음절 = **95음절** → 발화시간 약 14.4초. 여기에 문장부호 무음(s2: `.``?` 2개=1.4초, s3: `,``.` = 0.9초, s4: 문장부호 없음=0초, s5: `.` = 0.7초, 합 3.0초) + 구간 간 여백 0.8초 + 고정 구간(인트로·제목카드·s1·아웃트로 7.1+2.0=9.1초)를 더하면 약 **27.3~28초**로 `01-research.md`가 밝힌 추정치와 일치함(검산 완료)

- **압축 반영 시(s2·s3·s5 압축안 적용)**: s2 12음절 + s3 24음절 + s4 16음절(변경 없음) + s5 17음절 = **69음절** → 발화시간 약 10.5초. 문장부호 무음은 s3에서 쉼표 1개가 사라져 0.2초 감소(2.8초), 나머지 고정 요소는 동일
- **압축 반영 후 예상 총 길이: 약 24초 (28초 → 24초, 어림값)**

프로필 상한(60초)에 비하면 압축 전후 모두 여유가 크다. **짧아진 것 자체는 문제가 아니므로 되살릴 필요 없음.** 상한을 넘지 않으므로 추가로 더 쳐낼 후보는 제시하지 않는다.

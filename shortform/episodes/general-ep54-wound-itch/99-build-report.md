# 54화 "딱지 앉은 상처가 간지러운 이유" - 빌드 리포트

프로필: general (굼구미). 한국어판 1개만 제작(오케스트레이터 명시 지시, 영어 채널 운영 중단).

## 자산

### 재사용(신규 제작 없음)
- `character/Actor`, `character/BustActor`, `character/poses`(idle, touchForehead, crouch)
- `backgrounds/PlainBg`
- `props/NerveSignal` (s7, 신경 신호 -> 뇌 이동)
- `props/ThemedIcon`('brain', s7)
- `scenes/Caption`, `scenes/Label`
- `assets/brand/Intro`, `Outro`, `scenes/TitleCard`
- `assets/audio/intro_ding.mp3`, `outro_ding.mp3`, `realize_ding.mp3`(s1 - "멈칫하며 알아채는" 순간에 재사용, REGISTRY "발견·자각 리액션 전반 재사용 가능"과 일치)

38화(`general-ep38-paper-cut`)의 `WoundCrossSectionDiagram`·`FingertipNerveDiagram`은 REGISTRY를
먼저 확인했으나, 이번 화는 이미 딱지가 앉아 "낫는 중"인 단계(새 살 차오름·히스타민 방출·딱지
당김)를 다뤄 38화의 "갓 베인 상처(피·중앙 틈 있는 딱지·신경 노출)" 구조와 맞지 않아 그대로
재사용하지 못했다. `FingertipNerveDiagram`은 손끝 신경 밀도 소재라 이 화(무릎 상처) 내용과
무관해 사용하지 않았다.

### 신규 제작 + REGISTRY 등록
- `assets/props/WoundHealDiagram.tsx` - "딱지 앉은 상처가 낫는 중" 단면 다이어그램. `WoundCrossSectionDiagram`과 같은 원형 단면 시각 문법(CX/CY/R_OUTER/R_INNER 동일)을 재사용하되, `healProgress`(새살이 아래에서 차오르는 단일 도형)·`histamineProgress`(입자 3개, 점 무리 아닌 큰 원)·`scabTightenProgress`(딱지 오그라듦+주름선 2개)·`nerveGlow`(신경선 강조, f 펄스)를 독립 진행도로 받는다. `assets/REGISTRY.md` 4절, `assets/props/index.ts`에 등록 완료. "국소 손상 복구+화학물질 방출+신경 자극" 구조의 다른 소재(알레르기 반응 등) 재사용 가능성을 명시했다.

REGISTRY·props/index.ts는 병렬 렌더 중인 53화 작업을 건드리지 않도록 기존 줄은 그대로 두고
끝에만 추가했다. `episodes/README.md`도 건드리지 않았다.

## 기술 점검

- `npx tsc --noEmit`: 이 화(ep54)·`WoundHealDiagram.tsx` 관련 에러 0 (다른 화의 기존 무관 경고는 있으나 이 화와 무관)
- `node scripts/precheck.mjs`: 에러 0 / 경고 1(`SHAREDOUT` - 공용 루트 `out/`에 다른 화의 잔여 프레임 폴더가 있다는 경고, 이 화가 만든 게 아니라 손대지 않음)
- 렌더: `node scripts/render.mjs general-ep54-wound-itch ko` 1회로 완료(재렌더 없음). 산출물 1080x1920, 30fps, 1244프레임
- 오디오: `loudnorm` 측정 Input Integrated -14.0 LUFS / True Peak -2.2 dBTP (클리핑 없음)
- SFX 타이밍 검증: `realize_ding`(s1, 재도전 지점) 예상 구간(4.8~6.0s)에서 mean -29.3dB/max -9.1dB, 직전 무음 구간(4.0~4.7s)은 -91dB(디지털 무음) - 의도한 프레임 근처에서만 소리가 남을 확인

## 스틸 선점검에서 잡은 결함 (렌더 전, 코드만 수정하고 재렌더 없이 반영)

1. **S1 손 위치 겹침** - 첫 설계는 손(캡슐)이 상처 원의 경계 안쪽으로 파고들어 원에 "붙은 혹"처럼 보였다. 화면 좌표로 시작점(원 밖 먼 지점)과 목표점(원 가장자리 바깥, gap ~16px)을 명시해 "다가왔다 멈칫"이 읽히도록 다시 배치했다.
2. **S4/S5/S6 히스타민 입자가 너무 작아 점처럼 보임** - 반경을 `7~10` -> `11~17`(화면 px 기준), 퍼지는 거리를 58->70(viewBox)으로 키워 "큰 원 3개"로 읽히게 했다.
3. **S5 NerveSignal이 짧은 거리에서 뭉개짐** - 히스타민 입자 원점과 신경선이 다이어그램 안에서 20px 남짓밖에 안 떨어져 있어, 둘을 잇는 NerveSignal 곡선이 점 하나로 뭉개져 보였다(comma 같은 잔상). 별도 NerveSignal을 빼고 다이어그램 자체의 `nerveGlow`만으로 "입자가 신경에 닿아 반짝인다"를 표현하도록 단순화했다.
4. **S8 캐릭터 다리가 자막 박스와 겹침** - 크라우치 포즈는 `feetVb`가 낮아져 다리가 화면 아래로 더 내려오는데, 다른 화(ep38 S1Cut)의 `ground=1560` 값을 그대로 가져다 써서 발이 자막 박스 테두리에 겹쳤다(42화와 같은 유형). ep33의 크라우치 사용 관례(별도 `ground` 오버라이드 없이 theme 기본값에 가깝게)에 맞춰 1240으로 낮췄고, 흉터 액센트 위치(`SCAR_Y`)도 같은 비율로 함께 조정했다.

(1) 배터리(리튬이온 배터리) 안에서는 이온이라는 작은 입자가 이동하면서 전기를 만든다(전제 - 없으면 "온도가 왜 배터리에 영향을 주는지"가 안 풀림) → (2) 온도가 낮아지면 배터리 속 액체(전해질)가 뻑뻑해져서 이온이 느리게 움직이고, 그만큼 전기를 낼 힘이 줄어든다(핵심 - 없으면 질문 자체가 안 풀림). 곁가지(원칙 0-1)로 이건 배터리가 고장난 게 아니라 잠깐 힘을 못 내는 것이라, 따뜻한 곳에 가면 다시 돌아온다는 점을 붙였다.

## 해시태그 (업로드 메타데이터용, 원칙 6)

`#굼구미 #상식 #배터리 #휴대폰 #겨울 #쇼츠`

구성 메모: 채널 태그 + 카테고리(`#상식`) + 주제 키워드(`#배터리` `#휴대폰` `#겨울`, 대본 사실 범위 안) + 플랫폼 태그(`#쇼츠`).

## 설명 (업로드 캡션용, 원칙 6)

`배터리 안에서는 이온이 이동하면서 전기를 만드는데, 추워지면 배터리 속 액체가 뻑뻑해져서 이온이 느리게 움직여요. 그래서 겨울에는 배터리가 힘을 잘 못 내는 것처럼 보이는 거예요.`

구성 메모: 1문장은 전제(이온 이동 원리), 2문장은 핵심 원인(전해질이 뻑뻑해짐)을 요약해 완결. 구독·좋아요 유도 문구는 넣지 않았다.

## 자산 목록

### 기존 라이브러리 재사용
- `character/Actor`, `character/BustActor` - 캐릭터 배치
- `character/poses`의 `surprised` - s2 리액션
- `backgrounds/PlainBg` - 특정 장소 고정 없이
- `scenes/Caption`, `scenes/Label` - 자막·라벨
- `scenes/Counter`의 `CountUp`/게이지류 - 배터리 게이지 표시

### 새로 만들어야 함
- `props/BatteryColdDiagram.tsx` - 배터리 내부 단면에서 이온 입자가 이동하는 속도를 온도에 따라 다르게 보여주는 소품. `ionSpeedProgress`(0~1, 따뜻할 때 빠른 이동 ↔ 추울 때 느린 이동을 하나의 진행도로 표현) / `outputGaugeProgress`(0~1, 이온 속도에 연동된 전기 출력 게이지) / `rewarmRecoverProgress`(0~1, 곁가지용 - 따뜻해지며 다시 회복)를 독립 진행도로 받는다.

## 기술 점검 (원칙 5)

### 렌더 전 스틸 선점검에서 잡은 결함 (렌더 전 코드 수정으로 해결, 재렌더 불필요)
1. **s1 얼음 큐브가 아예 안 보임** - `SceneSwitcher`는 `f`만 자동으로 넘기고 `props.frames`는
   별도로 넘겨야 하는데, `Episode.tsx`의 s1 `SceneSpec`에 `props: { frames: frames[0] }`를
   빠뜨려 `S1Drop`의 `frames`가 `undefined`가 되고 `floatCube` 계산이 `NaN`이 되어 큐브
   `opacity`가 0으로 떨어졌다. `props`에 `frames` 추가로 해결.
2. **s1 얼음 큐브가 컵 바닥 테두리를 뚫고 나옴** - `IceFloatCup`에 `liquidLevel={0}`을 줬더니
   뜬 큐브의 안착 위치(`restY`)가 액체 없는 상태를 가정하지 않아 컵 바닥보다 아래로 42px
   튀어나갔다. `liquidLevel={0.18}`(약간의 물)로 바꿔 큐브가 컵 안에 온전히 들어오도록 수정.
3. **s3 "녹아 있는 공기" 라벨이 화면(정확히는 다이어그램 박스 왼쪽 테두리)에서 잘림** -
   `ICE_AIR_LABEL_PT`가 박스 왼쪽 가장자리에 너무 가까워(x=190, 박스 시작 x=70) `align='center'`
   텍스트의 절반이 박스 테두리 밖/위로 겹쳐 "녹" 글자의 왼쪽 획이 테두리 선에 가려 보였다.
   픽셀 스캔(`PIL`로 첫 dark 컬럼 좌표 실측)으로 확인 후 `x:190->260, y:150->100`으로 이동,
   미네랄 라벨도 같은 이유로 `y:170->130`으로 살짝 올려 기포 도형과의 겹침을 없앴다.
4. **s6/s7 방향성(가게) 얼음이 완전히 얼어도 반투명 입자 2개가 박스 밖에 계속 남아있음** -
   `EXIT_TARGETS`(660,690)가 `exitFade` 완전 소멸 지점(edge+60=690)에 딱 걸쳐 있어
   `pushProgress=1`이어도 opacity 0.5로 남는 입자가 있었다. `EXIT_TARGETS`를 (700,730)으로
   밀어 `pushProgress=1`일 때 4개 입자 모두 opacity 0으로 완전히 사라지도록 수정.

### 렌더 전 스틸 선점검에서 "결함처럼 보였지만 실제로는 도구 문제였던" 것 (코드 수정 없음)

### 무성 구간(s1) 효과음 검증 (원칙 7)
- **의도한 프레임 근처 실제 에너지 확인**: s1은 내레이션이 없어(무성) 최종 믹스에서 직접 측정
  가능. `ice_clink` 예정 재생 구간(글로벌 프레임 161~168, 5.37~5.63초) 앞뒤를 `ffmpeg astats`로

  `-56.5dB`로 명확한 에너지 상승을 확인했다.
- **효과음이 내레이션보다 작은가**: s1은 내레이션과 안 겹치므로 개별 소스 파일에 실제 볼륨

  (SFX, `volume=0.85`) Peak `-3.83dBTP` - SFX가 내레이션보다 확실히 낮다.
- 듣기 좋은지·타이밍이 체감상 자연스러운지는 사용자 확인 필요 - 위 두 수치까지만 이 에이전트가

(의문형 종결 대신 서술형으로 바꾸고 "이상해"의 화면 중복분만 제거) |

## "단어가 쉬워야 한다" 재검증 (오늘 피드백 대응)

`골전도|저음|고음|주파수|BoneConduction|frequency|pitch` 패턴으로 대본 전체를 grep했다.

- **내레이션(s1~s5, KO/EN 전부)에는 위 전문용어가 전혀 없다.** "몸속 길", "낮고 굵어요", "묵직해요" 등 쉬운 말로만 되어 있다. 통과.
- 매치된 곳은 두 군데뿐이고 둘 다 내레이션이 아니다.
  1. `## 해시태그` 절: `#골전도` / `#BoneConduction` - 검색 유입용 메타데이터. 대본 자체가 "내레이션 어휘 규칙과 해시태그 키워드 선정은 별개 기준"이라고 명시해뒀고, 실제로 시청자가 듣거나 읽는(자막) 문장이 아니므로 이 피드백의 적용 대상이 아니다.
  2. `구간 시간은 낭독 추정치이며 TTS 실측(...voice/rate/**pitch**)으로...` - 이건 음성학 용어 "고음/저음"이 아니라 TTS 엔진 파라미터명(pitch)을 가리키는 제작 메모 문장이라 시청자 노출과 무관하다.
- 결론: **재검증 결과 문제 없음.** 대본 5번째 줄의 "오늘 반영 사항" 메모(전문용어 0개로 만들었다는 주장)는 사실과 일치한다.

## 화면 대조 결과

- **s2**: 화면 지시 "캐릭터 표정이 놀람으로 전환" ↔ 내레이션 "목소리가 이상해" 중복. 화면이 이미 놀람을 보여주므로 내레이션의 해당 부분은 겹친다 (위 판정표 압축안 참고).
- s3~s5: 화면(다이어그램/파형 굵기/마이크 연출)은 전부 "텍스트 라벨 없음"으로 설계되어 있다. 숫자·문자를 화면에 띄워놓고 내레이션이 그대로 다시 읽는 patterns(예: 화면 "7개" ↔ "일곱 개야")는 이 대본에 없다. 화면은 개념을 시각으로만 보여주고, 그 개념을 말로 설명하는 몫은 내레이션이 담당하는 구조라 상호 보완 관계이지 중복이 아니다.
- **화면도 목소리도 정보가 없는 구간**: 없음. s1은 무성이지만 화면 동작(녹음→정지→재생 탭)이 상황 자체를 명확히 전달하므로 "길이 채우기" 구간으로 보지 않는다.

## 길이 재계산

기준: 한국어 초당 5.5음절 × TTS rate +20%(프로필 4절) → 실질 초당 6.6음절. 문장부호 무음(마침표·물음표 약 0.7초, 쉼표 약 0.2초), 구간 간 여백 0.2초 반영. 전부 어림값.

- s2(현재) 18음절, s3 29음절, s4 28음절, s5 37음절 = 총 112음절
  - 발화시간 ≈ 112 / 6.6 ≈ 17.0초
  - 문장부호 무음 합계 ≈ 6.0초 (s2 1.6 + s3 1.4 + s4 1.4 + s5 1.6)
  - 여기에 s1 무성 구간 2.0초 + 구간 간 여백(4곳 × 0.2초) 0.8초
  - **합계 ≈ 25.8초** → 대본 상단에 적힌 "약 25초"와 거의 일치, 계산 방식 교차검증됨
- s2 압축안("어, 목소리가 다르게 들려.") 반영 시: s2가 18음절 → 11음절, 문장부호 무음도 1.6초 → 0.9초로 줄어 총합 **≈ 24.0초**
- **짧아진 것 자체는 문제가 아니다.** 프로필 상한은 60초이고 원안(25.8초)도 압축안(24.0초)도 상한에 크게 못 미친다. "다시 늘리자"는 제안은 하지 않는다.
- 상한을 넘지 않으므로 추가로 더 쳐낼 후보는 없다.

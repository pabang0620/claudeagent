# 확정 타임코드 - 한국어 (general-ep03-recorded-voice)

TTS 실측(edge-tts WordBoundary, `ko-KR-SunHiNeural`) 기준. `assets/timeline.ts`의
`sceneFrames`/`sceneStarts`로 계산했다. 대본 문장은 `02-script-v2.md`에서 그대로 가져왔고
수정하지 않았다.

## 구간별 TTS 실측 길이

| 구간 | 텍스트 | rate | pitch | 실측 길이(초) |
|---|---|---|---|---|
| s1 (무성) | (없음, 동작만) | - | - | 2.000 (대본 지정값, 실측 대상 아님) |
| s2 | 어, 목소리가 다르게 들려. | +32% | +55Hz (리액션 오버라이드) | 2.424 |

| s4 | 몸속 길 소리는 더 낮고 굵어요. 그래서 평소 내 목소리는 더 묵직해요. | +20%(기본) | +30Hz(기본) | 5.880 |
| s5 | 녹음기는 공기를 타고 온 소리만 담아요. 그 묵직한 소리가 빠져서, 더 낯설게 들리는 거예요. | +20%(기본) | +30Hz(기본) | 6.720 |

## 여백(pad) 적용

- s1 -> s2: 0 (s1은 대본 지정 고정 길이, 여백 없음)
- s2 -> s3: **0.6초** (리액션→설명 전환, 프로필 기본 여백 0.2초보다 확대 - ep01 v9 원칙 적용)
- s3 -> s4, s4 -> s5, s5 -> (아웃트로): 0.2초 (프로필 기본 여백)

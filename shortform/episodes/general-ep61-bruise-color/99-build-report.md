## 6. 색 변화 순서 검증 (55화 사고 재발 방지 - 원칙 4)

시작·끝 프레임뿐 아니라 **각 구간의 중간 지점까지 포함해 총 11개 지점**에서 `bruiseColorAt`
결과를 직접 눈으로 확인했다.

| 지점 | healProgress(계산값) | 관찰된 색 |
|---|---|---|
| s3 시작(poolProgress~0) | 0.04 | 빨강 (풀 형성 시작, 아직 옅음) |
| s3 60% | 0.04 | 빨강 (웅덩이 60% 성장, 진해짐) |
| s3 90% | 0.04 | 빨강 (웅덩이 거의 다 참) |
| s4(고정) | 0.20 | 빨강-보라 경계, 보라에 가까움("빨갛거나 퍼렇게") |
| s5 60% | 0.20 | 보라(s4와 동일 색 유지, 백혈구만 다가옴) |
| s6 시작(=s5 끝과 동일) | 0.20 | 보라 |
| s6 75% | ~0.53 | 초록-보라 경계, 초록에 가까움("색이 달라져요") |
| s7 시작(=s6 끝) | 0.62 | 초록 |
| s7 50% | 0.81 | 초록-노랑 경계, 노랑에 가까움 |
| s7 끝(healProgress=1 부근) | ~0.98 | 노랑 + 옅어짐(불투명도 감소, "서서히 사라지는") |
| s8 카드 4장 | 상수(0/0.22/0.58/1) | 빨강/보라/초록/노랑 4색이 각각 독립적으로 뚜렷이 구분 |

**진행 방향은 항상 빨강 -> 보라 -> 초록 -> 노랑(+옅어짐) 한쪽으로만 움직였고, 역행하는
구간은 관찰되지 않았다.** `healProgress`가 씬마다 이전 씬의 끝값에서 이어받아 계속 증가만
하도록 설계했기 때문에(s3: 0.04 고정 -> s4/s5: 0.20 고정 -> s6: 0.20~0.62 상승 ->
s7: 0.62~1.0 상승) 구조적으로 역전이 불가능하다.

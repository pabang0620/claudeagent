## 2. 시행착오 (스틸 선점검에서 잡은 결함 - 렌더 전에 고침)

렌더 전 `remotion still`로 대표 프레임을 뽑아 확인하는 절차(정의파일 "렌더 전 스틸 선점검")를 그대로 따랐고, 아래 결함은 **전부 렌더 전에** 발견해 고쳤다(렌더 후에야 발견한 결함은 없음).

1. **s1 화면 아래쪽 여백 과다**: 초기 Actor size=580/기본 GROUND=1250으로 뒀더니 화면 하단 1/3 이상이 텅 비어 보였다(원칙 5 예방 체크리스트 "화면 아래쪽 여백" 항목). general-ep46의 실측값(`ACTOR_SIZE=860`/`ACTOR_GROUND=1600`)을 참고해 `S1_ACTOR_SIZE=820`/`S1_ACTOR_GROUND=1620`으로 키우고 구름도 살짝 아래(y=250)·크게(width=620) 조정했다.
2. **`ElephantSide`를 `CloudFloatDiagram` 내부에 nested `<svg position:absolute>`로 중첩**: 34화에서 실제로 났던 결함("svg 안에 position:absolute 자식 svg를 중첩하면 CSS 위치가 무시됨")과 동일한 위험 패턴이라, 렌더 전에 코드 리뷰 단계에서 미리 `ElephantMarks`라는 순수 `<g>` 조각으로 분리해 `<g transform>` 으로만 배치하도록 고쳐서 애초에 그 결함이 발생하지 않게 했다.
3. **코끼리 다리가 몸통에 가려 안 보임(z-order 버그)**: 1차 시도에서 다리(rect)를 몸통(ellipse) 그리기 **전**에 그렸더니, 같은 채움색인 몸통이 다리를 완전히 덮어 스틸에서 다리가 안 보였다. 다리를 몸통 **다음**에 그리도록 순서를 바꿔 고쳤다.
4. **코끼리 실루엣이 "코끼리로 안 읽힘"**: 손그림 베지어 몸통(1차) → 머리만 있는 아이콘(2차) → 몸통+다리+짧은 코(3차)까지 총 4차례 스틸로 확인하며 반복 수정했다. 저울 접시 위 작은 아이콘 크기에서는 디테일(다리 4개, 짧은 코)이 뭉개져 안 읽혔고, 최종적으로 "큰 귀(가장 상징적인 특징) + 둥근 몸통 + 몸통 밖으로 눈에 띄게 길게 늘어진 코(끝이 살짝 말림) + 다리 2개(굵고 큼직하게)"로 단순화해서야 확대해서 볼 때 코끼리로 읽혔다. `assets/props/CloudFloatDiagram.tsx`의 `ElephantMarks` 주석에 시행착오를 남겨뒀다.

## 4. 기술 검증 (관찰 사실 - 최종 판정 아님)

렌더는 **1회**로 끝났다(스틸 선점검에서 결함을 미리 잡았기 때문에 렌더 후 재렌더가 필요한 결함은 없었음).

- [x] **자막이 화면 밖으로 나가지 않는가**: f005(1050프레임, s6 저울 장면)·f007(1420, 아웃트로) 등 확인한 모든 프레임에서 자막 박스가 좌우 여백을 두고 화면 안에 들어왔다
- [x] **장면 전환 시 캐릭터 잔상**: s2(바스트샷)→s3(다이어그램) 전환은 캐릭터 자체가 사라지는 전환이라 잔상 없음. 다이어그램 간 전환(s3~s6)은 스틸에서 xfade 구간(f522, s3→s4 크로스페이드 5프레임 지점)을 직접 확인 - 이전 장면(s3 콜아웃)과 다음 장면(s4 미니 구름)이 겹쳐 보이는 것은 SceneSwitcher의 의도된 크로스페이드(xfade=6프레임)이지 잔상 결함이 아님을 확인했다
- [x] **등장 전 요소가 점처럼 남지 않는가**: `CloudFloatDiagram`의 모든 레이어가 `undefined`/`opacity=0` 기준으로 조건부 렌더(`{dp !== undefined && calloutR > 1 ? ... : null}` 등)라 scale(0) 잔점이 남지 않는다. 코끼리도 `elephant1A/2A > 0.02` 조건으로 완전히 안 그려지다가 등장한다

- [x] **화면 아래쪽 여백이 과다하지 않은가**: s1에서 발견 후 원칙 5 "시행착오" 절 1번 항목대로 렌더 전에 수정 완료. 재수정 후 스틸(f001, f001b)에서 캐릭터가 화면 하단부까지 크게 채운 것을 확인

- [x] **자막이 프로필 스타일을 따르는가**: `Caption` 컴포넌트를 그대로 사용(프로필 폰트 크기 50px·하단 23%·흰 배경 검은 외곽선), 별도 커스터마이즈 없음

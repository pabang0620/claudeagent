## 스틸 선점검에서 잡은 결함 (렌더 전, 원칙 5)

1. **BlanketWrap 1차 시도**: topY를 `ground - size*0.46`으로 잡아 캐릭터 얼굴 턱 밑까지
   덮었더니, 캐릭터가 담요 상자 뒤에 파묻힌 것처럼 보였다(귀·눈만 겨우 보임). idle 포즈의

   `ground - size*0.33`으로 올려 잡았다.
2. **BlanketWrap 2차 시도**: `Bed.tsx`처럼 화면 전체 폭 + 화면 바닥까지 덮는 방식으로

   과다). 최종적으로 어깨선(0.33)~골반선 약간 아래(0.12, RIG.HIP.y=820 실측 기반)까지만
   내려오는 좁은 숄 형태로 좁혀 다리가 보이는 서 있는 자세를 유지했다.
3. **S7Final 무성 크래시**: `Episode.tsx`의 scenes 배열에서 S7Final에 `mouth` prop을 빠뜨려
   `mouthAt(mouth, 's7', f)`에서 `Cannot read properties of undefined (reading 's7')`로
   렌더 자체가 실패했다. `props: { lines: linesS7, frames: frames[6], mouth }`로 수정.
4. **NasalImmuneDiagram 점액 방울이 조직 경계를 뚫고 나감**: 방울이 다 자란 정지 상태(흐르기

   처럼 보였다. `DROP_CY`를 위로 올리고(-46 -> -86 오프셋) 크기를 줄여(360 -> 300) 정지
   상태에서는 경계 안쪽에 들어오게 하고, `flowT`(밖으로 흐르는 후반 단계)가 커질 때만 경계를
   넘어가도록 고쳐 "흐르기 전/후"가 시각적으로 구분되게 했다. 흡수되는 바이러스·먼지·섞이는

## X 표시(정정 뉘앙스) 처리 (70화 사고 재발 방지)

- s6에서 X 표시(`QMark` glyph='✕')는 **"세균 감염?"이라고 적힌 말풍선(오해) 위에만** 찍힌다.

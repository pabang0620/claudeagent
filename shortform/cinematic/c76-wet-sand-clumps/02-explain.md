# c76 설명 사슬 - 젖은 모래가 뭉치는 이유

## 질문

젖은 모래는 왜 뭉쳐서 성이 될까.

## 의외성

물이 풀처럼 붙인다고 생각해 "물을 많이 부을수록 더 단단하다"고 믿기 쉽다. 실제로는 알갱이 사이 물다리가 당겨야 뭉치고, 물이 틈을 가득 채우면 오히려 무너진다. (s2가 "많이 부을수록 단단해지는 것은 아니에요"라고 말로 뒤집고, 풍선의 양동이 -> 성 그림 위 X가 그 뜻을 맡는다. s6이 이유를 채운다.)

답 1문장: 알맞게 젖은 모래는 알갱이 사이 물다리가 표면을 오므려 서로 당기기 때문에 모양을 지키고, 물이 마르거나 넘치면 그 당김이 없어져 흘러내린다.

## "그래서?" 점검

s1 젖은 건 성, 마른 건 흐름 -> 물이 많을수록 단단한가? s2 아니다 -> 그럼 뭐가 붙드나? s3 알갱이 사이 물다리 -> 물다리가 왜 붙드나? s4 표면을 오므려 서로 당긴다 -> 그래서? s5 붙들려 마른 모래와 달리 안 흐른다 -> 물이 너무 많으면? s6 틈이 가득 차 물 표면이 없어져 못 당긴다 -> 결론은? s7 알맞게 젖은 모래는 물다리가 당겨 모양을 지킨다. 비약 없음.

연결(이전 결과어가 다음 주어):
- s2 -> s3: 확대 카드가 젖은 모래 탑에서 자라고 문장이 "모래알 사이"로 시작.
- s3 물다리 -> s4: "작은 다리처럼 고여요" 뒤 "물다리는".
- s4 당겨요 -> s5: "당겨진 모래는".
- s5 안 흘러요 -> s6: 같은 밀기 그림을 물 찬 쪽에 다시 대고 "물이 틈을 가득 채우면". 마른 쪽이 흐르던 것처럼 이번엔 물 찬 쪽 위 알갱이가 굴러 내림.
- s6 못 당겨요 -> s7: 시점이 다르므로(물이 찬 상태 vs 알맞게 젖은 상태) "되감기" 표지로 알맞게 젖은 상태로 되돌린 뒤 "알맞게 젖은 모래는".
- s7 -> 반전: 카드가 탑으로 닫혀 실제 장면 복귀.

용어 풀이: "물다리"(s3 "작은 다리처럼 고여요"에서 바로 풀이), "표면"(일상어). 풀이 필요 용어 1개.

# c58 화면 글자 (내레이션 자막은 자동이라 제외)

앵커는 내레이션 id 기준이다. 라벨은 그 대상을 말하는 어절이 발음되는 순간 팝인한다. 좌표는 1080x1920 기준 px(칩 중심, 글자 크기 약 40px). 라벨 칩은 도식 패널(x 70-540) 안쪽 오른쪽 띠(칩 x 405-525)에 두고 지시선은 칩 왼쪽에서 탱크로 간다. 굼구미(x 585-885)와 겹치지 않는다.

| id | 종류 | 앵커(등장~퇴장) | ko | 위치 |
|---|---|---|---|---|
| L1 | 라벨 | s2@"머리로" ~ s4.t0-0.40, 다시 s6@"머리에" ~ s6.t1+0.30 | 머리 | 칩 (465, 505), 지시선 끝 머리 탱크 오른쪽 (372, 505) |
| L2 | 라벨 | s2@"피가" ~ s3.t0-0.40 | 피 | 칩 (465, 590), 지시선 끝 머리 탱크 붉은 눈금 속 (320, 540) |
| L3 | 라벨 | s3@"다리에" ~ s6.t0-0.40 | 다리 | 칩 (465, 1005), 지시선 끝 다리 탱크 오른쪽 (362, 1005) |
| L4 | 라벨 | s4@"심장으로" ~ s6.t1+0.30 | 심장 | 칩 (465, 740), 지시선 끝 심장 탱크 오른쪽 (368, 740) |

- 숫자 N 없음, 스케일 표지 S 없음(도식 패널은 확대가 아니라 몸속 그림이고, 제목카드가 주제를 알려줌).
- 가독성: 칩 뒤에 남색 판(`#1B2A4E` 알파 0.85, 글자 둘레 여백 12px)이 기본 칩 바탕이다. 패널 안이라 배경 무늬와 겹치지 않는다.
- 노출 시간(1.5초 이상): L1 1차 약 7.6초(7.41-14.98), 2차 약 3.7초(26.04-29.77) / L2 약 2.4초(8.32-10.69) / L3 약 11.6초(13.04-24.60) / L4 약 13.1초(16.68-29.77). 퇴장 페이드 0.15초는 노출에 포함하지 않아도 모두 1.5초 이상.
- 동시 글자 점검(자막 포함, 퇴장·팝인 겹침 포함): 비트 1(s1) 자막 1 / s2 시작-7.41 자막 1 / 7.41-8.32 자막+L1=2 / 8.32-10.54 자막+L1+L2=3 / 10.54-10.69 L2 퇴장(자막은 s2 끝 10.19에 퇴장 완료, 다음 자막 11.09 팝인) L1+L2=2 / s3 11.09-13.04 자막+L1=2 / 13.04-14.78 자막+L1+L3=3 / 14.78-14.98 자막(퇴장 중)+L1(퇴장 중)+L3=3 / s4 15.38-16.68 자막+L3=2 / 16.68-19.59 자막+L3+L4=3 / s5 20.19-24.40 자막+L3+L4=3 / 24.40-24.60 자막(퇴장 중)+L3(퇴장 중)+L4=3 / s6 25.00-26.04 자막+L4=2 / 26.04-29.47 자막+L4+L1=3 / 29.47-29.67 자막 퇴장 중+L4+L1=3 / 비트 7 글자 없음. 최대 3.
- 핵심 비트에서 라벨 유지: s3 핵심 다리(L3, 다리 말하는 순간 팝인), s4 핵심 다리와 심장(L3, L4), s5 핵심 심장(L4, 다리는 돌아오는 길의 출발점이라 L3 유지), s6 핵심 머리와 심장(L1 재팝인, L4). s2 핵심 머리와 피(L1, L2). s3에서 머리는 핵심이 아니라 L1이 유지되지만 s4에서 3개가 되지 않도록 s4.t0-0.40에 내린다.
- 처음 나오는 대상별 라벨: 머리 탱크(L1), 붉은 눈금=피(L2), 다리 탱크(L3), 심장 탱크(L4). 훅의 소파, 창, 화분, 굼구미는 일상 사물이라 라벨 없음. 화살표, 점선, 괄호, 어둠은 효과라 글자 없음.

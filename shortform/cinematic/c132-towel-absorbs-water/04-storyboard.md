# 굼구미 시네마틱 c132 - 수건이 물을 빨아들이는 이유 (9:16)

Canvas 1080x1920 (9:16), 30fps 출력, 그림은 on twos(2프레임마다 갱신), 휙 지나가는 순간(패널 자라남, 렌즈 줄어듦, 폴짝)만 on ones. 본편만 다룬다 - 브랜드 인트로·제목카드·아웃트로는 엔진이 붙인다. 제목카드가 주제를 보여주므로 본편에서 주제 자막을 다시 띄우지 않는다.

예상 본편 길이 **약 31.55초**(구간 길이 = 글자수x0.11+0.72, gap 포함, 비트8 1.40초). 실제 TTS는 이보다 짧거나 길 수 있고 앵커 기준으로 만든다. 내레이션 7구간, 비트 8개. 설명 사슬은 훅 s1 + 의외성 s2 + 인과 고리 4(s3, s4, s5, s6) + 답 s7.

V4 강조 자막(emph)은 구간 자막의 해당 어절을 키우는 방식이라 별도 글자 요소가 아니다(동시 글자 3개 상한에 더하지 않는다).

굼구미: 흰 몸, 잉크 `#252E3A`, 코랄 볼 `#FC876E`. 머리카락·옷·코·귀·손가락 묘사 없음. 도식 장면(비트3~6)의 굼구미는 물·실·틈에 손대지 않는 관찰자·안내자이며 패널 아래 왼쪽(중심 x 173, 발 y 1235, 키 173, 위 1062)에서 눈과 몸 방향으로 가리킨다(패널 아래 1037과 25px). 모든 표시와 20px 이상 떨어지고 x 85% 안쪽, y 1250 위다.

## 과장 명시 (비트3~7)

실 가닥의 굵기와 틈 너비(실제는 훨씬 가늘고 좁고 꼬여 있음), 곧은 관처럼 그린 실 모양, 물이 오르는 속도와 높이 차, 화살표 길이는 개념을 보이려는 크기·단순화이며 실제 척도가 아니다. 렌즈 장면도 확대 표시다. 그래서 8.59부터 비트7이 끝나는 30.15까지 S1 "확대해 과장해 그림"(공백 포함 10자, 칩 폭 580, x 250-830)을 계속 띄운다(비트3~7 내내, 욕실 복귀의 렌즈 구간 포함).

## 공간 설계

- **욕실 장면(비트1·2·7·8)**: 벽 y 0-1150(타일 줄눈 격자), 바닥 y 1150 아래. 왼쪽 굼구미(중심 x 216), 가운데 수건걸이와 수건(x 540-720), 아래 세면대(x 440-820). 오른쪽 뒤에 먼 샤워 커튼 `#CFE3F0` 50% (x 860-1000, y 300-1100, 흐리게, 의미 없음).
- **도식 장면(비트3~6)**: 욕실이 `#14233A`로 어두워지고 젖은 수건 부분(중심 (630,880))에서 패널(x 65-900, y 441-1037)이 자라 나온다. 굼구미는 패널 아래 왼쪽에서 가리킨다.
- 도식은 실제 수건의 젖은 부분에서 자라 나오고, 비트7에서 줄어들어 수건 왼쪽 빈 벽의 렌즈가 된다(수건과 젖은 끝선을 가리지 않고 지시선으로 젖은 부분을 가리킨다).

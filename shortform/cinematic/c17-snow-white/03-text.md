# c17 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("눈이 하얗게 보이는 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

라벨은 내레이션이 그 단어를 실제로 말하는 순간에 뜨도록 배치했다(6절 규칙) - 그래서 서로 다른 단어가 필요한 라벨마다 narration 텍스트에 그 단어를 그대로 포함시켰다(02-explain.md 참고: "얼음 결정"→s5, "경계면"→s6, "산란"→s9).

- 16.70-18.20: L1 + s5 자막 = 2개.
- 18.20-20.57: s5 자막 단독 = 1개(L1 페이드 아웃 후).
- 20.57-21.07: 없음(고리2 등장 전 간격).
- 21.07-23.24: s6 자막 단독 = 1개(L2 등장 전).
- 23.24-24.74: L2 + s6 자막 = 2개.
- 24.74-25.41: s6 자막 단독 = 1개(L2 페이드 아웃 후).
- 25.41-29.50: s7 자막 단독 = 1개(고리3 비트, 라벨 없음 - 갈라지는 산란 자체는 시각적으로 자명해 라벨을 붙이지 않는다).

# c13-shivering 리뷰

## 판정: PASS

## 시청 시뮬레이션 요약
1. 제목카드: "추우면 몸이 덜덜 떨리는 이유" - 주제 확정.
2. 비트1(0-3.72s): 눈 오는 밖, 굼구미가 떤다. s1 "굼구미가 추운 곳에서 몸을 떨어요." → 추위+떨림 장면만 앎, 설명 없음.
3. 비트2: 표정이 처짐. s2 "떨림은 그냥 힘이 빠져서 그런 거라 생각하기 쉬워요." → 통념(기대) 인지.
4. 비트3: 표정이 확신으로 바뀜. s3 "근데 사실 떨림은 몸이 일부러 하는 거예요." → 반전 인지, 원인은 아직 모름.
5. 비트4: 남색 dim + 스케일 표지 "피부 속 확대". s4 "몸속으로 들어가서 볼게요." → 스케일 전환만.
6. 비트5: 살구색 피부 단면, 파란 센서 반짝, 노랑 화살표가 뇌 쪽으로. L1 "온도 센서". s5 "피부의 온도 센서가 뇌에 신호를 보내요." → 고리1 습득.
7. 비트6: 뇌 글로우, 주황 화살표가 근육 쪽으로. L2 "뇌". s6 "뇌는 근육에 빨리 움직이라고 명령해요." → 고리2 습득.
8. 비트7: 근육 코일이 붉게 변하며 고속 진동. L3 "근육". s7 "근육이 아주 빠르게 수축과 이완을 반복해요." → 고리3 습득.
9. 비트8: 같은 코일에서 호박색 열 물결. L4 "열 발생". s8 "이 움직임 자체가 몸에 열을 만들어요." → 고리4 습득(운동=열의 출처가 시각적으로 이어짐).
10. 비트9: 야외로 컷백, 몸에 열 유령 윤곽 겹침. s9 "이제 떨림 덕분에 몸이 따뜻해져요." → 복귀 확인.
11. 비트10: 떨림이 잦아들며 편안한 미소. s10 "뇌가 근육을 움직여서 몸을 스스로 데우는 거예요." → 답 확정.
12. 비트11: 장난스럽게 한 번 더 크게 떤다(내레이션 없음, 반전 펀치라인).

이해 판정: 시뮬레이션 끝에서 시청자는 02-explain.md 답 문장("피부 센서가 뇌에 알리면 뇌가 근육에 명령하고, 근육의 빠른 수축-이완 자체가 열을 만든다")을 스스로 재구성할 수 있다. 끊기는 고리 없음.

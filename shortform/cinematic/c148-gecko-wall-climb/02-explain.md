# c148 설명 사슬 - 도마뱀붙이가 매끈한 벽에 붙는 이유

## 질문
도마뱀붙이는 유리처럼 매끈한 벽을 어떻게 기어오를까.

## 의외성
끈끈한 액체가 나와서 붙는다고 생각하기 쉽지만 발바닥에서는 아무것도 나오지 않는다(F6). 붙는 힘은 눈에 안 보이는 털 끝과 벽 사이의 아주 작은 끌림이다(F4).

## 인과 고리 (4개)

| 고리 | 내레이션(ko) | 봐야 하는 그림 | 피해야 할 오해 |
|---|---|---|---|
| 0 훅 s1 | 도마뱀붙이가 매끈한 벽을 기어올라요. | 반들반들한 벽을 도마뱀붙이가 거꾸로 기어올라 멈춘다. 설명 없음 | - |
| 0 반박 s2 | 도마뱀붙이가 끈끈이 때문에 붙는 게 아니에요. | 굼구미가 관객을 보고 고개를 젓는다(그림 추가 없음) | 끈끈이를 그리면 있는 것처럼 보임. 그리지 않는다 |
| 1 s3 | 발바닥에는 눈에 안 보이는 가는 털이 나 있어요. | 장면 발에서 확대 원이 커져 옆 단면 패널이 되고, 초록 발가락 아래 주름판에 털 2개가 자라며 벽 면에 "벽" 라벨 | 털이 접착제처럼 쓰이는 느낌, 털이 2개뿐이라는 느낌(표지로 보정) |
| 2 s4 | 털 끝은 더 가늘게 갈라져 벽면에 바싹 닿아요. | 털 끝이 둘로 갈라져 끝 4개가 되고 발이 내려와 벽에 닿는다 | 누르는 힘으로 붙는다는 오해(누름 화살표 없음) |
| 3 s5 | 아주 가까우면 털 끝과 벽은 서로 살짝 끌어당겨요. | 끝마다 분홍 화살표 한 쌍이 마주 봄 | 빨판처럼 빨아들이는 인상(공기 표시 없음), 털 끝만 특별한 자석이라는 인상("가까우면" 조건을 먼저 말함) |
| 4 s6 | 털 끝이 수없이 많아서 작은 끌림이 모두 더해져요. | 네 끝이 차례로 빛나며 분홍 막대가 끝 하나당 한 칸씩 4칸까지 쌓임 | 끌림 하나가 크다는 인상(첫 칸이 작게 보임) |

## 답
s7: 그래서 모인 끌림이 도마뱀붙이를 벽에 붙들어요.

## "그래서?" 점검
- 훅 붙는다 -> 그래서? 끈끈이는 아니다 -> 그럼? 털이 있다 -> 그래서? 끝이 갈라져 벽에 바싹 닿는다 -> 그래서? 가까우면 서로 끌어당긴다 -> 그래서? 끝이 많아 합쳐진다 -> 그래서 몸이 붙는다. 비약 없음.
- 이음: s3의 "털" -> s4 "털 끝은", s4의 "벽면에 바싹 닿아요" -> s5 "아주 가까우면 털 끝과 벽", s5의 "끌어당겨요" -> s6 "작은 끌림이", s6의 "더해져요" -> s7 "모인 끌림이".
- 원인 한마디: 고리 2는 "바싹 닿아요"(왜 가까워지나: 가늘게 갈라져서), 고리 3은 "아주 가까우면 끌어당겨요", 고리 4는 "수없이 많아서".

## 통념 반박과 조건
- s2가 "끈끈이 때문에 붙는 게 아니에요"로 말로 반박하고, s3이 진짜 원인 쪽(털)으로 시선을 옮긴다.
- 조건: 종은 도마뱀붙이로 한정(s1·s2·s7). 일반 도마뱀으로 확장하지 않는다.

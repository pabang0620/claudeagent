## 과학 정확성 판단

- 털 -> 갈라진 끝이 어디서 자라는가: 털은 주름판 아래에서 자라고 끝은 털 아래에서 갈라지니 방향은 맞다. 다만 주름판이 허공에 뜬 초록 막대 3개라 "발바닥 = 발가락 아래 면"이 읽히지 않는다. 장면의 발은 벽 쪽에서 본 위쪽 모습인데 패널은 옆 단면이고, 시점이 바뀌었다는 연결이 없다(고칠 것 1).
- 확대 배율 과장 표지: S1 "확대해 과장해 그림"이 비트3~6 내내 떠 있고 숫자가 없어 B급 문제 없음. 다만 발 -> 털 -> 갈라진 끝은 확대가 두 단계인데 표지는 한 번뿐이다. 비트4에서 "한 번 더 확대"를 따로 표지할 필요까지는 없다고 본다.
- 떼어낼 때 설명 생략: 오해 없음. 단 비트1에서 걸어 올라가는 모습과 s7 "붙들어요"가 영구 접착으로 읽힐 여지는 작다. 새 고리 추가는 제안하지 않는다.
- 벽 면 라벨 생략: 괜찮지 않다. 훅의 벽은 세로로 서 있고 패널의 판은 발 아래 가로 판이라 같은 벽으로 이어 읽기 어렵다. 자막 "벽면"과 색 일치만으로는 약하다(고칠 것 2).

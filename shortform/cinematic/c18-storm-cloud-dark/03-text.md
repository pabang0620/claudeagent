# 03. 화면 글자 (라벨 / 숫자 / 스케일 표지)

내레이션 자막은 `narration-ko.json`/`narration-en.json`에서 자동 표시되므로 여기 적지 않는다.
이번 편은 A등급 구체 수치가 없어 숫자(N) 라벨은 쓰지 않는다.

| id | 종류 | 앵커(등장~퇴장) | ko | en | 위치 |
|---|---|---|---|---|---|
| L1 | 라벨 | 비트6(s3 시작)~s5 종료 hold | 물방울 | Droplet | 대상 옆, 지시선 |
| L2 | 라벨 | 비트2(s1 시작)~비트11(s6) 재등장 hold | 얇은 구름 | Thin cloud | 대상 옆, 지시선 |
| L3 | 라벨 | 비트4(s2 시작)~비트12(s7) 종료 | 두꺼운 구름 | Thick cloud | 대상 옆, 지시선 |
| S1 | 스케일 표지 | 비트7(s3.t1+0.3)~s4 시작 | 물방울 크기로 | Droplet-scale view | 그림 무대 위쪽 |

- 한 화면 동시 최대치(내레이션 자막 1 + 라벨 2) 확인: 비트11(L2+L3 동시)이 최대 지점이며 초과 없음.
- 라벨 글자수: L1 3자, L2 4자, L3 4자 - 전부 6자 이내.
- 스케일 표지 S1: 7자(공백 제외) - 10자 이내.

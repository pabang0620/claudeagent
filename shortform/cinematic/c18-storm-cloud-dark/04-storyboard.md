# 04. 스토리보드 - 비구름만 새까매지는 이유

캔버스 1080x1920 (9:16), 30fps, on twos 기본(휙 전환·충돌만 on ones).
예상 본편 길이 약 43초 (브랜드 인트로 2.3초 + 제목카드 1.8초 + 본편 + 아웃트로 3.0초는 엔진이 별도 렌더).

## 팔레트 (hex)

- 맑은 하늘 배경: `#BFE1F2`
- 폭풍 하늘 배경: `#7C93A6`
- 얇은 구름(뭉게구름) 채움: `#FFFFFF`, 외곽선 잉크 `#252E3A`
- 두꺼운 구름(비구름) 채움: `#5B6B7A`, 외곽선 잉크 `#252E3A`
- 물방울 채움: `#BFE4FB`, 외곽선 `#2B4A5E`
- 햇빛/빛줄기: `#FFD83A` (방향과 무관하게 항상 이 색, 방향은 화살표 모양으로만 구분)
- 굼구미: 흰 몸, 잉크 `#252E3A`, 코랄 볼 `#FC876E` (고정)
- 라벨/표지 텍스트 배경: 잉크 `#252E3A` 필에 흰 글자

## 색 약속 표

| 개념 | 색 | 비고 |
|---|---|---|
| 물방울 | `#BFE4FB` 채움 + `#2B4A5E` 외곽선 | 뭉게구름·비구름 어디서든 동일 (재질이 같다는 것을 색으로도 증명) |
| 햇빛(들어오는 빛) | `#FFD83A` | 방향 전환 후에도 같은 색 유지 |
| 얇은 구름 | `#FFFFFF` | 뭉게구름, 항상 밝음 |
| 두꺼운 구름 | `#5B6B7A` | 비구름, 항상 어두운 회청색 |

## 화풍

굼구미 인트로와 동일한 잉크 라인 + 플랫 컬러 카툰 화풍. 설명(E) 구간에서는 설명 중인 대상 외 배경을 40~60% dim 처리해 초점을 하나로 모은다.

## 자체 점검 결과

- 인과 고리 4개 전부 `E` 비트(비트 8/9, 11/12, 14/15, 16/17)에 반영되고 순서 일치.
- 훅(비트1, 1.30초 silent) + 비트2(s1, 장면 관찰만, 1.99초) = 약 3.29초, 설명 없는 장면 설정만으로 2.5초 이상 확보.
- E 비트 각각 내레이션보다 0.3~0.4초 먼저 그려지기 시작, 핵심 장면 완성은 내레이션 진행 중 hold.
- 굼구미가 물리적 원인을 대신하는 비트 없음 (모두 가리키기/막대로 짚기/비교판 끌어오기 등 안내자 행동).
- `A` 비트 전부 1.4초 이하(최대 1.30초).
- `E` 비트 합계 약 35.3초 / 전체 약 43초 = 약 82% (55% 기준 충족).
- 처음 등장 과학 대상(물방울, 얇은 구름, 두꺼운 구름) 전부 라벨 있음.
- 비교 필요한 고리(밀도, 두께, 빛 굵기)는 전부 나란히 배치 또는 유령 윤곽 비교로 처리.
- 한 화면 동시 글자 최대(자막1+라벨2) 비트11에서 정확히 충족, 초과 없음.
- 화면 숫자 없음(A등급 수치 없어 사용하지 않음).
- 굼구미에게 머리카락·옷·코·귀·손가락 묘사 없음(손/막대/확대경/우산만 사용).

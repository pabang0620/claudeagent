# c15 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("팝콘이 뻥 하고 터지는 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

| id | 종류 | 등장~퇴장(예상 초) | ko | en | 위치 |
|---|---|---|---|---|---|
| S1 | 스케일 표지 (D.scaleBadge) | 9.31-11.75 | 알갱이 속으로 확대 | Zoom into the kernel | 그림 무대 위쪽 |
| L1 | 라벨 | 11.75-14.00 | 수분 | Moisture | 알갱이 단면 물방울 옆, 지시선 |
| L2 | 라벨 | 15.24-18.00 | 수증기 | Steam | 김 아이콘 옆, 지시선 |
| L3 | 라벨 | 18.99-20.70 | 압력 | Pressure | 바깥으로 미는 화살표 옆, 지시선 |
| L4 | 라벨 | 20.76-24.60 | 껍질 | Hull | 균열선 옆, 지시선 |

## 동시 표시 점검
- 0.00-1.30: 없음(장면 설정, 내레이션 시작 전).
- 1.30-5.12: 자막(s1)만 = 1개.
- 5.12-5.62: 없음(고리 전 간격).
- 5.62-9.31: 자막(s2)만 = 1개.
- 9.31-10.11: S1만 = 1개(스케일 전환, 무음 A 비트).
- 10.11-11.75: 자막(s3) + S1 = 2개.
- 11.75-13.02: 자막(s3) + L1 = 2개(S1은 11.75에 종료, L1과 겹치지 않음).
- 13.02-13.42: L1만 = 1개(고리1→고리2 전환 간격).
- 13.42-14.00: 자막(s4) + L1 = 2개.
- 14.00-15.24: 자막(s4)만 = 1개(L1 종료, L2 시작 전).
- 15.24-16.59: 자막(s4) + L2 = 2개.
- 16.59-16.99: L2만 = 1개(전환 간격).
- 16.99-18.00: 자막(s5) + L2 = 2개.
- 18.00-18.99: 자막(s5)만 = 1개(L2 종료, L3 시작 전).
- 18.99-20.42: 자막(s5) + L3 = 2개.
- 20.42-20.70: L3만 = 1개(전환 간격).
- 20.70-20.76: 없음(찰나의 간격).
- 20.76-20.82: L4만 = 1개(s6 자막 시작 전).
- 20.82-24.25: 자막(s6) + L4 = 2개.
- 24.25-24.60: L4만 = 1개(전환 간격).
- 24.60-24.65: 없음.
- 24.65-25.79: 자막(s7)만 = 1개(L5 시작 전).
- 25.79-28.08: 자막(s7) + L5 = 2개.
- 28.08-28.50: L5만 = 1개(전환 간격).
- 28.50-28.68: 없음.
- 28.68-32.50: 자막(s8)만 = 1개(일상 장면으로 복귀, 라벨 없음).
- 32.50-33.70: 없음(반전 비트, 자막·라벨 없음).
- 어느 시점도 상한(자막1+라벨2=3)을 넘지 않는다. 이번 판은 최대 동시 2개로 여유 있게 유지된다.

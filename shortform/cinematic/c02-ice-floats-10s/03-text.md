# c02 화면 글자

한 화면 동시 최대: 설명 자막 1 + 라벨 2 (주제 자막 T는 별도 상단 띠라 이 상한에 포함하지 않음).
체류시간 = max(1.8초, 글자 수[공백 포함] x 0.18초). 영어가 한국어보다 항상 더 길어서, 창(window)은 두 언어 dwell 중 큰 쪽(영어)에 맞췄다.

리뷰 반영: 훅이 0.80s -> 1.00s로 늘어나며(B 항목, 의외성 대비 추가) 뒤 비트가 전부 +0.20s 밀렸고, 전환-복귀(0.40->0.30)·마무리(0.60->0.50)에서 0.20s를 줄여 총 10.00초를 유지했다. L3/L4(액체/고체)를 신규 등록했다(K/비트6 항목).

동시 표시 점검:
- 1.40-2.00: S1(~1.80까지)+L1 = 최대 2개(T 제외).
- 2.00-3.00: L1+L2+c1 = 3개(상한과 동일, 위반 아님) -> 3.00 이후 L1 종료, L2+c1(2개) -> 3.50 이후 c1 단독.
- 5.36-5.96: L3+L4 = 2개(캡션 전).
- 5.96-9.20: L3+L4+c2 = 3개(상한과 동일, 위반 아님).
T는 상단 띠라 항상 별도 산정.

## 동시 표시 점검 (자막은 해당 구간 t0~t1 동안 표시)
- 0.00-1.00: 없음. 1.00-4.47: s1 = 1. 4.47-5.00: 없음.
- 5.00-5.27: L1 = 1. 5.27-6.41: L1 + s2 = 2. 6.41-6.50: L1 + L2 + s2 = 3. 6.50-7.91: S1 + L2 + s2 = 3. 7.91-8.41: S1 + s2 = 2. 8.41-8.71: S1 = 1.
- 8.71-9.11: S1 + L3 = 2. 9.11-10.21: S1 + L3 + s3 = 3. 10.21-11.92: S1 + s3 = 2. 11.92-12.72: S1 = 1.

- 25.74-29.65: S1 + s7 = 2. 29.65-30.65: S1 = 1. 30.65-34.45: S1 + s8 = 2. 34.45-35.85: 없음.
- V4 강조 자막(emph)은 구간 자막의 해당 어절을 키우고 색을 바꾸는 방식이며 별도 글자 요소가 아니다. 위 개수에 더하지 않는다.

## 라벨 규칙 점검
- 라벨 6자 이내(공백 포함): 체중계 3, 처음 눈금 5, 중력 2, 몸 속도 4, 위로 힘 4. 표지 10자 이내: 과장해 그림 6. 칩 폭 = 글자수x54+40: 3자 202, 5자 310, 2자 148, 4자 256, 6자 364.
- 노출 1.5초 이상: L1~L6 모두 1.50, S1 27.95.
- 대상이 처음 그려진 뒤 1초 안에 팝인: L1 0.13, L2 동시, L3 동시, L4 0.55, L5 0.22, L6 재호출.
- 라벨 팝인은 가리키는 어절 0.4초 전이거나 어절이 노출 중일 때: L2 "눈금도", L3 "중력이", L4 "몸도", L5 "힘이", L6 "바닥이" 모두 -0.40. L1은 체중계가 4.87에 처음 그려져 5.00에 팝인하고 어절 "체중계"(6.37)가 노출 중이다.
- S1은 과장 동작(바늘 이동 6.90-7.30)보다 0.40 먼저(6.50) 뜬다.
- 한 윤곽에 이름 두 개 금지: 주황 화살표는 "위로 힘" 하나, 보라는 "중력", 청록은 "몸 속도", 초록 점선 바늘은 "처음 눈금", 판은 "체중계"(L6은 같은 이름).
- 간격: L3 칩 오른쪽 373과 굼구미 왼쪽 약 396은 23px(웅크림 sx 1.08에서 약 390이면 17px이므로 L3 시각 b3 동안 웅크림은 sx 1.03 이하). L2/L4/L5 칩 아래 670 이하와 계기판 위 725는 55px, 칩 오른쪽 830 이하는 칸 오른쪽 안벽 880과 50px. 칩 왼쪽 520~540과 청록 화살표 x 470은 50px 이상. 칩과 자막 띠(y 1250 이하) 사이 거리는 충분.

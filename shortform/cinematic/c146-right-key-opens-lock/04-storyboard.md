# 굼구미 시네마틱 c146 - 맞는 열쇠만 자물쇠를 여는 이유 (9:16)

Canvas 1080x1920, 30fps 출력, 그림은 on twos(2프레임마다 갱신), 휙 지나가는 순간(패널 자라남·줄어듦)만 on ones. 본편만 다룬다. 제목카드가 주제를 보여주므로 본편에서 주제 자막을 다시 띄우지 않는다.

예상 본편 길이 **약 36.64초**(구간 길이 = 글자수x0.11+0.72, gap 포함, 비트9 1.40초). 실제 TTS는 앵커 기준으로 만든다. 내레이션 8구간, 비트 9개. 훅 s1 + 반박 s2 + 이동 s3 + 인과 고리 4(s4~s7) + 답 s8.

굼구미: 흰 몸, 잉크 `#252E3A`, 코랄 볼 `#FC876E`. 머리카락·옷·코·귀·손가락 묘사 없음. 손은 둥근 끝(고무호스 팔 끝)으로 열쇠 머리를 쥔다. 열쇠를 꽂고 돌리는 것은 원인 조작(실험자)이고, 핀을 올리고 속통을 막고 푸는 일은 톱니 모양·스프링·핀 배치가 한다. 장면에서는 얼굴이 오른쪽(문 쪽)을 본다. 도식 비트(3~7)의 굼구미는 키 200으로 표정(눈 찡그림, 눈 커짐)이 읽힌다.

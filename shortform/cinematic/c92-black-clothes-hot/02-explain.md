# c92 설명 사슬 - 햇볕에 검은 옷이 더 뜨거운 이유

## 질문

같은 햇볕 아래 걸어 둔 검은 옷은 왜 흰 옷보다 더 뜨거울까.

## 의외성

검은색이 열을 만들어 내거나 끌어모은다고 믿기 쉽다. 실제로 열의 출처는 햇빛이고, 색은 닿은 햇빛을 튕겨 내는 정도와 받아들이는 정도를 가를 뿐이다. (s2가 "옷 색이 열을 만들어 내는 건 아니에요"라고 말로 뒤집고, 풍선 안 검은 옷 -> 열 아이콘 위 X가 그 뜻을 맡는다. 이어서 s3이 "열이 될 에너지는 햇빛이 싣고 온다"로 시선을 햇빛으로 옮긴다.)

## "그래서?" 점검

s1 검은 옷이 더 뜨겁다 -> 색이 열을 만드나? s2 "만들어 내는 건 아니에요" -> 열은 어디서? s3 햇빛이 에너지를 싣고 온다 -> 두 옷은 뭐가 다른가? s4/s5 흰 옷은 많이 튕기고 검은 옷은 대부분 빨아들인다 -> 빨아들이면? s6 알갱이를 세게 흔든다 -> 흔들리면 왜 뜨거운가? s7 세게 흔들리면 뜨겁다 -> 결론 s8 더 빨아들여 더 뜨겁다. 비약 없음.

왜 그렇게 되나(고리마다 원인 한마디): s3 "싣고 와요"(열의 출처), s4/s5 "튕겨 내요/빨아들여요"(옷 색에 따라 닿은 뒤가 다름), s6 "세게 흔들어요"(흡수한 빛이 알갱이로 넘어감), s7 "흔들리면"(흔들림=온도, 주어를 "검은 옷 알갱이"로 밝힘).

연결(이전 결과어가 다음 주어):
- s1 -> s2: "더 뜨거워져요"에 "옷 색이 열을 만들어 내는 건 아니에요".
- s2 -> s3: "열을 만들어 내는 건 아니에요"에 "햇빛은 옷을 데울 에너지를 싣고 와요"(열의 출처 이동).
- s3 -> s4: "햇빛" -> "닿은 햇빛을". 카드 진입은 A 비트이고 표지 "옷감 확대".
- s4/s5 -> s6: "빨아들여요" -> "검은 옷이 받은 햇빛은"(검은 옷이 주어로 다시 나옴).
- s6 -> s7: "흔들어요" -> "검은 옷 알갱이가 세게 흔들리면".
- s7 -> s8: "뜨거워요" -> "더 뜨거워져요". 카드가 닫혀 실제 두 옷으로 복귀하고 온도계가 다시 오름.

용어 풀이: "에너지"(생활어, 햇빛이 데우는 힘이라는 화면 그림으로 충분), "알갱이"(라벨 "옷감 알갱이"와 그림)만 있음. 풀이가 필요한 용어 2개 이하.

시점 연결: 훅에서 이미 오른 온도계는 s3 시작에서 처음으로 되감김("처음으로 되감기")으로 카드의 시작 순간과 맞추고, s8에서 다시 올라 훅의 결과와 이어진다.

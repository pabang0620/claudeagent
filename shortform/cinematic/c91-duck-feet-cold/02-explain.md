# c91 설명 사슬 - 오리 발이 차가운 이유

## 질문

오리는 얼음 위에 서 있어도 왜 몸이 식지 않을까(발은 왜 차갑게 두는가).

## 의외성

"발이 따뜻해서 버틴다"고 믿기 쉽다. 실제로는 발이 차갑고, 그 차가움이 열을 덜 잃는 결과를 만든다. (s2가 "발을 따뜻하게 데워서 버티는 건 아니에요"라고 말로 뒤집고, 말풍선의 발 + 빨간 열기 위 X가 그 뜻을 맡는다. 이어서 s3부터 다리 속 혈관으로 시선을 옮긴다.)

## "그래서?" 점검

s1 오리가 얼음 위에 선다 -> 발이 따뜻한가? s2 데워서 버티는 건 아니다 -> 그럼 다리 속은? s3 따뜻한 피가 발까지 간다 -> 돌아오는 길은? s4 바로 옆 혈관으로 돌아온다 -> 옆이면? s5 열은 따뜻한 쪽에서 찬 쪽으로 흐른다 -> 그래서? s6 내려가는 피의 열이 옆의 식은 피로 넘어간다 -> 결과는? s7 내려가는 피는 식고 올라오는 피는 데워진다 -> 발은? s8 발에는 식은 피가 가서 발이 차갑다 -> 차가우면 뭐가 좋나? s9 얼음과 온도 차가 작아서 열이 덜 샌다 -> 결론 s10. 비약 없음.

연결(이전 결과어가 다음 주어):
- s2 -> s3: 카드가 오리 다리에서 열리고 문장이 "몸의 따뜻한 피"로 시작.
- s3 "발까지 가요" -> s4 "발에서 식은 피": 발을 받아 돌아오는 길로.
- s4 "바로 옆 혈관" -> s5: 옆이면 열이 오간다는 이유(열의 방향)를 말.
- s5 "찬 쪽으로 흘러요" -> s6 "그래서 ... 식은 피로 넘어가요".
- s6 "넘어가요" -> s7 "식고 ... 데워져요" 결과.
- s7 "내려가는 피는 식고" -> s8 "발에는 식은 피가 가서".
- s7 "내려가는 피는 식고" -> s8 "발에는 식은 피가 가서 발도 차가워요".
- s8 "발도 차가워요" -> s9 "차가운 발은 ... 열이 덜 새요": 주어가 이전 결과어.
- s9 "열이 덜 새요" -> s10 "몸의 열을 덜 잃는 구조": 카드를 닫고 실제 오리로 복귀.

용어 풀이: "혈관"은 일상어라 풀이 없이 그림(관)으로 보여줌. 새 전문용어 없음.

## 동시 표시 점검
- 0.00-13.19: 자막(s1~s4)만 순차 표시 = 각 1개.
- 13.19-13.89: S1 단독 = 1개(s5 자막 시작 전, 무음 A 전환 구간).
- 13.89-14.69: s5 자막 단독 = 1개(S1 이미 퇴장).
- 14.69-17.71: L1 + s5 자막 = 2개.
- 17.71-18.71: s6 자막 단독 = 1개(L1 퇴장 후).
- 18.71-21.02: L2 + s6 자막 = 2개.
- 21.02-25.63: L3 + L4 + s7 자막 = 3개(상한과 정확히 일치, 초과 아님).
- 25.63-30.08: s8 자막 단독 = 1개(라벨 없음, 일상 장면으로 복귀).
- 30.08-31.28: 없음(반전 버튼, 자막·라벨 없음).
- 어느 시점도 상한(3개)을 넘지 않는다(21.02-25.63 구간이 정확히 3개로 최대치).

# c82 사실 확인 - 코끼리가 귀를 펄럭이는 이유

분야: 동물의 몸 구조와 능력. 주제: 더운 날 코끼리가 귀를 펄럭이는 것은 파리 쫓기만이 아니라 체온을 식히는 일이기도 하다.

## 핵심 사실

| # | 사실 | 등급 | 근거 |
|---|---|---|---|
| F1 | 큰 몸은 부피에 비해 피부 면적이 상대적으로 작아 몸속 열이 잘 빠지지 않는다 | A | 표면적 대 부피 관계, 교과서 수준 |
| F2 | 코끼리 귀는 넓고 얇으며 피부 가까이에 혈관이 많다 | A | 코끼리 체온 조절 설명의 표준 내용 |
| F3 | 몸속 열을 실은 피가 귀로 가고, 귀 피부를 지나 열이 공기로 나간다 | A | 열 방출 경로의 표준 설명 |
| F4 | 귀를 펄럭이면 귀 곁의 데워진 공기가 새 공기로 바뀌어 열이 더 빠진다 | A (정성) | 공기 흐름이 열 방출을 늘리는 일반 원리. 얼마나 늘어나는지는 말하지 않음 |
| F5 | 귀에서 식은 피가 몸으로 돌아가 몸이 식는다 | A | 같은 순환 설명 |

## 인과 고리 후보

| 고리 | 등급 | 근거 |
|---|---|---|
| 몸이 커서 열이 잘 안 빠진다 | A | F1. 비교 수치는 쓰지 않고 "큰 몸 = 속에서 피부까지 멀다" 수준으로만 |
| 열을 실은 피가 넓고 얇은 귀로 간다 | A | F2, F3 |
| 얇은 피부를 지나 열이 공기로 나간다 | A | F3 |
| 펄럭이면 공기가 바뀌어 열이 더 빠진다 | A (정성) | F4. "더 빠져요"까지만 |
| 식은 피가 몸으로 돌아가 몸이 식는다 | A | F5 |

## 버린 사실과 이유

- 아프리카코끼리가 아시아코끼리보다 귀가 크다: 새 사실을 추가하는 것(한 편 한 사실 원칙).
- 귀 면적, 귀 온도, 식는 정도 같은 숫자: B등급(출처마다 다름). 숫자 없음.
- 코끼리는 땀샘이 거의 없다: 세부가 출처마다 다름(B). 쓰지 않음.
- 파리를 쫓는 효과의 크기: 의외성에서 "전부가 아니다"까지만 말함. 파리 쫓기도 한다는 것은 사실이라 부정하지 않음.
- 귀로 소리를 듣거나 신호를 보내는 기능, 귀가 커진 진화 경위: 학계 설명이 갈림(C). 쓰지 않음.
- 후보였던 낙타 혹(지방 저장 + 몸 한 곳에 몰린 이유가 B), 카멜레온 색 변화(세부 갈림), 문어 먹물(세부 B): 일상 체감과 그림화가 약해 반려.

## 비유 오류 점검표

| 그림/표현 | 시청자가 받을 인상 | 실제 메커니즘 | 맞는가 |
|---|---|---|---|
| 몸속 투시 + 주황 열 점 | 열이 알갱이처럼 몸속에 있다 | 열은 에너지 이동이고 알갱이가 아님. 점은 "열의 양과 이동"의 표시 | 정성적으로 맞음. 라벨을 "몸속 열"로 하고 점 개수는 "양"의 표시. 숫자 없음 |
| 몸 속 점 5개 -> 3개, s7은 3개 그대로 글로우와 몸 주황 기운만 옅어짐 | 열이 줄어든다 | 열이 귀로 빠지고 식은 피가 돌아와 몸이 식음 | 맞음(정성). 몸속 점은 열의 양, 카드 안 점은 귀를 지나는 열로 서로 다른 표시(04 점 표시 약속) |
| 주황 물결선(비트 3 한 줄, 비트 8 세 줄) | 귀에서 연기·김이 난다 | 열은 눈에 안 보이고 주황은 열의 표시라는 약속(색 약속 표) | 맞음(정성). 연기나 김이 아니라 열 방출의 표시임을 04에 명시 |
| 거리 화살표(몸 가운데에서 왼쪽·위쪽 피부) | 큰 몸은 속에서 피부까지 멀다 | F1: 부피에 비해 피부 면적이 작아 속 열이 잘 안 빠짐 | 맞음(정성). 숫자 없음 |
| 귀 단면 카드: 얇은 피부 밑 혈관 | 피가 피부 밑 가까이 흐른다 | 귀 혈관이 피부 가까이 있음 | 맞음. 피부 두께는 과장해 그림(표지 "귀 단면 확대"에 포함, 숫자 없음) |
| 귀 곁 주황 막(데워진 공기) | 귀에 붙은 공기가 데워져 남는다 | 피부 곁 공기 층이 데워짐 | 맞음(정성) |
| 펄럭이면 막이 밀려나고 새 공기 줄이 들어옴 | 공기가 바뀐다 | 흐르는 공기가 열을 더 가져감 | 맞음. "바뀌어" 수준이며 "완전히 새 공기"를 뜻하지 않음 |
| 점 2개 약 1.0초 -> 점 2개 약 0.40초로 나감 + 주황 막 사라짐 | 펄럭이면 열이 더 빠진다 | 방출량 증가 | 정성적("더"). 몇 배인지 말하지 않음 |
| 말풍선: 파리 -> 귀 + "+" 점선 원 | 파리 쫓기도 이유이고 다른 이유가 더 있다 | 파리를 쫓기도 하고 체온도 식힘 | 맞음. X로 파리를 부정하지 않음 |
| 굼구미가 잎 부채로 흉내 | 굼구미도 시원해진다 | 사람이 부채질하면 공기가 흘러 피부 열이 빠지고 땀도 마름 | 개그 장면이고 원리를 주장하지 않음(내레이션 없음) |

비유 정확도 수준: 내레이션은 "빠져요 / 더 빠져요 / 식어요" 같은 정성적 표현만 쓴다. "딱 맞게 식힌다" 류 표현 없음.

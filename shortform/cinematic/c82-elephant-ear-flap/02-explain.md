# c82 설명 사슬 - 코끼리가 귀를 펄럭이는 이유

## 질문

더운 날 코끼리는 왜 귀를 계속 펄럭일까.

## 의외성

귀 펄럭임은 파리를 쫓는 동작으로 보기 쉽다. 파리를 쫓기도 하지만 그것이 전부가 아니고, 몸의 열을 내보내는 일이다. (s2가 "전부가 아니에요"라고 말로 뒤집는다. 그림은 파리 -> 귀 펄럭 옆에 "+"와 빈 점선 원을 두어 "다른 이유가 더 있다"를 뜻한다. 파리를 X로 지우지 않는다. 이어서 s3이 그 다른 이유(몸속 열)로 시선을 옮긴다.)

## 인과 고리 (내레이션은 narration-ko.json)

| 고리 | 내레이션(ko) | 봐야 하는 그림 | 피해야 할 오해 |

답 1문장: 코끼리는 큰 몸의 열을 피에 실어 얇은 귀로 보내고, 귀를 펄럭여 공기를 바꿔 열을 더 내보낸 뒤 식은 피를 몸으로 돌려보낸다.

## "그래서?" 점검

s1 귀를 펄럭인다 -> 파리 때문인가? s2 전부가 아니다 -> 그럼 뭔가? s3 큰 몸이라 열이 안 빠진다 -> 그래서? s4 열을 실은 피가 귀로 간다 -> 귀에서? s5 얇은 피부로 열이 공기로 나간다 -> 펄럭이는 건? s6 공기가 바뀌어 열이 더 빠진다 -> 그래서? s7 식은 피가 몸으로 돌아가 몸이 식는다. 비약 없음.

연결(이전 결과어가 다음 주어):
- s3 "몸속 열" -> s4 "몸속 열을 실은 피".
- s4 "귀로" -> s5 "얇은 귀 피부". 귀 확대 카드가 s4와 s5 사이 A에서 자람.
- s5 "열이 공기로 나가요" -> s6 "따뜻한 공기가 바뀌어". 주황 막이 두꺼워진 상태에서 시작.
- s6 "열이 더 빠져요" -> s7 "식은 피". 카드를 닫고 몸 단면으로 복귀(s7 시작 직전 되감기: 카드가 귀로 줄어듦).

용어 풀이: 전문용어 없음("혈관" 대신 "피"라고 말함).

## 그림 일관 규칙 (04와 동일)

- 대상: 굼구미 1, 해 1, 파리 1, 코끼리 1(귀 1), 말풍선 1(꼬리 2, 아이콘: 파리 1, 화살표 1, 귀 1, "+" 1, 점선 원 1, 원 안 주황 점 1), 거리 화살표 2, 몸속 열 점 5(s4 후 3, s7도 3개 그대로 글로우만 옅어짐), 혈관: 나가는 줄기 1 + 귀 가지 2, 돌아오는 줄기 1, 흐름 화살표 3(비트 7, 돌아오는 줄기 위), 카드 1(귀 단면 시트 1: 피부 2면 + 혈관관 1), 카드 안 열 점(시작 2 = s4에서 귀에 닿은 2와 같음, s5 나감 2, 비트 5 말미 새로 2 들어와 s6 나감 2), 공기 줄 4, 주황 막 2(위·아래), 잎 1, 주황 물결선 1(비트 3)과 3(비트 8).
- 몸속 점 개수는 열의 양 표시(5 -> 3, s7은 개수 그대로 3). 카드 안 점은 귀를 지나는 열(2 -> 2). 두 곳은 다른 표시임을 04 머리말 "점 표시 약속"에 적음. "더 빠져요"는 같은 개수 2개의 속도(약 1.0초 -> 0.40초)와 주황 막이 사라지는 것으로 보임.
- 주황 물결선은 열의 표시이며 연기·김이 아님(01 점검표).
- 색: 열 주황, 피 빨강, 공기 하늘, 몸·귀 회색.

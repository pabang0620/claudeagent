## 동시 표시 점검 (자막은 해당 구간 t0~t1 동안 표시)
- 0.00-1.26: 없음. 1.26-4.36: L1 + s1 = 2. 4.36-4.76: L1 = 1.
- 4.76-5.16: L2 = 1 (L1 퇴장과 L2 팝인이 같은 순간). 5.16-6.76: L2 + s2 = 2. 6.76-7.97: s2 = 1. 7.97-8.37: 없음.
- 8.37-8.77: S1 = 1. 8.77-9.03: S1 + s3 = 2. 9.03-10.53: S1 + L3 + s3 = 3. 10.53-12.03: S1 + L4 + s3 = 3 (L3 퇴장과 L4 팝인이 같은 순간). 12.03-12.46: S1 + s3 = 2. 12.46-13.26: S1 = 1.
- 13.26-14.40: S1 + s4 = 2. 14.40-15.90: S1 + L5 + s4 = 3. 15.90-16.07: S1 + s4 = 2. 16.07-16.87: S1 = 1.
- 16.87-18.56: S1 + s5 = 2. 18.56-20.06: S1 + L6 + s5 = 3. 20.06-20.34: S1 + s5 = 2. 20.34-21.14: S1 = 1.
- 21.14-24.28: S1 + s6 = 2. 24.28-25.08: S1 = 1. 25.08-28.55: S1 + s7 = 2. 28.55-28.95: S1 = 1.
- 28.95-29.35: 없음. 29.35-30.49: s8 = 1. 30.49-33.04: S2 + s8 = 2. 33.04-34.44: 없음.
- V4 강조 자막(emph)은 구간 자막의 해당 어절을 키우고 색을 바꾸는 방식이며 별도 글자 요소가 아니다. 위 동시 개수에 더하지 않는다.
- 어느 시점도 3개를 넘지 않는다.

## 라벨 규칙 점검
- 라벨 6자 이내(공백 포함): 식빵 2, 물 1, 녹말 2, 열 1, 누르는 힘 5, 붙은 자리 4. 표지 10자 이내: 확대·과장해 그림 9, 과장해 그림 6.
- 노출 1.5초 이상: L1 3.50, L2 2.00, S1 20.58, L3 1.50, L4 1.50, L5 1.50, L6 1.50, S2 2.55. 전부 충족.
- 라벨은 대상이 처음 그려진 뒤 1초 안에 팝인: L1 비닐 0.80 등장에서 1.26(0.46초), L2 풍선 4.76 등장과 동시, L3 알갱이 8.77에서 9.03(0.26초), L4 주황 화살표 9.55에서 10.53(0.98초), L5 회갈색 화살표 14.30에서 14.40(0.10초), L6 초록 막대 18.56 등장과 동시, S2 겹침 알갱이 30.49 등장과 동시.
- **라벨·그림이 어절 시각에 시작하지 않는다**: L1 s1@"식빵도"(1.66)-0.40, L2 s2.t0(5.16)-0.40, L3 s3@"녹말은"(9.43)-0.40, L5 s4@"말랑해요"(14.80)-0.40, L6 s5@"달라붙어요"(18.96)-0.40, S2 s8@"녹말이"(30.89)-0.40. L4는 s3@"구울"(9.87)보다 앞선 9.55에 그려진 주황 화살표를 가리키며 바로 앞 라벨이 물러나는 10.53에 뜬다. 비트 끝에 몰아서 띄운 라벨 없음.
- 한 윤곽에 이름 두 개 금지: "식빵"(훅의 비닐 속 식빵 전체), "녹말"(둥근 알갱이), "열"(주황 화살표), "누르는 힘"(회갈색 화살표), "붙은 자리"(초록 막대)는 서로 다른 대상이다. 빵 조각(도식 속 단면)은 이미 "식빵"으로 불렸으므로 새 이름을 붙이지 않는다.
- 레이아웃 간격: 칩끼리 20px 이상(S1 y 340-410과 칩 y 470 시작 사이 60px). 칩과 패널 위 테두리(y 441) 29px 이상(칩 y 470 시작). L2 칩 y 440-510은 패널 밖(훅·비트2 장면)이고 풍선 위 560과 50px, 창문 y 200-420과 20px. L4 칩 y 1065-1135는 패널 아래 1037과 28px이고 자막 띠(y 1267 이상)와 130px 이상. 굼구미(도식 장면 x 16%, 발 y 1235, 키 173px, 위 1062)와 L4 칩 x 560 사이 300px.

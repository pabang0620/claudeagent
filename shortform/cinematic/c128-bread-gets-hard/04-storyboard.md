# 굼구미 시네마틱 c128 - 식빵이 시간이 지나면 딱딱해지는 이유 (9:16)

Canvas 1080x1920 (9:16), 30fps 출력, 그림은 on twos(2프레임마다 갱신), 휙 지나가는 순간(줌 인·되감기, 반전 폴짝)만 on ones. 본편만 다룬다 - 브랜드 인트로·제목카드·아웃트로는 엔진이 붙인다. 제목카드가 주제를 보여주므로 본편에서 주제 자막을 다시 띄우지 않는다.

예상 본편 길이 **약 34.44초**(구간 길이 = 글자수x0.11+0.72에 gap 포함, 비트9 1.40초). 실제 TTS는 이보다 짧을 수 있고 앵커 기준으로 만든다. 내레이션 8구간, 비트 9개. 설명 사슬은 의외성 1(s2) + 인과 고리 4(s3+s4, s5, s6, s7) + 답(s8).

V4 강조 자막(emph)은 구간 자막의 해당 어절을 키우는 방식이라 별도 글자 요소가 아니다(동시 글자 3개 상한에 더하지 않는다). emph는 narration-ko.json에 구간마다 1~2개 있고 부정문 s2는 "아니에요"를 강조한다.

굼구미: 흰 몸, 잉크 `#252E3A`, 코랄 볼 `#FC876E`. 머리카락·옷·코·귀·손가락 묘사 없음. 굼구미는 부엌 장면에서 식빵을 누르고 두드리는 실험자이며(일상 장면), 도식 장면에서는 패널 아래 왼쪽에서 가리키기만 하는 안내자다. 도식 속 알갱이·화살표·빵 조각에 손대지 않는다. 도식 장면의 굼구미는 y 1250(65%) 아래, x 85% 이후에 들어가지 않고 모든 표시와 20px 이상 떨어진다. 불꽃·칼·전열기구는 그리지 않고 열은 주황 화살표로만 표현한다(따라 하면 위험한 장면 없음).

## 과장 명시 (비트3~8)

녹말 알갱이는 실제로 눈에 안 보이는 아주 작은 알갱이인데 지름 64~100으로 크게, 개수는 6개로 적게 그렸고 알갱이가 통째로 움직여 모이는 것은 개념 표시다. 그래서 도식 구간(8.37부터 28.95까지)은 S1 "확대·과장해 그림"을 계속 띄운다. 비트8에서 식빵 속에 겹쳐 그린 알갱이(지름 60)도 실제보다 훨씬 크므로 S2 "과장해 그림"을 30.49부터 33.04까지 띄운다.

## 공간 설계

- **부엌 장면(비트1·2·8·9)**: 벽 y 0-1000, 바닥 y 1000 아래. 조리대 x 340-960, y 770-1000 위에 식빵 비닐. 굼구미는 왼쪽(중심 x 216, 발 y 1180, 키 250, 몸 오른쪽 끝 약 316)으로 조리대 왼끝 340과 24px, 모든 표시와 20px 이상. 라벨 칩은 y 440-540 대에 두고 자막 띠(y 1250 이하)에 칩·그림이 없다.
- **도식 장면(비트3~7)**: 부엌이 `#14233A`로 어두워지고 비닐 속 식빵에서 패널(x 65-900, y 441-1037)이 자라 나온다. 굼구미는 패널 아래 왼쪽(x 16%, 발 y 1235, 키 173px, 위 1062, 패널 아래 1037과 25px)에서 가리킨다.
- 도식은 식빵에서 자라 나오고, 비트8에서 되감기로 같은 식빵으로 줄어든다.

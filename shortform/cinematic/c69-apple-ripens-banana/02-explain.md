# c69 설명 사슬 - 사과 옆에 두면 바나나가 빨리 익는 이유

## 질문

사과 옆에 둔 초록 바나나는 왜 혼자 둔 것보다 더 빨리 노랗게 익을까.

## 의외성

과일은 제각각 혼자 익는다고 믿기 쉽다. 그런데 옆 과일이 내뿜는 기체가 바나나가 익는 속도를 바꾼다. (훅 s1이 두 바나나의 색 차이로 먼저 보여주고, s2의 생각 풍선과 X가 "혼자 익는다"는 믿음을 지운다.)

답 1문장: 사과가 내뿜는 에틸렌 기체가 공기로 퍼져 옆 바나나에 닿으면, 껍질의 초록빛이 줄고 원래 있던 노랑이 드러나 바나나가 더 빨리 익는다.

## "그래서?" 점검

사과 옆 바나나가 더 빨리 익는다(s1) -> 과일은 혼자 익지 않나? 그렇게 믿기 쉽지만 풍선과 X로 지운다(s2) -> 그럼 무엇이 영향을 주나? 확대하면 사과가 에틸렌 기체를 내뿜는다(s3) -> 그게 바나나에 어떻게 닿나? 공기로 퍼져 닿고 익으라는 신호가 된다(s4) -> 그래서 바나나는? 껍질 속 초록빛이 줄어든다(s5) -> 그러면 색은? 껍질에 있던 노랑이 드러난다(s6) -> 결론은? 사과의 에틸렌 덕에 더 빨리 익는다(s7). 비약 없음.

중간 단계 확인:
- s1에서 s2: s1은 "더 빨리 익어요"로 닫고, s2 "과일은 ... 익는다고"가 "익다"를 받아 "혼자가 아니다"로 뒤집는다.
- s2에서 s3: s2는 "믿기 쉬워요"로 닫고 s3 "하지만 확대하면"이 반박한다. 진입 A 비트에서 점선 고리와 카드가 "사과와 바나나 사이 공기를 확대했다"를 잇는다.
- s3에서 s4: s3 결과어 "에틸렌 기체"를 s4 주어 "에틸렌은"으로 받는다.
- s4에서 s5: s4 결과어 "알려요(신호)"를 s5 "신호를 받은"으로 받는다.
- s5에서 s6: s5 결과어 "초록빛이 줄어요"를 s6 "초록빛이 줄면"으로 받는다.
- s6에서 s7: s6 결과어 "노랑이 드러나요"를 s7 "노래진 바나나는"으로 받고, 도식에서 실제 장면으로 돌아와 사과와 바나나를 잇는다.
- 조건: 바나나가 "초록"(s1), 사과가 "옆"(s1, s4). 반전도 연두 바나나 옆에 사과를 놓는다.

# 설명 사슬 - 바나나에 씨가 없는 이유 (본편 약 44.4초)

## 질문
바나나를 잘라보면 왜 씨 없이 작은 검은 점만 줄지어 있을까. (제목카드가 이미 주제를 보여주므로 본편 내레이션은 다시 묻지 않는다. 첫 문장은 장면 묘사로 시작한다.)

## 의외성
지금 먹는 바나나는 처음부터 씨가 없었던 게 아니다. 바나나의 조상격인 야생 바나나는 원래 크고 단단한 씨로 가득한 과일이었다. 이 반전을 훅 장면 직후 두 비트(단면의 검은 점을 관찰 s1 -> 사실 씨앗이 되려다 만 흔적이라는 반전 s2 -> 야생 바나나는 원래 씨로 가득했다는 대비 s3)로 나눠 보여준다. **훅 비트(s1) 자체에는 설명·비교를 넣지 않는다** - 훅은 설명 없는 일상 장면 설정 전용이다.

## 인과 고리 (4개)

**고리1 (염색체가 한 벌 더 많음)**: 우리가 먹는 바나나 품종은 염색체를 정상보다 한 벌 더 가진 품종이다.
- 내레이션 ko: "먹는 바나나는 염색체가 원래보다 한 벌 더 많아요."
- 내레이션 en: "The bananas we eat have one extra set of chromosomes than normal."
- 봐야 하는 그림: 짙은 남색 도식 안 세포 하나. 이미 짝지어진(골드 글로우) 염색체 막대 2벌 옆에 3번째 막대 묶음이 새로 자라나 완성되는 모습. 라벨 "염색체", 숫자 라벨 "3벌"
- 피해야 할 오해: 정확한 염색체 개수(22, 33 등)를 화면 숫자로 보여주지 않는다. "한 벌 더 많다"는 배수 관계만 보여준다

그래서? -> 염색체가 한 벌 더 있으면 씨를 만드는 데 구체적으로 뭐가 문제인가.

**고리2 (짝짓기 실패)**: 씨앗을 만들려면 염색체가 둘씩 짝을 지어 나뉘어야 하는데, 세 벌(홀수)이면 꼭 하나가 남는다.
- 내레이션 ko: "씨를 만들려면 염색체가 둘씩 짝을 지어야 해요." / "근데 홀수라서 꼭 하나가 남아요."
- 내레이션 en: "To make a seed, chromosomes need to pair up two by two." / "But since it's an odd number, one always gets left out."
- 봐야 하는 그림: 기존 2벌 막대가 서로 다가와 맞물려 골드 브래킷이 생기는 모습, 이어서 3번째 막대가 짝을 못 찾고 회청색으로 흐려지며 홀로 남는 모습(짝지어진 둘과 대비). 라벨 "홀로 남음"
- 피해야 할 오해: 굼구미가 손으로 염색체를 직접 짝지어주면 안 된다. 굼구미는 가리키고 대비를 안내할 뿐, 짝짓기·실패는 염색체 스스로 일어난다

그래서? -> 짝을 못 지은 염색체가 하나 남으면 결과적으로 씨앗은 어떻게 되는가.

**고리3 (흔적만 남음)**: 그래서 정상적인 씨를 만들지 못하고, 그 자리에 작게 퇴화한 흔적만 남는다.
- 내레이션 ko: "그래서 정상 씨 대신 흔적만 남아요."
- 내레이션 en: "So instead of a real seed, only a trace is left behind."
- 봐야 하는 그림: 세포 도식이 축소되며 바나나 단면 속 작은 검은 점 크기로 빨려 들어가듯 완성되는 모습 (비트2의 검은 점과 시각적으로 연결)
- 피해야 할 오해: 이 흔적이 "독성이 있다"거나 "먹으면 안 된다"는 인상을 주지 않는다. 단순히 발달이 멈춘 자리라는 것만 보여준다

그래서? -> 씨로 못 퍼뜨리는 바나나는 그럼 어떻게 번식하고 있는가.

**고리4 (뿌리 새싹으로 번식)**: 씨로 번식할 수 없으니, 뿌리에서 올라온 새싹을 잘라다 심는 방식으로 번식시킨다.
- 내레이션 ko: "씨 대신 뿌리에서 난 새싹을 잘라 심어요."
- 내레이션 en: "Instead of seeds, a shoot from the roots gets cut and replanted."
- 봐야 하는 그림: 밭 장면. 바나나 나무 밑동 뿌리 옆에 돋아난 새싹을 굼구미가 모종삽으로 캐내 옆 화분에 옮겨 심는 모습. 라벨 "새싹"
- 피해야 할 오해: 이 장면은 실제 농법을 재연하는 것이지 굼구미가 생물학적 원인을 대신 만들어내는 것이 아니다(실제로 사람이 흡지를 잘라 심는 방식으로 바나나를 재배한다)

## 답 (1문장)
우리가 먹는 바나나는 염색체가 한 벌 더 많아 정상적인 씨를 만들지 못하고, 대신 뿌리 새싹을 잘라 심어 번식시키기 때문에 지금 흔히 먹는 바나나는 유전적으로 거의 같은 복제품이다.

## 복귀·답 내레이션
설명이 끝난 뒤 다시 밭 장면에서 방금 심은 나무 여러 그루가 모두 같은 유전자를 가졌음을 보여준 다음, 처음 부엌 장면으로 돌아와 마지막 문장으로 답을 확정한다.
- 복귀 ko: "그렇게 자란 바나나는 다 같은 유전자예요."
- 복귀 en: "Every banana grown that way shares the same genes."
- 최종 답 ko: "그래서 지금 바나나는 거의 다 복제품이에요."
- 최종 답 en: "So the bananas we eat today are basically all clones."

## 전체 사슬 통독 점검 ("그래서?" 릴레이)
장면(굼구미가 바나나를 까서 베어 물고 단면을 보여줌, s1) -> 그래서? 그런데 속에 작은 까만 점들이 줄지어 있다(관찰, s1 내) -> 그래서? 사실 이 점은 씨앗이 되려다 만 흔적이다(반전, s2) -> 그래서? 야생 바나나는 원래 딱딱한 씨로 가득했다(대비, s3) -> 그래서? 먹는 바나나는 염색체가 한 벌 더 많은 품종이다(고리1, s4) -> 그래서? 씨를 만들려면 둘씩 짝을 지어야 하는데 홀수라 하나가 남는다(고리2, s5·s6) -> 그래서? 정상 씨 대신 흔적만 남는다(고리3, s7) -> 그래서? 씨 대신 뿌리 새싹을 잘라 심어 번식시킨다(고리4, s8) -> 그래서? 그렇게 자란 나무들은 다 같은 유전자다(복귀, s9) -> 그래서? 지금 바나나는 거의 다 복제품이다(답, s10). 비약 없이 전부 이어진다.

## 내레이션 대본 규칙 점검 (channel profile 3절)
- 첫 문장(s1, "바나나 속에 작은 까만 점들이 줄지어 있어요")은 장면 묘사이며 질문형이 아니다.
- 전문용어는 "염색체" 하나뿐이고, 등장하는 자리(비트5)에서 세포 도식과 라벨("염색체")로 곧바로 시각적으로 풀어준다. 한 편에 풀이가 필요한 용어 2개 이하 원칙에 부합.
- 숫자를 읽지 않는다. "세 벌"·"삼배체"라는 구체적 수치 표현을 내레이션에 쓰지 않고 "한 벌 더 많아요", "홀수라서 하나가 남아요"처럼 정성적으로만 말한다. 정확한 배수(3벌)는 화면 숫자 라벨(N1)이 담당한다.
- 마지막 문장(s10, "그래서 지금 바나나는 거의 다 복제품이에요")은 핵심 사실이며 교훈을 덧붙이지 않는다.
- 각 구간 한국어 30자 이내(가장 긴 구간 28자, s4).

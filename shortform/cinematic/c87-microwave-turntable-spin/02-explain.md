# c87 02-explain - 전자레인지 속 접시가 도는 이유

## 질문
전자레인지 속 접시는 왜 계속 돌까.

## 의외성
열을 주는 전파가 음식에 고르게 닿을 것 같지만 그렇지 않다. 전파가 센 자리와 약한 자리가 안쪽에 고정돼 있다. (A)

## 인과 고리 (4개)

| 고리 | 내레이션 id | 내용 |
|---|---|---|
| 1 | s3, s4 | 전파가 금속 벽에 튕겨 겹치고, 겹친 자리마다 전파가 센 곳과 약한 곳이 생긴다(그림에서 겹친 마디가 센/약한 원으로 변함) |
| 2 | s5, s6 | 센 곳 음식은 속 물이 흔들려 열이 나고, 약한 곳은 덜 흔들려 덜 데워진다 |
| 3 | s7 | 접시가 돌아도 센 곳과 약한 곳은 그대로(자리 고정)이고, 음식이 두 곳을 번갈아 지난다 |
| 4 | s8, s9 | 안 돌면 같은 곳이 계속 덜 데워지고, 그래서 접시는 더 고르게 데우려고 돈다 |

그래서? 점검:
- 전파가 벽에 튕겨 겹친다 -> 그래서? 겹침 때문에 센 곳과 약한 곳이 생긴다(s4가 "겹쳐서"로 이어 받음).
- 센 곳과 약한 곳이 있다 -> 그래서? 센 곳 음식은 많이 데워지고 약한 곳은 덜 데워진다(s5, s6가 "센 곳/약한 곳"을 이어 받음).
- 자리마다 데워짐이 다르다 -> 그래서? 음식이 자리를 바꾸면 평균이 맞는다(s7).
- 자리를 안 바꾸면 -> 같은 곳이 계속 덜 데워진다(s8) -> 그래서 돈다(s9). 비약 없음.

## 답 1문장
접시는 음식이 전파의 센 곳과 약한 곳을 번갈아 지나게 해 더 고르게 데우려고 돈다.

## 고리별 내레이션 / 그림 / 오해

| id | 내레이션(ko) | 봐야 하는 그림 | 피해야 할 오해 |
|---|---|---|---|
| s1 | 전자레인지 속 접시가 빙글빙글 돌아요. | 전자레인지 창 안에서 밥그릇이 도는 일상 장면 | 설명 도식을 넣지 않음 |
| s2 | 열 주는 전파가 음식에 고르게 닿는 게 아니에요. | 위에서 본 단면 카드, 전파 호가 나오고 균일한 보라 막 위에 X | 전파가 "열"이라는 인상(전파가 열을 준다는 뜻으로만) |
| s3 | 전파는 금속 벽에 튕겨 겹쳐요. | 벽 라벨, 나간 호와 돌아온 호가 만나 겹친 자리 7곳에 마디가 생김(3곳 진함, 4곳 연함) | 접시가 튕긴다는 오해(튕기는 건 전파) |
| s4 | 겹쳐서 전파가 센 곳과 약한 곳이 생겨요. | 진한 마디가 보라 채운 원(센 곳)으로, 연한 마디가 옅은 점선 원(약한 곳)으로 같은 자리에서 변함 | 센 곳이 움직인다는 오해(고정) |
| s5 | 센 곳의 음식 속 물이 흔들려 열이 나요. | 센 곳에서 확대 렌즈: 물 분자가 세게 흔들리고 주황 열 | 전파가 음식 속까지 다 데운다는 오해(흔들려 열이 나는 원리만) |
| s6 | 약한 곳은 물이 조금만 흔들려 덜 데워져요. | 약한 곳 렌즈를 옆에 나란히: 물 분자가 조금 흔들리고 하늘색 | 얼음처럼 차갑다는 오해("덜 데워져요") |
| s7 | 돌면 두 곳은 그대로, 음식이 번갈아 지나요. | 접시가 돌 때 센/약한 원은 제자리에서 한 번 맥박, 라벨 "음식 조각" 붙은 초록 핀이 번갈아 지남 | 센/약한 자리가 접시와 함께 돈다는 오해(자리는 말로도 "그대로") |
| s8 | 안 돌면 같은 곳이 계속 덜 데워져요. | 멈춘 접시에 주황과 하늘색 얼룩이 생김 | 완전히 안 데워진다는 오해 |
| s9 | 그래서 접시는 더 고르게 데우려고 돌아요. | 안 돌 때와 돌 때 나란히, 돌 때는 주황 띠가 둘레로 고름 | "완벽히 고르다"는 오해(더 고르게) |

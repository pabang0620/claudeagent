# c103 화면 글자 (내레이션 자막 제외 - 자동 표시)

한 화면 동시 최대: 내레이션 자막 1 + 라벨/표지 2 (퇴장·팝인 겹침 포함). V4 강조 자막은 내레이션 자막과 같은 줄(자막 띠)에서 튀므로 자막 1개로 센다. 제목은 제목카드가 보여주므로 본편에서 다시 띄우지 않는다.

시각은 narration-ko.json 기준 예상 절대 초(글자수x0.11 + gap, 검토용). 애니메이터는 앵커를 쓴다.

내레이션 구간(예상): s1 1.20-3.62 / s2 4.32-6.08 / s3 7.08-9.83 / s4 10.33-12.86 / s5 13.76-16.84 / s6 17.74-20.71 / s7 21.41-24.05 / s8 24.95-28.14.

라벨 칩 폭은 글자수x54+40px, 높이 약 70px. 지시선은 칩 끝에서 대상의 해당 부위로.

패널 의미 표시: 두 눈 시점 패널은 S3 "눈에 비친 풍경"(b6 첫 1.56초)이 "비둘기 눈에 비친 풍경"임을 알린다. 이후 L4, L5는 그 패널의 상태 이름이다.

## 동시 표시 점검
- 0-1.20 없음. 1.20-3.62 s1=1. 4.32-6.08 s2=1.
- 7.08-9.40 s3=1. 9.40-9.83 L1+s3=2. 9.83-10.33 L1=1. 10.33-10.55 L1+s4=2. 10.55-11.00 L1+L2+s4=3(상한). 11.00-12.40 L2+s4=2. 12.40-12.86 s4=1.
- 13.46-13.76 S1=1. 13.76-15.00 S1+s5=2. 15.00-15.30 s5=1. 15.30-16.84 L3+s5=2. 16.84-17.30 L3=1.
- 17.44-17.64 S3=1. 17.64-17.74 S3+L4=2. 17.74-19.00 S3+L4+s6=3(상한). 19.00-19.28 L4+s6=2. 19.28-20.71 L4+S2+s6=3(상한). 20.71-21.40 L4+S2=2. 21.40-21.41 L4. 
- 21.41-21.85 L4+s7=2 (S2는 21.40 퇴장). 21.85-23.90 L4+L5+s7=3(상한, s7은 24.05까지). 23.90-24.05 s7=1.
- 24.95-28.14 s8=1. 어느 시점도 3개 초과 없음.

## 라벨 규칙 점검
- 라벨 6자 이내: 머리 멈춤 4, 몸 이동 4, 눈동자 3, 움직일 때 5, 멈출 때 4. 표지 10자 이내: 눈 확대 4, 눈에 비친 풍경 8, 과장해 그림 6.
- 노출 1.5초 이상: L1 1.60, L2 1.85, S1 1.54, L3 2.00, S3 1.56, L4 6.26, S2 2.12, L5 2.05. 충족.
- 라벨은 대상이 그려진 뒤 1초 안에 팝인: L4는 패널 열림(17.34) +0.30, S3 +0.10, L3는 확대 원이 자란 뒤(14.2) 1.1초 뒤지만 "눈동자를" 발음 시점이며 S1이 같은 대상을 먼저 알림.
- 라벨은 가리키는 말이 발음되는 순간 팝인: L1 "멈춰요", L2 "몸이", L3 "눈동자를", L5 "멈추면", S2 "움직이면". L4는 패널이 열린 직후(패널 이름 역할, 해당 어절 "움직이면"은 19.28이며 그때 S2가 같이 뜸).
- 한 윤곽 이름 하나: 머리(L1), 몸(L2), 눈동자(L3), 패널(S3 + L4/L5는 상태).
- 자막 띠(y 1250 이하)에 칩 없음.

## 숫자(N)
화면 숫자 없음. 걸음 속도, 정지 시간 같은 수치는 B등급이라 쓰지 않는다.

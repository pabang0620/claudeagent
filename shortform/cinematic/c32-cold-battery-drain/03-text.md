# c32 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("겨울에 휴대폰 배터리가 빨리 닳는 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

| id | 종류 | 등장~퇴장(예상 초) | ko | en | 위치 |
|---|---|---|---|---|---|
| S1 | 스케일 표지 (D.scaleBadge) | 12.70-14.20 | 배터리 속 확대 | Zoom into battery | 그림 무대 위쪽 |
| L1 | 라벨 | 16.80-19.80 | 이온 | Ion | 이온 알갱이 옆, 지시선 |
| L2 | 라벨 | 25.80-27.30 | 느려짐 | Slower | 느려진 이온 옆, 지시선 |
| L3 | 라벨 (용어 콜아웃) | 32.50-35.07 | 점성 | Viscosity | 액체 도식 아래 중앙, 강조 박스 |
| L4 | 라벨 | 29.90-31.40 | 약해짐 | Weaker | 전류 화살표 옆, 지시선 |

## 동시 표시 점검
- 12.10-12.70: s4 자막 단독 = 1개(S1 등장 전).
- 12.70-14.20: S1 + s4 자막 = 2개.
- 14.20-15.48: s4 자막 단독 = 1개(S1 페이드 아웃 후).
- 15.48-15.98: 없음(고리1 등장 전 간격).
- 15.98-16.80: s5 자막 단독 = 1개(L1 등장 전).
- 16.80-19.80: L1 + s5 자막 = 2개.
- 19.80-20.06: s5 자막 단독 = 1개(L1 페이드 아웃 후, 구간 종료 직전).
- 20.06-23.50: s6 자막 단독 = 1개(라벨 없음 - 액체가 뻑뻑해지는 변화는 시각 자체로 표현).
- 23.50-25.80: s7 자막 단독 = 1개(L2 등장 전).
- 25.80-26.94: L2 + s7 자막 = 2개.
- 26.94-27.30: L2 단독 = 1개(s7 자막 종료 후 짧은 꼬리, s8 시작 전).
- 27.30-29.90: s8 자막 단독 = 1개(L4 등장 전).
- 29.90-30.38: L4 + s8 자막 = 2개.
- 30.38-31.40: L4 + s9 자막 = 2개(비트 경계를 살짝 넘어 hold).
- 31.40-32.50: s9 자막 단독 = 1개(L4 페이드 아웃 후, L3 등장 전).
- 32.50-34.57: L3 + s9 자막 = 2개.
- 34.57-35.07: L3 단독 = 1개(s9 자막 종료 후, s10 시작 전 짧은 꼬리).
- 35.07-38.76: s10 자막 단독 = 1개(라벨 없음, 회복 장면).
- 38.76-43.44: s11 자막 단독 = 1개(라벨 없음, 답 정리).
- 43.44-44.24: 없음(반전 코다, 자막·라벨 없음).
- 어느 시점도 상한(3개)을 넘지 않으며, 실제로는 최대 2개만 동시에 뜬다.

## 숫자(N)
화면 숫자 없음. `01-fact.md`의 A등급이더라도 기기·배터리마다 다른 정확한 % 하락 수치·임계 온도는 화면에 쓰지 않는다. 배터리 게이지는 색(초록↔빨강) 채움 비율로만 표현하고 숫자를 표시하지 않는다.

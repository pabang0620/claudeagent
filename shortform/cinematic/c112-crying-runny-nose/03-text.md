# c112 화면 글자 (내레이션 자막 제외 - 자동 표시)

한 화면 동시 최대: 내레이션 자막 1 + 라벨/표지 2. 제목은 브랜드 제목카드가 보여주므로 본편에서 주제 자막을 다시 띄우지 않는다.

시각은 `narration-ko.json` 기준 예상 절대 초(구간 글자수x0.11+0.72, 어절은 구간 시작 + 첫 글자 순번x0.11)다. 애니메이터는 앵커를 쓴다. 팝인 연출은 "어절 0.4초 전 시작, 어절 순간에 완전히 자리 잡음"이다.

내레이션 구간 시각(예상): s1 1.00-4.03 / s2 5.03-7.95 / s3 8.65-12.12 / s4 12.82-16.40 / s5 17.10-20.79 / s6 21.49-24.85 / s7 25.75-29.33.

라벨 칩 폭은 공백 포함 글자수x54+40px, 높이 70px. 지시선은 칩 끝에서 대상의 해당 부위로. 칩은 얼굴 단면의 해부 윤곽 위에 올리지 않는다(카드 왼쪽 빈 영역 x 85-287, 또는 단면 오른쪽 흐려진 영역 x 540 이후). 지시선만 윤곽을 지날 수 있다. 좌표는 04-storyboard "크기 기준"과 같다(카드 x 65-886, y 440-1030).

## 동시 표시 점검 (자막은 해당 구간 t0~t1 동안 표시)
- 0.00-1.00: 없음. 1.00-4.03: s1 = 1. 4.03-4.13: 없음.
- 4.13-5.03: S1 = 1. 5.03-5.07: S1 + s2 = 2. 5.07-5.63: S1 + L1 + s2 = 3 (상한). 5.63-6.28: L1 + s2 = 2. 6.28-7.57: L1 + L2 + s2 = 3 (상한). 7.57-7.95: L2 + s2 = 2. 7.95-8.28: L2 = 1. 8.28-8.65: 없음.
- 8.65-9.68: s3 = 1. 9.68-10.12: S3 + s3 = 2. 10.12-11.68: S3 + L3 + s3 = 3 (상한). 11.68-12.12: L3 + s3 = 2.
- 12.82-13.08: s4 = 1. 13.08-13.41: S3 + s4 = 2. 13.41-14.58: S3 + L4 + s4 = 3 (상한). 14.58-15.51: L4 + s4 = 2. 15.51-16.40: s4 = 1.
- 16.70-17.10: S2 = 1. 17.10-17.47: S2 + s5 = 2. 17.47-19.00: S2 + L5 + s5 = 3 (상한). 19.00-19.67: L5 + s5 = 2. 19.67-20.79: s5 = 1.
- 21.49-22.52: s6 = 1. 22.52-24.72: L6 + s6 = 2. 24.72-24.85: s6 = 1.
- 25.75-29.33: s7 = 1 (라벨 없음).
- 29.33-30.33: 없음.
- V4 강조 자막(emph)은 구간 자막의 해당 어절을 키우는 방식이라 별도 글자 요소가 아니다. 위 개수에 더하지 않는다.
- 어느 시점도 3개를 넘지 않는다.

## 라벨 규칙 점검
- 라벨 6자 이내(공백 포함): 콧속 2, 눈 1, 눈물점 3, 눈물관 3, 눈물 많음 5, 콧물 2. 표지 10자 이내: 사람 얼굴 단면 7, 과장해 그림 6, 점선은 평소 6.
- 노출 1.5초 이상: S1 1.50, L1 2.50, L2 2.00, S3 ① 2.00 ② 1.50, L3 2.00, L4 2.10, S2 2.30, L5 2.20, L6 2.20.
- **대상이 처음 그려진 뒤 1초 안에 팝인**: L1 콧속 점막 강조 5.07과 동시. **L2 눈은 b3에서 눈 없이 얼굴 윤곽만 그려 두고 6.28에 눈(흰자·눈동자·눈꺼풀)이 처음 그려지는 순간 L2가 같이 팝인한다**(처음 그려진 시각과 동일). L3 눈물점은 9.68 그려지고 10.12(0.44초). L4 관은 13.08 그리기 시작, 13.41(0.33초). L5 고인 눈물은 17.03 시작, 17.47. L6 방울은 22.52 맺힘과 동시.
- 가리키는 단어가 발음되는 순간 완전히 자리 잡음: L1 "코에서만"(5.47), L2 "아니에요"(6.68), L3 "구멍이"(10.52), L4 "관을"(13.81), L5 "많아서"(17.87), L6 "콧물과"(22.92). 눈이 단서로 밝아지는 6.28-6.68과 라벨이 일치한다.
- 한 윤곽에 이름 두 개 금지: 눈, 눈물점(눈 안쪽 가장자리의 구멍), 눈물관, 콧속은 서로 다른 윤곽이다.
- 레이아웃: 칩끼리 20px 이상(동시 노출 조합 L1+L2는 y 간격 182px에 좌우 영역도 달라 겹치지 않음). 칩과 카드 테두리(x 65-886) 20px 이상: L5 오른쪽 끝 850(36px), L3/L4/L6 왼쪽 끝 85(20px). 칩과 얼굴 윤곽 20px 이상: L3/L4 오른쪽 끝 287과 윤곽(y 600-770에서 x 345-308)은 최소 21px, L6 오른쪽 끝 233과 윤곽(y 910-980에서 x 약 305)은 72px. 칩과 굼구미(위 1062) 20px 이상(L6 아래 980, 82px), 자막 띠(y 1250 이하)에 칩 없음.

# c134 설명 사슬 - 산에서 소리치면 메아리가 돌아오는 이유

## 질문
맞은편 산에 대고 "야호" 하면 왜 잠시 뒤 같은 소리가 돌아올까.

## 의외성
"산이 대답해 준다"고 느끼기 쉽다. 실제로는 산이 소리를 내는 게 아니라, 내가 낸 소리가 산에 부딪혀 되돌아오는 것이다.

## 인과 고리 (4개)

| 고리 | 내레이션 (ko) | 봐야 하는 그림 | 피해야 할 오해 |
|---|---|---|---|
| 훅 s1 | 맞은편 산을 보고 야호 하고 외쳐요. | 계곡 건너편 산 절벽을 보고 선 굼구미가 외친다. 청록 소리 물결 2줄이 입에서 산 쪽으로 나간다. 설명 없음 | - |
| 훅 s2 | 잠시 뒤 같은 야호가 돌아왔어요. | 산 절벽에서 연보라 물결 2줄이 갈수록 옅어지며 돌아와 굼구미에게 닿는다(닿는 순간은 s2 시작 직전 무음). 굼구미가 깜짝 놀람 | - |
| 의외성 s3 | 산이 대답해 주는 게 아니에요. | 생각 풍선 속 입 달린 산 아이콘에 X | 산이 스스로 소리를 낸다는 통념 |
| 1 s4 | 내 목소리는 공기를 타고 사방으로 퍼져요. | 도식 패널에 공기 점(라벨 "공기") 7개가 옅게 떠 있고, 얼굴 아이콘 입에서 청록 원호가 사방으로 퍼지며 지나가는 공기 점을 흔듦. 가장자리는 옅어짐 | 소리가 한 방향 직선으로만 간다는 인상 |
| 2 s5 | 단단한 산에 부딪혀 되튕겨요. | 오른쪽에 단단한 벽(산)이 솟아오름. 청록 원호가 벽 면에 닿는 순간 벽 면에서 연보라 원호가 왼쪽으로 나옴 | 소리가 벽을 통과한다는 인상, 벽이 새 소리를 낸다는 인상 |
| 3 s6 | 되튕긴 소리가 내게 돌아와요. | 연보라 원호가 왼쪽으로 가서 얼굴 아이콘에 닿는 순간 아이콘이 깜짝 놀람 | 다른 소리가 온다는 인상(색이 다른 것은 방향 구분일 뿐) |
| 4 s7 | 소리는 빛보다 느려서 갔다 오는 데 시간이 걸려요. | 같은 출발 눈금에서 노란 빛 줄이 한 프레임에 끝까지 닿고, 흰 막대(소리)는 한참 자라 연보라 눈금에 도착. 비교 기준이 빛이고 막대가 "걸린 시간" | 돌아온 소리가 새로 생겨 늦는다는 인상(생기는 때가 아니라 오는 데 걸리는 시간) |
| 답 s8 | 메아리는 산에 부딪혀 늦게 돌아온 내 목소리예요. | 계곡 장면 복귀. 가는 화살표(청록)와 돌아오는 화살표(연보라) 요약 + 라벨 "메아리" | - |

## 답 1문장
산에서 외치면 내 목소리가 공기를 타고 퍼져 단단한 산에 부딪혀 되튕기고, 소리는 빛보다 느려서 갔다 오는 데 시간이 걸리기 때문에 메아리는 늦게 돌아온 내 목소리다.

## "그래서?" 점검
1. 산이 대답하는 게 아니라면? -> 내 목소리가 공기를 타고 사방으로 퍼진다(고리 1, 원인: 목소리가 공기를 흔들어 퍼짐).
2. 퍼져서 그래서? -> 퍼지던 소리가 단단한 산에 닿으면 뚫고 가지 못하고 되튕긴다(고리 2, 원인 한마디: 단단한).
3. 되튕겨서 그래서? -> 되튕긴 소리가 내게 돌아온다(고리 3).
4. 그런데 왜 곧바로가 아니라 잠시 뒤? -> 소리는 빛보다 느려서(비교 기준 빛) 갔다 오는 데 시간이 걸린다(고리 4, 원인: 느림).
5. 결론 -> 메아리는 늦게 돌아온 내 목소리다. 비약 없음.

## 한계(내레이션에는 넣지 않음)
가까운 벽에서는 돌아오는 소리가 거의 곧바로 섞여 따로 들리지 않는다. 훅을 "맞은편 산을 보고 외쳐요"로 한정해 조건을 걸었고 일반화하지 않았다.

## 색 연결 규칙
가는 소리 청록(`#62C6F2`), 돌아온 소리 연보라(`#B9A6FF`, 갈수록 옅음), 공기 연한 회청색 점, 빛 노랑 줄, 시간 막대 흰색, 산과 벽 갈색. 훅부터 끝까지 같은 색.

# c84 설명 사슬 - 병에 물을 채우면 소리가 높아지는 이유

## 질문

병에 물을 채우고 불면 왜 소리가 높아질까.

## 의외성

물이 출렁여서 소리가 나고 물이 많아져서 높아진다고 믿기 쉽다. 실제로 소리를 내는 것은 병 속에 갇힌 공기이고, 물은 공기가 든 자리를 줄일 뿐이다. (s3이 "소리를 내는 건 물이 아니에요"라고 말로 뒤집고, 말풍선의 물방울 -> 소리 화살표 위 X가 그 뜻을 맡는다. 이어서 s4가 진짜 원인 쪽으로 시선을 옮긴다.)

## "그래서?" 점검

s1·s2 물을 채우면 소리가 높아진다 -> 물이 소리를 내나? s3 "물이 아니에요" -> 그럼 뭐가? s4 병 속에 갇힌 공기가 떨려 -> 왜 떨리나? s5 바람이 입구 공기를 누르면 속 공기가 되밀어요 -> 그래서? s6 눌렸다 올랐다 계속 떨려요 -> 그럼 물을 채우면 뭐가 달라지나? s7 공기가 든 자리가 좁아져요 -> 그래서? s8 더 세게 되밀어 빨리 떨려요 -> 빨리 떨리면? s9 높은 소리로 들려요 -> s10 결론. 비약 없음.

연결(이전 결과어가 다음 주어):
- s2 -> s3: "소리가 높아져요"를 "소리를 내는 건"으로 받음.
- s3 -> s4: "물이 아니에요"를 "병 속에 갇힌 공기가"로 받음. 확대 카드가 병에서 자라 나옴.
- s4 -> s5: "공기가 떨려"를 "바람이 입구 공기를 누르면 속 공기가"로 풀어 이유를 붙임.
- s5 -> s6: "되밀어요"를 "그래서 입구 공기가 눌렸다 올랐다"로 받음.
- s6 -> s7: "계속 떨려요" 뒤에 "물을 채우면"으로 훅의 조작과 이어 병이 두 개로 나란히 섬(복제 그림).
- s7 -> s8: "자리가 좁아져요"를 "좁은 자리 공기는"으로 받음.
- s8 -> s9: "빨리 떨려요"를 "더 빨리 떨릴수록"으로 받음.
- s9 -> s10: "높은 소리"를 "물이 찰수록 ... 높은 소리가 나요"로 닫음. 카드가 병으로 닫히며 실제 장면으로 복귀(표지 없이 확대 카드가 닫히는 것으로 연결).

용어 풀이: "떨려"(진동)를 일상어로만 씀. 전문용어 없음.

## 그림 일관 규칙 (04와 동일)

- 대상: 굼구미 1, 상자 1, 실제 병 1(훅·복귀·반전), 컵 1, 말풍선 1, 카드 1 안에 병 단면(처음 1개, s7부터 2개), 입구 공기 틀 1(s5-s6) 2(s8-s9, 병마다 1) + 실제 병 1(s10), 바람 줄(훅·s5·s8·반전), 주황 화살표(s5-s6에 1, s8에 2), 공기 자리 눈금 막대(s7에 2, 실제 장면 복귀에 2, 라벨 "공기 자리" 막대 하나씩 s7과 s10).
- 색: 공기(바람 포함) 하늘색, 물 파랑, 입구 공기 표시 노란 점선, 되미는 힘 주황, 소리 보라 동심원, 공기 자리 눈금 청록(원래 자리 회색 점선).
- 동심원 간격: 낮은 소리가 넓고 높은 소리가 촘촘(훅 70 대 35, 카드 32 대 약 19). 굵기는 모두 같아 소리 크기 차이로 읽히지 않음.

## 동시 표시 점검 (자막은 해당 구간 t0~t1 동안 표시)
- 0.00-0.60: 없음. 0.60-1.00: L1 = 1. 1.00-4.23: s1 + L1 = 2. 4.23-4.63: L1 = 1. 4.63-5.03: 없음.
- 5.03-5.18: s2 = 1. 5.18-8.92: s2 + L2 = 2. 8.92-9.22: L2 퇴장 후 없음.
- 9.22-9.62: S1 = 1. 9.62-9.99: s3 + S1 = 2. 9.99-10.86: s3 + S1 + L3 = 3 (상한과 일치). 10.86-11.09: s3 + L3 = 2 (S1 퇴장). 11.09-13.18: s3 + L3 + L4 = 3 (상한과 일치). 13.18-13.48: L3 + L4 = 2. 13.48-13.88: 없음.
- 13.88-14.03: s4 = 1. 14.03-17.33: s4 + L5 + S2 = 3 (상한과 일치). 17.33-17.73: L5 + S2 = 2.
- 17.73-18.13: L6 + S2 = 2 (L5는 17.73에 퇴장). 18.13-19.70: s5 + L6 + S2 = 3 (상한과 일치). 19.70-21.91: s5 + S2 = 2. 21.91-22.61: S2 = 1.
- 22.61-23.31: s6 + S2 = 2. 23.31-23.97: s6 + L7 = 2 (S2 퇴장). 23.97-26.39: s6 + L7 + L8 = 3 (상한과 일치). 26.39-26.89: L7 + L8 = 2.
- 26.89-27.29: S3 = 1. 27.29-27.33: s7 + S3 = 2. 27.33-28.49: s7 + S3 + S4 = 3 (상한과 일치). 28.49-28.83: s7 + S4 = 2. 28.83-31.07: s7 = 1. 31.07-32.47: 없음(비트8).
- V4 강조 자막(emph)은 구간 자막의 해당 어절을 키우는 방식이며 별도 글자 요소가 아니다. 동시 개수에 더하지 않는다.

## 라벨 규칙 점검
- 라벨 6자 이내(공백 포함): 금붕어 3, 지느러미 4, 뼈와 근육 5, 같은 크기 물 6, 부레 2, 가스 2, 미는 힘 4, 몸무게 3. 표지 10자 이내: 몸속 단면 4, 과장해 그림 6, 다시 어항으로 7.
- 노출 1.5초 이상: L1 4.03, L2 3.74, S1 1.64, L3 3.49, L4 2.39, S2 9.28, L5 3.70, L6 1.97, L7 3.58, L8 2.92, S3 1.60, S4 1.50. 전부 충족.
- 라벨은 대상이 처음 그려진 뒤 1초 안에 팝인: L1 금붕어는 0.00부터 보이고 0.60, L2 지느러미는 0.00부터 보이던 부위를 설명 대상으로 처음 부르는 시점 5.18(같은 금붕어에 속한 부위), L3 시소 위 단면 9.62 등장 뒤 9.99, L4 물덩이가 10.46에 오른쪽 받침으로 들어온 뒤 11.09(0.63초), L5 부레 14.03 생성과 동시, L6 가스 컵 17.73 등장과 동시, L7 위쪽 화살표 22.40 시작에서 23.31(0.91초), L8 아래쪽 화살표 23.97 시작과 동시, S4 부레 윤곽 27.33 등장과 동시.
- **라벨 팝인은 가리키는 어절 0.4초 전이다**: L1 s1@"금붕어가", L2 s2@"지느러미를", L3 s3@"뼈와", L4 s3@"물보다", L5 s4@"부레", L6 s5@"가스는", L7 s6@"미는", L8 s6@"몸무게와", S4 s7@"부레". 비트 끝에 몰아서 띄운 라벨 없음.
- 한 윤곽에 이름 두 개 금지: 부레 바깥 윤곽(L5)과 소형 저울의 가스 컵(L6)은 다른 윤곽이다. 부레 안의 연보라 채움은 이름 없이 색 약속으로만 가스를 뜻한다. 뼈와 근육은 한 라벨 "뼈와 근육"이 금붕어 단면의 뼈·근육 영역 전체를 가리킨다. 비트6의 물 모양 윤곽(`#8FD0FF`, 이름 없음)은 시소의 물덩이와 같은 색이라 "물"이고 새 라벨이 없다.
- 레이아웃 간격: 칩끼리 20px 이상(L3 x 130-440과 L4 x 610-974는 170, L5 x 190-338과 L6 x 366-514는 28, S3 y 270-340과 S4 y 360-430은 20), 칩과 패널 테두리(x 70-1010, y 440-1040) 20px 이상(L3 왼쪽 60, L4 오른쪽 36, L7 위 80, L8 아래 40), 자막 띠(y 1250 이하)에 칩·도식 없음. 어항 장면의 칩 L1·L2·S4는 어항 위끝 y 460과 30px 떨어진다.

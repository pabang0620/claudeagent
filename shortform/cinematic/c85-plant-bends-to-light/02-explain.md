# c85 설명 사슬 - 화분 줄기가 빛 쪽으로 휘는 이유

## 질문

창가 화분의 줄기는 왜 빛 쪽으로 휠까.

## 의외성

햇빛이 줄기를 끌어당긴다고 믿기 쉽다. 실제로는 줄기 속에서 그늘 쪽이 더 길게 자라 굽는다. (s2가 "끌어당기는 건 아니에요"라고 말로 뒤집고, 풍선 속 햇빛 줄 -> 줄기 위 X가 그 뜻을 맡는다. 이어서 s3-s6이 진짜 원인을 채운다.)

## 인과 고리 (내레이션은 narration-ko.json)

| 고리 | 내레이션(ko) | 봐야 하는 그림 | 피해야 할 오해 |
|---|---|---|---|
| 훅 s1 | 창가 화분은 줄기가 햇빛 드는 쪽으로 휘어요. | 오른쪽 창에서 햇빛이 들고, 달력이 넘어가는 동안 화분 줄기가 창 쪽으로 휨. 설명·도식 없음 | 굼구미가 줄기를 구부림 |
| 의외성 s2 | 햇빛이 줄기를 끌어당기는 건 아니에요. | 풍선: 해에서 줄로 줄기를 당기는 그림 + X | 빛이 물리적으로 끎 / 식물이 스스로 몸을 숙임 |

답 1문장: 창가 줄기는 빛이 한쪽에서 오면 옥신이 그늘 쪽으로 몰려 그늘 쪽 세포가 더 길어지고, 한쪽만 길어진 줄기가 짧은 쪽인 빛 쪽으로 굽어 휜다.

## "그래서?" 점검

s1 줄기가 창 쪽으로 휜다 -> 빛이 끌어서? s2 "끌어당기는 건 아니에요" -> 그럼 안에서 뭐가? s3 세포는 옥신을 받으면 길어진다 -> 그런데 왜 한쪽으로만? s4 빛이 한쪽에서 오면 옥신이 그늘 쪽으로 몰린다 -> 그러면? s5 그늘 쪽 세포가 더 길어진다 -> 그러면 줄기는? s6 한쪽만 길어지면 짧은 쪽으로 굽는다 -> 결론 s7 그늘 쪽이 더 자라 빛 쪽으로 휜다. 비약 없음.

연결(이전 결과어가 다음 주어):
- s2 -> s3: 되감기와 확대 카드가 줄기에서 열리고 문장이 "줄기 세포는"으로 시작.
- s3 옥신 -> s4: "옥신을 받으면 길어져요" 뒤 "옥신이 그늘 쪽으로 몰려요".
- s4 그늘 쪽 -> s5: "그늘 쪽으로 몰려요"를 "그늘 쪽 세포가 옥신을 받아"로 받음.
- s5 더 길게 늘어나요 -> s6: "길어지면"으로 이어서 "한쪽만"으로 시작.
- s6 짧은 쪽으로 굽어요 -> s7: "그늘 쪽이 더 자라서 ... 빛 쪽으로 휘어요"로 실제 장면 복귀(카드가 줄기 끝으로 닫힘).

용어 풀이: 옥신(s3 "자람 물질")만 풀이. 세포는 일상어로 둠.

## 그림 일관 규칙 (04와 동일)

- 대상: 굼구미 1, 낮은 테이블 1, 화분 1과 줄기 1과 잎(곁잎 2쌍과 끝잎 1), 오른쪽 벽 창 1과 해 1, 햇살 줄 2, 달력 1, 풍선 1과 X 1과 풍선 안 해·줄기·줄 각 1, 카드 1 안에 세포 줄 3 x 열 2(세포 6), 옥신 6, 빛 화살표 3, 유령 점선(세포 높이 3 + 오른쪽 열 윗선 1), 반전의 새 자람 구간 1.
- 색: 옥신 보라, 빛 노랑, 그늘 쪽 회청, 빛 쪽 연노랑, 줄기·잎 초록, 세포 벽 연두, 화분 테라코타. 보라 반쪽(실제 줄기 왼쪽 반)은 옥신이 몰린 그늘 쪽을 뜻함.
- 방향: 창과 빛은 항상 오른쪽. 그늘 쪽은 항상 왼쪽. 줄기는 항상 오른쪽(짧은 쪽)으로 굽음(반전의 화분 돌림 직후만 왼쪽).

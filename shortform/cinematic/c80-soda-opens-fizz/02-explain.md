# c80 설명 사슬 - 탄산음료를 열면 거품이 올라오는 이유

## 질문

탄산음료는 뚜껑을 열면 왜 거품이 올라올까.

## 의외성

열 때 밖의 공기가 들어가 거품이 된다고 믿기 쉽다. 실제 거품은 음료에 이미 녹아 있던 탄산 기체다. (s2가 "밖에서 들어온 공기가 만든 거품이 아니에요"라고 말로 뒤집고, 풍선의 회색 공기 -> 거품 그림 위 X가 그 뜻을 맡는다. s3이 "거품 재료는 음료 속에 녹아 있는 탄산 기체"로 시선을 진짜 원인으로 옮긴다.)

## "그래서?" 점검

s1 열면 거품이 올라온다 -> 공기가 들어와서 아닌가? s2 밖에서 들어온 공기가 만든 게 아니다 -> 그럼 거품 재료는? s3 음료 속에 녹아 있는 탄산 기체 -> 왜 녹아 있었나? s4 닫힌 병은 위쪽 기체가 세게 눌러서 -> 열면? s5 누르는 힘이 확 줄어요 -> 그래서? s6 녹을 수 있는 기체도 줄어요 -> 못 녹은 건? s7 못 녹은 기체가 빠져나와 거품이 되어 올라온다. 비약 없음.

연결(이전 결과어가 다음 주어):
- s1 거품 -> s2 "거품이 아니에요" -> s3 "거품 재료는". 거품이 세 문장을 이어줌.
- s3 녹아 있는 -> s4 "위쪽 기체가 세게 눌러서 녹아 있어요"(왜 녹아 있나를 이어 받고, 누르는 주체가 병 위쪽 기체임을 말과 그림으로 보임).
- s4 눌러서(화살표 "누르는 힘") -> s5 "누르는 힘이 확 줄어요" -> s6 "누르는 힘이 줄면".
- s6 녹을 수 있는 기체도 줄어요 -> s7 "못 녹은 기체가".
- s7 거품이 올라와요가 훅 s1과 닫힘. 카드가 닫히며 실제 병 장면으로 복귀.

용어 풀이: "탄산 기체"는 이름 자체가 쉬운 말이라 별도 풀이 없음. "압력"은 말하지 않고 "누르는 힘"으로만 말함.

## 그림 일관 규칙 (04와 동일)

- 대상: 굼구미 1, 병 A(연 병) 1, 병 B(반전의 닫힌 병) 1, 뚜껑 A 1(굼구미 손에 쥠), 뚜껑 B 1(굼구미 손에 쥠), 생각 풍선 1, X 1, 카드 1(병 단면 1), 카드 안 뚜껑 띠 1, 위쪽 기체 알갱이 4(진한 하늘 실선), 누르는 힘 화살표 3, 알갱이 5(녹은 상태 점선 연한색, 못 녹은 상태 실선 진한색), 기포 1, 거품 둔덕 3, 훅의 병 속 기포 3, 훅의 입구 거품 3, 회색 공기 물결 3, 점선 지시선 2.
- 색: 탄산 기체 하늘(녹음은 연한 점선, 녹지 않은 위쪽 공간 기체와 못 녹은 기체는 진한 실선), 음료 주황, 누르는 힘 남보라, 밖 공기 회색, 뚜껑 청록.

# c57 화면 글자 (내레이션 자막은 자동이라 제외)

앵커는 내레이션 id 기준이다. 라벨은 그 대상을 말하는 어절이 발음되는 순간 팝인한다. 좌표는 1080x1920 기준 px(글자 중심, 글자 크기 약 40px).

| id | 종류 | 앵커(등장~퇴장) | ko | 위치 |
|---|---|---|---|---|
| L1 | 라벨 | s2@"노란색은" ~ s3.t0-0.40 | 노란색 | 글자 (790, 1060), 지시선 끝 손에 쥔 잎 오른쪽 가장자리 (580, 995) |
| S1 | 스케일 표지(확대 창 이름 겸용) | s3.t0 ~ s3@"노란"-0.10 | 여름 잎 속 확대 | 그림 무대 위쪽 중앙 (540, 330) |
| L2 | 라벨 | s3@"초록" ~ s6.t0+3.40 | 초록 색소 | 글자 (770, 940), 지시선 끝 오른쪽 아래 클러스터 C6의 초록 점 (720, 818) |
| L3 | 라벨 | s3@"노란" ~ s5.t0-0.40, 다시 s6.t0-0.15 ~ s7.t1+0.30 | 노란 색소 | 글자 (250, 640), 지시선 끝 클러스터 C3의 노란 점 (560, 700) |
| L4 | 라벨 | s5@"해가" ~ s6.t0-0.40 | 해 길이 | 글자 (780, 340), 지시선 끝 해 아이콘 위 (780, 395) |

- 가독성: L1, L2 글자 뒤에 어두운 반투명 판(`#1B2A4E` 알파 0.6)을 깔고, 해 아이콘(L4 지시 대상) 뒤에도 남색 판(x 690-870, y 380-455)을 깐다(좌표는 04 배치 고정값).
- 숫자 N 없음(화면 숫자 없음).
- 동시 글자 점검(자막 포함): 비트 1(s1) 자막=1 / 비트 2(s2) 자막+L1=2 / 비트 3(s3) 자막+S1+L2=3(S1은 s3@"노란"-0.10에 퇴장하고 L3은 s3@"노란"에 팝인하므로 S1과 L3이 겹치지 않음. 이후 자막+L2+L3=3) / 비트 4(s4) 자막+L2+L3=3 / 비트 5(s5) 자막+L2+L4=3(L3은 s5.t0-0.40에 퇴장) / 비트 6(s6) 자막+L2+L3=3(L4는 s6.t0-0.40에 0.25초 퇴장하고 L3은 s6.t0-0.15에 다시 팝인해 겹치지 않음, L2는 s6.t0+3.40에 퇴장) / 비트 7(s7) 자막+L3=2 / 비트 8 글자 없음. 최대 3.
- 노출 시간(1.5초 이상): L1 약 4.0초 / S1 약 2.0초 / L2 약 18초(s3@"초록" 약 11.8초에서 s6.t0+3.40 약 29.3초) / L3 1차 약 7.8초, 2차 약 9.7초 / L4 약 4.5초.
- 핵심 비트에서 라벨 유지: 초록 색소(L2)는 초록이 핵심인 s3-s6 전부에 있고, 노란 색소(L3)는 가려짐이 핵심인 s3-s4와 드러남이 핵심인 s6-s7에 있다. s5는 해 길이(L4)와 초록 색소(L2)가 핵심이라 동시 글자 3개 한도 때문에 L3을 잠시 내린다.
- 비트 1(훅)과 비트 8(반전)에는 글자가 없다(비트 1은 자막만, 비트 8은 자막도 없음).
- 처음 나오는 대상별 라벨/표지: 손에 쥔 노란 잎(L1), 확대 창(S1), 초록 점(L2), 노란 점(L3), 해 아이콘(L4). 은행나무, 하늘, 땅은 훅의 일상 사물이라 라벨 없음. X 표, 반짝임, 점선 원, 금(균열)은 효과라 글자 없음.

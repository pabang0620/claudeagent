# c57 설명 사슬 - 가을에 은행잎이 노랗게 변하는 이유

## 질문

가을에 은행잎이 초록에서 노랗게 변하는 건 왜일까.

## 의외성

그 노란색은 가을에 새로 생긴 색이 아니다. 잎 속에 처음부터 있었는데 초록에 가려져 있던 것이다.

## 인과 고리 (내레이션 id는 narration-ko.json)

| 고리 | 내레이션(ko) | 봐야 하는 그림 | 피해야 할 오해 |
|---|---|---|---|
| 훅 s1 | 가을이 되면 은행잎이 초록에서 노랗게 변해요. | 가을 길가 은행나무 아래 굼구미가 올려다봄. 나뭇잎이 위에서부터 초록에서 노랑으로 번짐. 잎 하나가 떨어져 굼구미 손에 받아 쥠. 설명·라벨 없음 | - |
| 의외성 s2 | 그 노란색은 가을에 새로 생긴 게 아니에요. | 장면이 어두워지고 굼구미와 손에 쥔 노란 잎만 밝음(라벨 "노란색"). 잎 위에 노란 반짝임이 팝인하고 빨간 X가 찍힘 | 가을에 노란 물감이 새로 생긴다 |
| 고리1 s3 | 잎에는 처음부터 초록 색소와 노란 색소가 있어요. | 잎이 도로 초록으로 되감김(화면 장치). 잎 속 확대 창(표지 "여름 잎 속 확대"). 창 속 초록 점 18개와 노란 점 6개가 함께 있고 라벨 "초록 색소", "노란 색소" | 색소가 눈에 보이는 알갱이다(점은 상징) |
| 고리2 s4 | 여름엔 잎이 초록 색소를 계속 채워서 노랑이 가려져요. | 창 속 초록 점이 부서지고 새 초록 점이 노란 점 위에 채워지는 일이 12번 일어나 노란 점이 초록에 덮임. 개수는 18개 그대로 | 초록이 노랑을 완전히 지운다, 층층이 쌓여 있다 |
| 고리3 s5 | 해가 짧아지는 가을엔 잎이 초록 색소를 안 채워요. | 창 위 해 아이콘의 호가 넓다가 좁아지고(유령 윤곽이 비교로 남음, 라벨 "해 길이"). 새 점이 채워질 빈 자리(점선 원)에 빨간 X. 점 18개 그대로 | 가을에 갑자기 초록이 없어진다 |
| 고리4 s6 | 안 채우면 초록 색소는 원래 조금씩 부서져 사라져요. | 초록 점이 그룹별로 금이 가며 부서져 사라지고(6그룹 x 3개), 노란 점만 남음. 손에 쥔 잎과 뒤 나무 색이 초록에서 노랑으로 변함 | 가을에 초록이 갑자기 사라진다 |
| 답 s7 | 초록이 사라지면 원래 있던 노란색이 드러나요. | 남은 노란 점 6개가 차례로 환하게 빛남(라벨 "노란 색소"). 손에 쥔 노란 잎 | 노란색이 새로 만들어진다 |

답 1문장: 은행잎에는 처음부터 노란 색소가 있는데, 여름엔 초록 색소가 계속 채워져 가려져 있다가 가을에 해가 짧아져 초록이 사라지면서 노란색이 드러난다.

## "그래서?" 점검

잎이 노랗게 변한다 -> 그래서? 노란색은 새로 생긴 게 아니다 -> 그럼 어디서? 잎에 처음부터 노란 색소가 있었다 -> 왜 여름엔 안 보였나? 초록이 계속 채워져 가려졌다 -> 왜 가을엔 달라지나? 해가 짧아지면 초록을 안 채운다 -> 안 채우면? 초록은 원래 조금씩 부서져 사라진다 -> 그래서? 가려졌던 노랑이 드러난다. 비약 없음. s4에서 부서짐과 채움이 둘 다 보이기 때문에 s6의 "원래 조금씩 부서져요"는 이미 본 장면이다. 용어 풀이: "색소"는 일상어이고 화면 점과 라벨이 풀이를 대신한다(풀이 필요 용어 0개).

- 야외 장면: 굼구미 중심 x 250, 발 y 1190, 키 300px(몸 x 100-400, 머리 위 y 890). 오른쪽을 봄. 오른손이 쥔 잎 중심 (525, 990), 손 끝 (470, 1040). 은행나무 줄기 x 640-740, 수관 중심 (680, 560).
- 초록 = `#3FAE49`, 노랑 = `#FFC21A`. 잎, 수관, 색소 점이 모두 같은 두 색이다.
- 확대 창 W1: 중심 (620, 690), 반지름 190. 창 속 초록 점 18개, 노란 점 6개(점 반지름 18). 노란 점 6개는 모든 비트에서 같은 자리, 같은 개수.
- 초록 점 개수: s3 18 -> s4 18(12번 교체) -> s5 18 -> s6 18에서 0 -> s7 0. 노란 점은 항상 6.
- 굼구미는 잎을 쥐고 들여다볼 뿐 색소를 만지거나 부수지 않는다. 확대 창과 해 아이콘은 굼구미 손 도구가 아니라 화면 장치다.

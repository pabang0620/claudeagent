# c24 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("잠들면 코를 고는 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

| id | 종류 | 등장~퇴장(예상 초) | ko | en | 위치 |
|---|---|---|---|---|---|
| S1 | 스케일 표지 (D.scaleBadge) | 10.40-11.90 | 목 안 확대 | Zoom into throat | 그림 무대 위쪽 |
| L1 | 라벨 | 13.00-15.30 | 목 근육 | Throat muscle | 늘어지는 조직 옆, 지시선 |
| L2 | 라벨 | 15.70-17.80 | 통로 | Airway | 좁아진 통로 옆, 지시선 |
| L3 | 라벨 | 18.20-20.90 | 빠른 공기 | Fast air | 빠른 화살표 옆, 지시선 |
| L4 | 라벨 | 21.30-23.80 | 떨림 | Flutter | 떨리는 조직 옆, 지시선 |

## 동시 표시 점검
- 0.00-10.40: 자막(s1~s4)만 순차 표시, 라벨 없음 = 최대 1개.
- 10.40-11.90: S1 + s4 자막 = 2개.
- 11.90-12.50: s4 자막 단독 = 1개(S1 페이드 아웃 후).
- 12.50-13.00: 없음(고리1 등장 전 간격).
- 13.00-15.30: L1 + s5 자막 = 2개.
- 15.30-15.70: 없음(간격, L1 페이드 아웃 후 L2 등장 전).
- 15.70-17.80: L2 + s6 자막 = 2개.
- 17.80-18.20: 없음(간격).
- 18.20-20.90: L3 + s7 자막 = 2개.
- 20.90-21.30: 없음(간격).
- 21.30-23.80: L4 + s8 자막 = 2개.
- 23.80-27.20: s9 자막 단독 = 1개(라벨 없음, 방으로 복귀).
- 27.20-30.20: s10 자막 단독 = 1개(라벨 없음, 답 정리).
- 30.20-31.20: 없음(반전 코다, 자막·라벨 없음).
- 어느 시점도 상한(3개)을 넘지 않으며, 실제로는 최대 2개만 동시에 뜬다.

## 숫자(N)
화면 숫자 없음. `01-fact.md`의 버린 사실 항목대로 기도 협착 비율·기류 속도·소리 크기 수치는 개인차가 커 A등급이 아니므로 화면에 쓰지 않는다. "빠름/좁음/떨림" 같은 정성적 라벨로만 개념을 보여준다.

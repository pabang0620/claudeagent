# c07 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("쇠가 나무보다 차갑게 느껴지는 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

|---|---|---|---|---|---|
| S1 | 스케일 표지 (D.scaleBadge) | 10.98-12.48 | 피부 단면 확대 | Zoom into skin | 그림 무대 위쪽 |

## 동시 표시 점검
- 10.98-12.48: S1 + s4 자막 = 2개.
- 12.48-13.11: s4 자막 단독 = 1개(S1 페이드 아웃 후).
- 13.11-13.61: 없음(고리1 등장 전 간격).
- 13.61-16.10: s5 자막 단독 = 1개(L1 등장 전).
- 16.10-16.52: L1 + s5 자막 = 2개.
- 16.52-16.92: L1 단독 = 1개(간격, s6 시작 전).
- 16.92-18.10: L1 + s6 자막 = 2개.
- 18.10-19.56: s6 자막 단독 = 1개(L1 페이드 아웃 후, L2 등장 전).
- 19.56-19.96: L2 + s6 자막 = 2개.
- 19.96-20.36: L2 단독 = 1개(간격, s7 시작 전).
- 20.36-21.06: L2 + s7 자막 = 2개.
- 21.06-23.13: s7 자막 단독 = 1개(L2 페이드 아웃 후, L3 등장 전).
- 23.13-23.53: L3 + s7 자막 = 2개.
- 23.53-23.93: L3 단독 = 1개(간격, s8 시작 전).
- 23.93-25.03: L3 + s8 자막 = 2개.
- 25.03-26.71: s8 자막 단독 = 1개(L3 페이드 아웃 후, L4 등장 전).
- 26.71-27.21: L4 단독 = 1개(간격, s9 시작 전).
- 27.21-29.73: L4 + s9 자막 = 2개.

## 숫자(N)
화면 숫자 없음. `01-fact.md`의 A등급이더라도 정확한 온도값·열전도율 수치(재질마다 다름)는 화면에 쓰지 않는다. "빠름/느림"이라는 정성적 라벨(L2, L3)로만 대비를 보여준다.

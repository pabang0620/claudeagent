# c38 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("뱀이 혀를 날름거리는 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

## 동시 표시 점검
- 0.00-9.17: 자막(s1~s2)만 순차 표시 = 각 1개.
- 9.17-10.50: S1 + 자막(s3) = 2개.
- 10.50-10.90: S1 + L1 + 자막(s3) = 3개(상한과 정확히 일치, 초과 아님).
- 10.90-12.60: L1 + 자막(s3) = 2개.
- 12.60-13.00: L1 단독 = 1개(s4 자막 시작 전, 전환 간격).
- 13.00-14.80: 자막(s4) 단독 = 1개.
- 14.80-16.69: L2 + 자막(s4) = 2개.
- 16.69-16.90: L2 단독 = 1개(고리2->고리3 전환 간격).
- 17.09-20.52: 자막(s5) 단독 = 1개.
- 20.52-20.92: 없음(전환 간격).
- 20.92-22.60: 자막(s6) 단독 = 1개.
- 22.60-24.48: L3 + 자막(s6) = 2개.
- 24.48-24.90: L3 단독 = 1개(s7 자막 시작 전).
- 24.98-26.00: 자막(s7) 단독 = 1개.
- 26.00-28.28: L4 + 자막(s7) = 2개.
- 28.28-28.88: L4 단독 = 1개.
- 28.88-28.90: L4 + 자막(s8) = 2개.
- 28.90-32.44: 자막(s8) 단독 = 1개(라벨 없음, 일상 장면으로 복귀).
- 32.44-36.99: 자막(s9) 단독 = 1개.
- 36.99-38.19: 없음(반전 버튼, 자막·라벨 없음).
- 어느 시점도 상한(3개)을 넘지 않는다(10.50-10.90 구간이 정확히 3개로 최대치).

# c99 설명 사슬 - 젖은 천이 더 짙어 보이는 이유

## 질문

천에 물이 묻으면 왜 그 자리만 더 짙은 색이 될까.

## 의외성

물이 색을 칠하는 것 같지만 물은 투명하고 색이 없다. 진짜 원인은 천 속 빛의 움직임이다. (s2가 "물이 색을 입히는 게 아니에요"라고 말로 뒤집고, 말풍선의 물방울 -> 붓 -> 짙은 칠 위 X가 그 뜻을 맡는다. 이어서 s3이 "마른 천은 실 사이에 공기 틈이 많아요"로 시선을 천 속으로 옮긴다.)

답 1문장: 천이 젖으면 물이 실 사이 공기를 밀어내 빛이 덜 흩어지고 실 속으로 들어가 흡수되므로, 눈으로 돌아오는 빛이 줄어 짙어 보인다.

## "그래서?" 점검

s1 젖은 곳이 짙다 -> 물이 칠한 건가? s2 아니다(물은 색이 없다) -> 그럼 뭐가? s3 마른 천은 실 사이 공기 틈이 많다 -> 그래서? s4 틈마다 빛이 흩어져 눈에 많이 돌아와 연하다 -> 젖으면? s5 물이 공기를 밀어낸다 -> 그래서? s6 물과 실 경계는 공기와 실 경계보다 빛이 덜 꺾인다 -> 그래서? s7 덜 흩어지고 실 속으로 들어간다 -> 들어가면? s8 실이 빨아들인다 -> 결국? s9 돌아오는 빛이 줄어 짙어 보인다. 비약 없음.

연결(이전 결과어가 다음 주어):
- s2 -> s3: 말풍선이 닫히고 카드가 천에서 자라며 문장이 "마른 천은 ..."로 시작.
- s3 공기 틈 -> s4: "틈마다".
- s4 많이 돌아와요 -> s5: 같은 카드가 오른쪽으로 넓어지며 "젖으면"으로 상태 전환(마른 쪽은 왼쪽에 그대로 남아 비교).
- s5 물이 공기를 밀어내요 -> s6: "물과 실 경계는 공기와 실 경계보다"(젖은 칸 실 둘레와 마른 칸 실 둘레를 나란히 비교). s6 덜 꺾여요 -> s7: "그래서 빛이 덜 흩어지고". s7 들어가요 -> s8: "들어간 빛은". s8 -> s9: "젖은 천은 ... 돌아오는 빛이 줄어", 셔츠와 같은 색 견본으로 실제 장면과 연결.

용어 풀이: 전문용어 없음. 섬유는 "실", 산란은 "흩어져", 굴절은 "꺾여요"(빛이 경계에서 꺾이는 정도, 경계가 공기와 실이면 크고 물과 실이면 작다), 흡수는 "빨아들여요"로 풀어 씀.

# c98 설명 사슬 - 우유가 요구르트로 굳는 이유

## 질문

우유는 어떻게 요구르트로 굳을까.

## 의외성

요구르트 속 균이 우유를 직접 굳힌다고 믿기 쉽다. 실제로 굳히는 건 균이 만든 신맛 젖산이 우유 단백질 알갱이를 달라붙게 하는 것이다. (s2가 "직접 굳히는 건 아니에요"라고 말로 뒤집고, 풍선의 균 -> 굳은 병 화살표 위 X가 "직접은 아니다"를 뜻한다. 이어서 s3-s8이 진짜 원인을 채운다.)

## "그래서?" 점검

s1 굳는다 -> 균이 굳히나? s2 직접은 아니에요 -> 그럼 굳는 건 뭐가? s3 단백질 알갱이(밀어내 떠 있음, 그래서 평소엔 안 굳음) -> 균은 뭘 하나? s4 당을 먹고 젖산을 냄 -> 그래서? s5 젖산이 쌓이면 알갱이 겉이 변함 -> 그래서? s6 밀어내던 힘이 줄어요 -> 그래서? s7 달라붙어 그물 -> 그래서? s8 그물에 물이 갇혀 굳음. 비약 없음.

연결(이전 결과어가 다음 주어):
- s2 -> s3: "굳히는 건 아니에요" 뒤 카드가 병에서 자라고 문장이 "우유 속 단백질 알갱이"로 시작(진짜 대상으로 시선 이동).
- s3 -> s4: "그동안"으로 같은 우유 속에서 동시에 벌어지는 일을 잇고, 주어 "균은"은 s2의 "균"을 받음.
- s4 -> s5: "젖산을 내요" -> "젖산이 쌓이면".
- s5 -> s6: "알갱이 겉이 변해요" -> "그러면 서로 밀어내던 힘이 줄어요"(s3의 "밀어내며"를 받음).
- s6 -> s7: "힘이 줄어요" -> "알갱이가 서로 달라붙어".
- s7 -> s8: "그물이 돼요" -> "그물에 물이 갇혀서". 마지막 문장이 핵심 사실.

용어 풀이: 유산균은 s2 "요구르트 속 균", 젖산은 s4 "신맛 젖산", 당은 "우유 속 당". 풀이가 필요한 용어는 균·젖산 둘.

# c60 설명 사슬 - 비누로 기름기가 씻기는 이유

## 질문

기름 묻은 접시는 물로만 헹구면 안 씻기는데, 비누를 쓰면 씻기는 건 왜일까.

## 의외성

물을 아무리 부어도 기름은 그대로 남는다. 물과 기름은 서로 섞이지 않기 때문이다. 그런데 비누를 쓰면 같은 기름이 물에 씻겨 나간다. 비누가 기름을 물에 섞이게 하는 것이 아니라 기름 방울을 감싸서 물과 어울리게 만든다.

답 1문장: 비누 분자가 기름 방울을 감싸 겉이 물과 어울리게 만들어서, 헹구면 기름이 물에 씻겨 간다.

## "그래서?" 점검

물만 부으면 기름이 남는다 -> 왜? 물과 기름은 섞이지 않는다 -> 그럼 비누를 쓰면? 비누를 풀면 비누 분자가 기름 방울 곁으로 온다 -> 그 분자는 뭐가 다른가? 분자의 한쪽 끝이 물과 어울린다 -> 그리고? 반대쪽 끝은 기름과 어울린다 -> 그래서? 기름 쪽 끝이 방울에 박힌다 -> 그러면? 박힌 방울은 겉이 물과 친해져 떠다닌다(s2 "섞이지 않음"은 "비누 분자가 박힌" 조건으로 한정) -> 그래서? 헹구면 물에 씻겨 간다(s1 훅 해결). 비약 없음.

중간 단계 확인:
- "비누가 왜 나오고 어디로 가나"는 s3(비누를 풀면 분자가 기름 방울 곁으로, 분홍 비누 방울이 풀려 점이 모임)에서 메운다. 분홍은 훅의 세제병과 같은 색이다.
- "왜 비누를 쓰면 다른가"는 s4-s5(양쪽 끝이 서로 다른 것과 어울림)에서 메운다.
- "그래서 방울에 어떻게 붙나"는 s6에서 "기름 쪽 끝이 방울에 박힘, 머리는 바깥"으로 메운다.
- "섞이지 않는 기름이 왜 물에 뜨나"는 s7에서 "겉이 물과 친해짐"으로 메운다.
- 용어 풀이: "분자"는 S1 "분자 크기 확대"와 작은 알갱이 모양 그림으로 푼다. 풀이 필요 용어 1개(2개 이하).

# c94 설명 사슬 - 문이 삐걱거리는 이유

## 질문

방문을 열면 왜 끼익 소리가 날까.

## 의외성

쇠끼리 비비기만 하면 나는 소리라고 믿기 쉽다. 실제로는 쇠 표면의 울퉁불퉁한 곳이 걸렸다가 툭 풀리는 일이 아주 빠르게 반복되어 생기는 떨림이다. (s2가 "경첩 쇠끼리 비비기만 해서 나는 소리가 아니에요"라고 말로 뒤집고, 풍선의 "쇠 비빔 -> 소리 호" 그림 위 X가 그 통념을 지운다. 이어서 s3이 진짜 원인을 말한다.)

## "그래서?" 점검

s1 끼익 소리가 난다 -> 쇠끼리 비벼서? s2 비비기만 해서 나는 소리가 아니에요 -> 그럼? s3 걸렸다 풀리는 소리 -> 왜 걸리나? s4 표면이 울퉁불퉁 -> 그래서? s5 밀어도 튀어난 곳끼리 걸려 붙는다 -> 그러면? s6 힘이 쌓이다 툭 미끄러진다 -> 그래서 소리는? s7 아주 빠르게 반복돼 떨린다 -> 떨리면? s8 문짝에 퍼져 울린다 -> 어떻게 없애나? s9 기름이 틈을 채우면 걸리지 않아 조용 -> s10 결론. 비약 없음.

연결(이전 결과어가 다음 주어):
- s2 -> s3: "소리가 아니에요" 뒤 "소리예요"로 진짜 원인을 받음. 확대 카드가 경첩에서 자라 "경첩 속"으로 시작.
- s3 -> s4: "경첩 속 쇠끼리 걸렸다" 뒤 "경첩 속 쇠 표면은"(같은 대상, 왜 걸리나 답).
- s4 -> s5: "울퉁불퉁해요" 뒤 "튀어난 곳끼리"(울퉁불퉁의 튀어난 곳).
- s5 -> s6: "걸려 붙어요" 뒤 "걸린 채".
- s6 -> s7: "툭 미끄러져요" 뒤 "이게 ... 반복되며"(걸렸다 풀리는 일).
- s7 -> s8: "쇠가 떨려요" 뒤 "그 떨림이"로 실제 장면 복귀(카드가 경첩으로 닫힘).
- s8 -> s9: 소리가 났으니 기름을 바른다(굼구미가 기름을 떨어뜨리는 A 비트 1.2초가 잇는 말 대신). "걸리지 않아"가 s5-s6의 "걸려 붙어요"를 받음.
- s9 -> s10: 위 칸(기름 없음)을 밝혀 "걸렸다 풀리는 떨림"으로 결론. 위 칸은 비트 8 끝처럼 빠른 반복이 기본이고, s10 한 사이클만 느리게 풀어 보여준다.
- s1 -> s2: 훅에서 소리가 문 가장자리에서 나고, s2가 "경첩"을 말하며 그 자리에 경첩이 나타나 쇠의 자리를 잇는다.

용어 풀이: 쉬운 일상어만 쓴다. "마찰", "진동"이라는 말은 쓰지 않는다. 풀이가 필요한 용어 0개.

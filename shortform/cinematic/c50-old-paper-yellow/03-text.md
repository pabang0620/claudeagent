# c50 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("종이가 누렇게 변하는 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `04-storyboard.md`의 비트별 절대 초(추정치)를 그대로 따랐다(검토용). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인하며, 애니메이터는 이 표의 절대 초가 아니라 storyboard의 상대 앵커(예: `s3@"성분"-0.50`)를 쓴다.

## 동시 표시 점검
- 0.00-1.20: 없음(훅 예비 구간, 자막 시작 전).
- 1.20-5.28: s1 자막 단독 = 1개.
- 5.28-9.57: s2 자막 단독 = 1개.
- 9.57-10.47: S1 단독 = 1개(s3 자막 시작 전, 무음 A 전환 구간).
- 10.47-11.30: s3 자막 단독 = 1개(S1 사라짐, L1 아직).
- 11.30-14.94: L1 + s3 자막 = 2개.
- 14.94-17.00: L2 + s4 자막 = 2개.
- 17.00-17.30: L2 + L3 + s4 자막 = 3개(공기->빛 전환 겹침 구간, 상한과 정확히 일치).
- 17.30-19.16: L3 + s4 자막 = 2개(L2 사라짐).
- 19.16-21.30: s5 자막 단독 = 1개(L3 사라짐, L4 아직).
- 21.30-23.25: L4 + s5 자막 = 2개.
- 23.25-23.95: L4 단독 = 1개(비트7 무음 전환, s6 시작 전).
- 23.95-24.00: s6 자막 단독 = 1개(L4 사라짐, L5 아직).
- 24.00-27.51: L5 + s6 자막 = 2개.
- 27.51-31.50: s7 자막 단독 = 1개(라벨 없음).
- 31.50-36.28: s8 자막 단독 = 1개(라벨 없음, 일상 장면으로 복귀).
- 36.28-37.28: 없음(반전 비트, 자막·라벨 없음).
- 어느 시점도 상한(3개)을 넘지 않는다. 최대 도달 지점은 17.00-17.30(L2+L3+s4=3개, 비트5).

## 숫자(N)
화면 숫자 없음. `01-fact.md`에서 B등급으로 버린 수치(성분 잔존 비율, 변색 소요 시간)는 화면·내레이션 어디에도 쓰지 않는다.

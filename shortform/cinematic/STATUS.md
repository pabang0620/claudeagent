## 업로드 형식

- 제목: `[C##] <한국어 제목> #굼구미 #상식 #쇼츠`
- 설명: 각 편 `05-meta.md`의 한국어 설명 + 해시태그
- 시청자층: 아니요, 아동용이 아닙니다
- 방법: Playwright MCP로 YouTube Studio에서 직접 예약한다. 기본 `playwright` MCP를 다른 세션이 쓰면 `playwright-music` MCP를 쓴다(굼구미 채널 로그인 확인됨). 5편씩 묶어 올리고 Shorts 목록에서 "예약됨" 날짜를 확인한다.

## 제작 방식 (C51~C100에서 굳힌 것)

- 기획(`gumgumi-cinematic-planner` + `gumgumi-explain-reviewer`)은 5편씩 병렬로, 제작(`gumgumi-animator`)은 1편씩 순차로 한다.
- 병렬 기획 때는 편마다 분야를 나눠 주제 중복을 막는다. 같은 주제가 `[N화]` 시리즈에 있어도 내용이 다르면 괜찮다(사용자 확인).
- 오디오: `finalize` headroom 0.75로 시작해 최종 mp4 피크를 -3 ~ -1dB에 맞춘다(AAC 인코딩 때 피크가 1~2.5dB 오른다).
- 라벨 지시선은 진행률을 1-p로 쓰지 않는다(C62~C64 버그 원인).
- 정지컷 PNG는 지우지 않는다(삭제는 사용자 승인 사항).
- 엔진 새 기능: `render.js --pipe`(PNG 없이 바로 mp4), `D.strata`(땅 단면), `window.CUES`(화면 동작 효과음 자동 배치).

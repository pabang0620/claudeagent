# c52 화면 글자 (내레이션 자막 제외, 자동 표시)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목은 제목카드가 보여주므로 본편에서 주제 자막 없음. 아래 예상 초는 검토용이고 애니메이터는 앵커를 쓴다.

| id | 종류 | 앵커(등장~퇴장) | ko | 위치 |
|---|---|---|---|---|
| L1 | 라벨 | s2@"컵에" ~ s2.t1+0.10 (5.5-8.9) | 컵 속 물 | 돋보기 속 단면 왼쪽 파란 물 옆, 지시선 |
| L2 | 라벨 | s2@"물방울이" ~ s2.t1+0.10 (6.8-8.9) | 겉 물방울 | 돋보기 속 단면 오른쪽 물방울 옆, 지시선 |
| S1 | 스케일 표지 | s2.t1+0.10 ~ s3.t0+0.50 (8.9-10.5) | 공기 속으로 | 그림 무대 위쪽(16%) |
| L9 | 라벨 | s3@"공기엔" ~ s3@"수증기가" (10.0-11.7) | 공기 | 회색 점 하나에 지시선 |
| L3 | 라벨 | s3@"수증기가" ~ s3.t1+0.20 (11.7-14.3) | 수증기 | 속 빈 보라 원 하나에 지시선 |
| L4 | 라벨 | s4@"공기는" ~ s4.t1 (15.9-18.0) | 식은 공기 | 컵 벽 곁 파란 띠 안, 지시선 |
| L10 | 라벨 | s5.t0-0.40 ~ s5@"조금밖에" (18.6-20.6) | 먼 공기 | 왼쪽 눈금 막대 위, 지시선 |
| L5 | 라벨 | s5@"식은" ~ s5.t1 (19.0-22.9) | 컵 곁 공기 | 오른쪽 눈금 막대 위, 지시선 |
| L6 | 라벨 | s5@"조금밖에" ~ s6.t0 (20.6-23.4) | 품는 한계 | 오른쪽 막대 점선 옆, 지시선 |
| L7 | 라벨 | s6@"물방울이" ~ s6.t1+0.20 (25.5-27.6) | 물방울 | 벽에 맺힌 하늘색 물방울 옆, 지시선 |
| L8 | 라벨 | s7@"컵" ~ s7.t1 (28.4-32.6) | 물 그대로 | 컵 속 물높이 점선 옆, 지시선 |

숫자(N): 없음. 온도, 습도, 수치는 화면에도 내레이션에도 쓰지 않는다(눈금은 높이만).

## 동시 표시 점검 (예상 초)
- 0-1.2: 없음. 1.2-5.02: s1 자막 1개.
- 5.52-8.82: s2 자막 + L1(5.5부터) + L2(6.8부터) = 최대 3개.
- 8.9-10.0: S1 단독 1개(자막 없음). 10.02-10.5: s3 자막 + S1 + L9 = 3개.
- 10.5-11.7: s3 자막 + L9 = 2개. 11.7-14.1: s3 자막 + L3 = 2개(L9는 L3 팝인 직전 퇴장). L3 퇴장 14.3.
- 14.6-18.03: s4 자막 + L4(15.9부터) = 2개.
- 18.6-19.0: 자막 없음 + L10 = 1개. 19.03-20.6: s5 자막 + L10 + L5 = 3개(L4는 18.0에 퇴장).
- 20.6-22.85: s5 자막 + L5 + L6 = 3개(L10은 20.6에 퇴장). 22.85-23.4: 자막 없음 + L5 퇴장 22.9 + L6 = 최대 2개.
- 23.45-27.4: s6 자막 + L7(25.5부터) = 2개(L6은 23.4에 퇴장).
- 28.4-32.61: s7 자막 + L8 = 2개. L7은 27.6에 퇴장.
- 어느 시점도 3개를 넘지 않는다.

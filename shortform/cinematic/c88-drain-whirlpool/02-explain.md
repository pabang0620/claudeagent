# c88 설명 사슬 - 욕조 물이 소용돌이치는 이유

## 질문

욕조 마개를 뽑으면 물은 왜 빙글빙글 돌며 빠질까.

## 의외성

"지구가 자전해서 그렇다"고 믿기 쉽다. 실제로는 욕조 크기에서 자전의 힘이 너무 약하고, 물에 남은 작은 회전이 원인이다. (s2가 "자전 때문이 아니에요"라고 말로 뒤집고 지구 -> 소용돌이 화살표 위 X가 그 뜻을 맡는다. s3이 "욕조에선 자전의 힘이 너무 약하다"를 보라 큰 호와 가는 호의 대비로 보여주고, s4가 진짜 원인으로 시선을 옮긴다.)

## "그래서?" 점검

s1 빙글 돈다 -> 자전 때문? s2 아니에요 -> 왜 아닌가? s3 욕조에선 자전의 힘이 너무 약함 -> 그럼 진짜 원인은? s4 물에 남은 작은 회전 -> 어디서 났나? s5 물 받을 때 생긴 흐름이 안 가라앉음 -> 뽑으면? s6 배수구로 모임 -> 모이면? s7 빨리 돈다 -> 왜? s8 도는 양은 거의 그대로, 원이 작아짐 -> 그래서? s9 빠른 회전이 소용돌이 -> 정리하면? s10 남은 회전이 빨라진 것. 비약 없음.

연결(이전 결과어가 다음 주어):
- s1 -> s2: "물이 돌아요"의 원인으로 믿기 쉬운 통념("자전")을 s2 "그건 지구 자전 때문이 아니에요"가 받아 부정.
- s3 -> s4: "자전의 힘이 약해요" 뒤 "진짜 원인은".
- s4 -> s5: "남은 ... 회전"을 "다 가라앉진 않았거든요"가 이유로 받음.
- s5 -> s6: 카드 표지 "물 받던 때"에서 지금(마개 뽑음)으로 돌아와 "마개를 뽑으면"으로 시작.
- s6 -> s7: "모여들어요"를 "모여드는 물은"으로 받음.
- s7 -> s8: "빨리 돌아요"의 이유를 "도는 양은 ... 원이 작아졌거든요"로.
- s8 -> s9: "그 빠른 회전이"로 s7-s8 결과를 받음.
- s9 -> s10: "소용돌이가 돼요"를 "소용돌이는"으로 받아 답으로 정리.

용어 풀이: "도는 양"(속도가 아니라 회전의 양)은 s8 문장에서 "도는 양은 거의 그대로인데, 원이 작아졌거든요"로 속도(s7 "더 빨리")와 구분해 쓴다. 막대 2개가 같은 길이라 "속도가 같다"가 아니라 "양이 같다"로 읽히고, 속도는 호 화살표 길이가 따로 보여준다. 회전량·각운동량·코리올리 용어는 쓰지 않는다.

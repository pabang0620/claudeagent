# 굼구미 시네마틱 c139 - 바지락이 입을 벌리는 이유 (9:16)

Canvas 1080x1920 (9:16), 30fps 출력, 그림은 on twos(2프레임마다 갱신), 휙 지나가는 순간(카드 자라남·줄어듦, 껍데기 벌어짐)만 on ones. 본편만 다룬다 - 브랜드 인트로·제목카드·아웃트로는 엔진이 붙인다. 제목카드가 주제를 보여주므로 본편에서 주제 자막을 다시 띄우지 않는다.

예상 본편 길이 **약 37.72초**(구간 길이 = 글자수x0.11+0.72, gap 포함, 마지막 비트 1.40초). 실제 TTS는 다를 수 있으니 앵커 기준으로 만든다. 내레이션 9구간, 비트 9개. 설명 사슬은 훅 s1 + 의외성 s2 + 반박 s3 + 인과 고리 5(s4~s8) + 답 s9.

완성 시각은 절대 초가 아니라 어절 앵커에 묶는다. 아래 괄호 안 초는 예상치다. V4 강조 자막(emph)은 별도 글자 요소가 아니다.

굼구미: 흰 몸, 잉크 `#252E3A`, 코랄 볼 `#FC876E`. 머리카락·옷·코·귀·손가락 묘사 없음. 주방 장면(비트1·8·9)은 중심 x 170, 키 250, 발 y 1235. 도식 장면(비트2~7)은 카드 아래 왼쪽(중심 x 173, 발 y 1235, 키 173, 위 1062)에서 눈과 몸 방향으로 가리킨다. 껍데기·근육·인대·화살표에 손대지 않는 관찰자이고 모든 표시와 20px 이상 떨어지며 x 85% 안쪽, y 1250 위다. 굼구미가 하는 일은 바지락을 냄비에 붓는 것(재료 준비)뿐이다.

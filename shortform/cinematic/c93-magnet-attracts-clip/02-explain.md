# c93 설명 사슬 - 자석에 클립이 붙는 이유

## 질문

자석에는 왜 클립이 붙고, 그 클립에 또 클립이 줄줄이 붙을까.

## 의외성

클립이 원래 자석이라서 붙는다고 믿기 쉽다. 실제로는 클립이 평소엔 자석이 아니고, 자석 곁에 있는 동안만 자석이 된다. (s2가 "원래 자석이라서 붙는 게 아니에요"라고 말로 뒤집고, 풍선의 "클립 = 자석"에 X가 그 뜻을 맡는다. 이어서 s3이 쇠 속 구역 이야기로 시선을 옮긴다.)

## 인과 고리 (내레이션은 narration-ko.json)

| 고리 | 내레이션(ko) | 봐야 하는 그림 | 피해야 할 오해 |
|---|---|---|---|
| 훅 s1 | 자석 아래에 클립이 줄줄이 매달려 있어요. | 막대 끝 자석 아래 클립 3개가 이어 매달림, 막대를 들고 살짝 흔드는 굼구미. 설명 없음 | 굼구미가 붙임 |
| 의외성 s2 | 클립이 원래 자석이라서 붙는 게 아니에요. | 풍선: 빨강-파랑 클립 = 자석 + X | 클립이 원래 자석 / 클립은 자석과 무관 |
| 진입 | (s3과 함께) | 맨 위 클립에서 확대 카드가 자라남. 표지 "클립 속 확대" | 새 클립 |

| 고리5 s7 | 클립의 자석 쪽 끝은 자석과 반대 극이라 당겨요. | 자석 아래 끝(빨강, 라벨 "N극")과 클립 위 끝(파랑, "S극")이 노랑 빛으로 맞닿음, 클립이 살짝 당겨짐 | 같은 극끼리 붙음 |

| 반전 A | (없음) | 굼구미가 막대를 왼쪽 위로 들어올려 자석을 치우면 빛이 꺼지고 클립이 바닥으로 떨어짐 | 클립이 계속 자석 |

답 1문장: 쇠 클립은 자석 곁에 있는 동안만 속 구역이 맞춰져 자석이 되고, 자석 쪽 끝이 반대 극이라 붙는다.

## "그래서?" 점검

s1 매달린다 -> 원래 자석이라서? s2 아니다 -> 그럼 쇠 속엔? s3 작은 자석 구역 -> 그런데 왜 평소엔 자석이 아닌가? s4 방향이 제각각이라 지워진다 -> 자석이 오면? s5 같은 방향으로 맞춰진다 -> 그래서? s6 클립이 자석이 되어 끝에 극 -> 왜 붙나? s7 반대 극이라 당긴다 -> 줄줄이는? s8 아래 클립도 똑같이 -> 결론 s9. 비약 없음.

연결(이전 결과어가 다음 주어):
- s2 -> s3: 카드가 맨 위 클립에서 자라고 문장이 "쇠 속에는"으로 시작.
- s3 구역 -> s4: "방향이" 가 구역 화살표를 받음.
- s4 지워져요 -> s5: "자석의 힘에"로 반대 상황(맞춰짐)을 이어줌.
- s5 맞춰져요 -> s6: "그러면 클립이"로 도식에서 실제 클립으로 복귀(카드가 닫히며 이어짐).
- s6 극 -> s7: "자석 쪽 끝은 ... 반대 극".
- s7 당겨요 -> s8: "위 클립 때문에"로 줄줄이로 확장.
- s8 똑같이 돼요 -> s9: "쇠 클립은 ... 곁에서만 자석이 돼서".

용어 풀이: "자석 구역"은 이름 자체가 풀이("작은 자석 구역"), "극"은 s6의 "끝에 극이"와 색띠·라벨 "S극/N극"으로 풀이. 한 편 2개.

## 그림 일관 규칙 (04와 동일)

- 대상: 굼구미 1, 막대 1, 자석 1, 클립 3, 풍선 1(클립 아이콘 1, 자석 아이콘 1, "=" 1, X 1), 카드 1(쇠 덩어리 1, 구역 6, 화살표 6, 자석 힘 화살표 2, 게이지 1).
- 색: N극 빨강, S극 파랑, 클립·쇠 은회색, 힘(합친 힘/자석 상태 빛) 노랑, 바깥에서 오는 자석 힘 보라.

## 동시 표시 점검 (자막은 해당 구간 t0~t1 동안 표시)
- 0.00-1.00: 없음. 1.00-4.36: s1 = 1. 5.16-8.30: s2 = 1. 9.00-12.14: s3 = 1.
- 12.44-12.84: S1 = 1. 12.84-13.76: S1 + s4 = 2. 13.76-14.14: S1 + L1 + s4 = 3 (상한과 일치). 14.14-16.42: L1 + s4 = 2. 16.42-16.57: L1 = 1.
- 16.82-17.22: S2 = 1. 17.22-17.48: S2 + s5 = 2. 17.48-18.62: S2 + L2 + s5 = 3 (상한과 일치). 18.62-20.80: L2 + s5 = 2. 20.80-20.90: L2 = 1.
- 21.40-21.44: s6 = 1. 21.44-24.21: L3 + s6 = 2. 24.21-24.51: L3 = 1.
- 24.51-24.91: S3 = 1. 24.91-25.50: S3 + s7 = 2. 25.50-26.21: S3 + L4 + s7 = 3 (상한과 일치). 26.21-26.49: L4 + s7 = 2. 26.49-27.50: L4 + L5 + s7 = 3 (상한과 일치). 27.50-28.82: L5 + s7 = 2. 28.82-29.02: L5 = 1.
- 29.42-29.79: s8 = 1. 29.79-31.11: L6 + s8 = 2. 31.11-32.00: L6 + L7 + s8 = 3 (상한과 일치). 32.00-32.67: L7 + s8 = 2. 32.67-32.87: L7 = 1.

- 37.44-41.02: s10 = 1. 41.02-42.32: 없음.
- V4 강조 자막(emph)은 구간 자막의 해당 어절을 키우고 색을 바꾸는 방식이며 별도 글자 요소가 아니다. 위 동시 개수에 더하지 않는다.

## 라벨 규칙 점검
- 라벨 6자 이내(공백 포함): 작은 소리 5, 빈 공간 4, 안쪽 벽 4, 소라 길이 5, 맞는 소리 5, 돌아온 소리 6, 원래 크기 5, 섞인 소리 5. 표지 10자 이내: 소리를 그려 보기 9, 소라 속 단면 7, 소리를 선으로 그림 10.
- 노출 1.5초 이상: S1 1.70, L1 2.81, S2 1.80, L2 3.42, L3 3.07, S3 1.70, L4 2.00, L5 2.53, L6 2.21, L7 1.76, L8 2.01. 전부 충족.
- 라벨은 대상이 처음 그려진 뒤 1초 안에 팝인: L1 시계 호(12.80 시작, 13.76 팝인, 0.96초), L2 빈 곳 반짝(17.48과 동시), L3 청록 호가 막힌 끝 쪽으로 다가가는 순간(21.00 이동 시작, 21.44 팝인), L4 길이 화살표(24.91 완성, 25.50 팝인), L5 호박색 물듦(26.49와 동시), L6 되돌아온 선(29.79와 동시), L7 점선 윤곽(31.11과 동시), L8 선들이 한 띠로 섞이기 시작(34.19와 동시).
- 라벨이 가리키는 단어가 발음되는 순간에 완전히 보임: L1 "작은" 14.16, L2 "비어" 17.88, L3 "안쪽" 21.84, L4 "소라" 25.90, L5 "맞는" 26.89, L6 "되돌아온" 30.19, L7 "커져요" 31.51, L8 "섞여" 34.59.
- 한 윤곽에 이름 두 개 금지: 소라 길이(화살표), 빈 공간(안쪽 전체 빈 곳), 안쪽 벽(막힌 끝의 벽), 맞는 소리(호박색 줄), 돌아온 소리(되돌아오는 점선 호박색 선), 원래 크기(점선 윤곽), 섞인 소리(청록 띠), 작은 소리(방의 청록 호)는 서로 다른 윤곽이다.

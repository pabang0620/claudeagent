한 화면 동시 최대: 내레이션 자막 1 + 라벨/표지 2 (퇴장·팝인 겹침 포함). 제목은 브랜드 제목카드가 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다. V4 강조 자막(emph)은 구간 자막의 어절을 키우는 방식이라 동시 글자 수에 더하지 않는다.

## 동시 표시 점검 (자막은 해당 구간 t0~t1 동안 표시. S2는 9.31-29.95 항상 1개로 센다)

- 5.04-8.51: s2 = 1. 8.51-9.31: 없음(말풍선 X hold).
- 9.31-10.81: S2 + L1 + L2 = 3 (자막 없음). 10.81: L1·L2 퇴장 후 s3 시작이라 겹침 없음.

## 라벨 규칙 점검
- 라벨 6자 이내: 피부 2, 속살 2, 신경 2, 혈관 2, 원래 크기 5, 주름 2. 표지 10자 이내: 한참 뒤 4, 손끝 단면 (과장) 10.
- 노출 1.5초 이상: S1 1.50, S2 20.64, L1 1.50, L2 1.50, L3 2.84, L4 1.50, L5 1.89, L6 2.63, L7 3.50, L8 1.67. 전부 충족.
- L1·L2는 줌 인 휩(8.91-9.31)이 끝난 9.31에 팝인해 읽을 수 있는 노출이 1.5초다. 고리와 속살은 휩 도중에 그려져 완성되므로 지시선은 빈 곳을 가리키지 않는다.
- 대상이 처음 그려진 뒤 1초 안에 팝인: L1·L2 단면 완성 9.31과 동시, L3 신경선 그리기 시작 11.50에서 0.34초, L4 혈관 등장 14.80에서 0.21초, L5 점선 윤곽 등장과 동시, L6 재등장(처음 9.31에 이름 붙음), L7 재등장, L8 접힘이 시작되는 27.95에서 0.33초.
- 라벨 팝인은 가리키는 어절 0.3~0.5초 전: L3 s3@"신경이"(12.24), L4 s4@"혈관이"(15.41), L5 s4@"좁아져요"(16.84), L6 s5@"속살이"(20.13), L7 s6@"겉피부는"(23.20), L8 s7@"주름져요"(28.68). 비트 끝에 몰아서 띄운 라벨 없음.
- 한 윤곽에 이름 두 개 금지: 피부는 바깥 고리, 속살은 안쪽 분홍, 신경은 노란 선, 혈관은 빨간 원, 원래 크기는 점선 윤곽(혈관 둘레)만 가리킨다. 속살의 점선 윤곽(비트5)과 괄호(비트6)는 새 라벨 없이 같은 약속으로 이어진다.
- 간격: 칩끼리 20px 이상(L1 x 720-868과 L3 x 540-688은 32px, L4 x 100-248과 L5 x 560-870은 312px, L2 x 90-238과 L3는 302px). S2(y 270-340)와 칩(y 470-540)은 130px. 칩과 패널 위 테두리(y 441) 29px, 오른쪽 테두리(x 900)와 32px. 칩은 도식 위 띠 안(y 470-540)이며 고리 윗면(y 560)과 20px 이상. 자막 띠(y 1250 이하)에 칩 없음.

# c124 02-explain - 설명 사슬

## 질문
목욕을 오래 하면 왜 손끝이 쭈글쭈글해질까.

## 의외성
"물에 불어서 쭈글해진다"고 다들 생각하지만, 이 주름은 물에 불어서만 생기지 않는다. 손끝 신경이 혈관을 좁히는 신호를 보내서 생긴다(A).

## 인과 고리 (4개) 와 내레이션

| 구간 | 내레이션(ko) | 봐야 하는 그림 | 피해야 할 오해 |
|---|---|---|---|
| s1 (훅) | 목욕을 오래 하면 손끝이 쭈글쭈글해져요. | 욕조에서 한참 뒤 굼구미 손끝에 굵은 주름 | 설명 없이 장면만 |
| s2 (의외성) | 이 주름은 물에 불어서만 생기는 게 아니에요. | 말풍선: 물이 스며들어 살짝 부푼 손끝 + X | "물을 전혀 안 머금는다"로 오해 -> "만"으로 한정, 부풀림은 작게 |
| s3 (고리1) | 물에 오래 닿으면 손끝 신경이 신호를 보내요. | 손끝 단면: 겉피부 고리, 속살, 아래 물방울, 신경선과 신호 구슬 | 신경이 직접 피부를 쪼그라뜨린다는 오해 -> 신호는 혈관 쪽으로 간다 |
| s4 (고리2) | 손끝 혈관이 그 신호를 받아 좁아져요. | 혈관 둘이 나타나 가늘어짐 + 점선 원래 크기 | 혈관이 막힌다는 오해 -> 가늘어질 뿐 |
| s5 (고리3) | 손끝에 피가 덜 차면 속살이 쪼그라들어요. | 혈관 안 빨강이 줄고 속살이 점선 원래 크기 안쪽으로 줄어듦 | 혈관 두 개가 줄어든 만큼 속살이 줄었다는 오해 -> 크기 비교 없음, 정도는 과장 |
| s6 (고리4) | 그런데 겉피부는 줄지 않고 남아 있어요. | 고리 흰 윤곽 강조, 같은 폭 괄호로 줄지 않음을 보임 | 정확한 수치 -> 수치 없음 |
| s7 (답) | 속살은 줄고 남은 겉피부가 접혀 주름져요. | 고리가 물결로 접히고 라벨 "주름" | 비유로 오해 -> 도식 그대로, 주름 모양은 단순화 |

## 답 1문장
물에 오래 닿으면 신경 신호로 손끝 혈관이 좁아져 속살이 줄고, 줄지 않은 겉피부가 접혀 주름이 된다.

## "그래서?" 점검

- 훅: 손끝이 쭈글해진다. 그래서? -> 물에 불어서일까(s2)
- s2: 불어서만은 아니다. 그래서? -> 진짜 원인은 몸이 보내는 신호(s3)
- s3: 신경이 신호를 보낸다. 그래서? -> 신호를 받은 혈관이 좁아진다(s4)
- s4: 혈관이 좁아진다. 그래서? -> 피가 덜 차 속살이 줄어든다(s5)
- s5: 속살이 줄었다. 그래서? -> 겉피부는 줄지 않고 남는다(s6)
- s6: 겉피부는 남는다. 그래서? -> 남은 겉피부가 접혀 주름이 된다(s7)
- s7: 접혀 주름 -> 훅의 손끝 주름으로 복귀(비트8 되감기)

비약 없음. 각 고리의 "왜" 한마디: s3 물에 오래 닿으면, s4 그 신호를 받아, s5 피가 덜 차면, s6 그런데(속과 대비), s7 줄고 남은 겉피부가 접혀.

# c04 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("신선한 달걀일수록 안 까지는 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

## 동시 표시 점검
- 5.71-6.01: L3+L4 = 2개(내레이션 자막 시작 전).
- 6.01-9.57: L3+L4+s2 자막 = 3개(상한과 정확히 일치, 초과 아님).
- 9.57-10.07: L3+L4 단독 = 2개.
- 10.07-11.50: L3+L4+s3 자막 = 3개.
- 11.50-14.15: s3 자막 단독 = 1개.
- 14.15-14.95: S1 단독 = 1개(전환 A 비트, 자막 없음).
- 16.30-18.87: L1+s4 자막 = 2개.
- 19.27-21.00: L2+s5 자막 = 2개.
- 21.00-23.48: L3+L4+s5 자막 = 3개.
- 23.48-23.58: L3+L4 단독 = 2개(s5 자막 종료 후 짧은 꼬리).
- 23.88-26.60: L5+s6 자막 = 2개.
- 26.60-27.83: L5+L6+s6 자막 = 3개.
- 27.83-27.93: L5+L6 단독 = 2개.
- 28.23-28.50: L6+L7+s7 자막 = 3개(전환 구간, 상한 이내).
- 28.50-32.05: L7+s7 자막 = 2개.
- 32.05-32.35: L7 단독 = 1개.
- 32.65-36.99: s8 자막 단독 = 1개(라벨 없음).
- 어느 시점도 상한(3개)을 넘지 않는다.

## 숫자(N)
화면 숫자 없음. `01-fact.md`의 A등급 숫자(흰자 pH 변화 수치, 기공 개수)는 정확한 값이 조건에 따라 갈리는 세부(B등급)이거나 30자 이내 자막 원칙에 맞지 않아 화면에 쓰지 않는다.

# c14 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("삶은 달걀이 딱딱해지는 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용, 글자수x0.13초+0.7초 공식). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

## 동시 표시 점검
- 0.00-11.29: 자막(s1~s3)만 순차 표시 = 각 1개.
- 11.29-12.09: S1 단독 = 1개(s4 자막 시작 전, 무음 A 전환 구간).
- 12.09-13.26: S1 + s4 자막 = 2개.
- 13.26-13.60: S1 + L1 + s4 자막 = 3개(상한과 정확히 일치, 초과 아님).
- 13.60-15.91: L1 + s4 자막 = 2개.
- 15.91-18.00: 없음(고리1→고리2 전환 간격, s5 시작 전).
- 18.00-19.74: L2 + s5 자막 = 2개.
- 19.74-20.14: L2 단독 = 1개(s5 종료 후 짧은 꼬리).
- 20.14-21.50: s6 자막 단독 = 1개(라벨 시작 전).
- 21.50-23.83: L3 + s6 자막 = 2개.
- 23.83-24.23: 없음(전환 간격, s7 시작 전).
- 24.23-25.50: s7 자막 단독 = 1개(라벨 시작 전).
- 25.50-27.79: L4 + s7 자막 = 2개.
- 27.79-28.29: L4 단독 = 1개(s7 종료 후 짧은 꼬리).
- 28.29-29.50: s8 자막 단독 = 1개(라벨 시작 전).
- 29.50-31.20: L5 + s8 자막 = 2개.
- 31.20-31.80: L5 단독 = 1개(s8 종료 후, s9 시작 전).
- 31.80-32.00: L5 + s9 자막 = 2개(용어 라벨 꼬리와 복귀 자막 겹침).
- 32.00-35.62: s9 자막 단독 = 1개(라벨 없음, 일상 장면으로 복귀).

# c56 화면 글자 (내레이션 자막은 자동이라 제외)

앵커는 내레이션 id 기준이다. 라벨은 그 대상을 말하는 어절이 발음되는 순간 팝인한다. 좌표는 1080x1920 기준 px(글자 중심).

|---|---|---|---|---|

- 숫자 N 없음(화면 숫자 없음). 확대 창 속 "−" 기호는 전자 점의 일부(글자 아님).
- 동시 글자 점검(자막 포함): 비트 2(s2) 자막+L1+L2=3 / 비트 3(s3) 자막+S1+L3=3(L1은 s3.t0-0.40, L2는 s3.t0-0.10에 퇴장해 L3 팝인 전) / 비트 4(s4) 자막+L3+L4=3(S1은 s3.t1 퇴장) / 비트 5(s5) 자막+L3+L5=3 / 비트 6(s6) 자막+L3+L6=3(L5는 s6.t0-0.40 퇴장) / 비트 7(s7) 자막+S2+L3=3(L6은 s7.t0-0.40 퇴장) / 비트 8(s8) 자막+L3+L1=3(S2는 s8.t0-0.40 퇴장) / 비트 9(s9) 자막+L3+L1=3. 최대 3.
- 노출 시간(1.5초 이상): L1 s2 약 3.8초, s8-s9 약 7.7초 / L2 약 2.8초 / S1 약 4.0초 / L3 약 28초(연속) / L4 약 4.1초 / L5 약 3.9초 / L6 약 3.8초 / S2 약 3.8초.
- 핵심 비트에서 라벨 유지: 전자 라벨(L3)은 전자가 나오는 모든 비트(s3-s9)에 있고, 금속 손잡이 라벨(L1)은 손잡이가 핵심인 s2, s8, s9에 있다.
- 비트 1(훅)과 비트 10(반전)에는 글자가 없다(자막만, 비트 10은 자막도 없음).

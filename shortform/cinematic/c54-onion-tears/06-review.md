2. 비트4-6 라벨과 굼구미 겹침(7절): 확대 창 A는 반지름 324px, 중심 x 562px로 왼쪽 끝이 x 약 238px(22%W)다. 굼구미는 x 26%W(약 281px)에 키 269px로 서 있어 창 아래쪽 원호와 겹친다. L4와 L5는 창 위쪽 바깥(y 18-24%H)이나 오른쪽 여백으로 옮긴다. 오른쪽 쇼츠 UI 영역(82%W 밖)은 피한다.

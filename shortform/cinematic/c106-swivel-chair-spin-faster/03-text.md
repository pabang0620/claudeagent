# c106 화면 글자 (내레이션 자막 제외 - 자동 표시)

한 화면 동시 최대: 내레이션 자막 1 + 라벨/표지 2 (퇴장·팝인 겹침 포함). 제목은 브랜드 제목카드가 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다.

시각은 `narration-ko.json` 기준 예상 절대 초(글자수x0.11+문장끝 0.5, 검토용)다. 실제 값은 TTS 후 확정하고 애니메이터는 앵커를 쓴다.

s2를 25자로 늘려(주어 "회전이" 추가) s2 끝과 s3 이후 구간의 예상 초는 아래 표보다 약 +0.44초 뒤로 밀린다. 아래 초는 변경 전 계산이므로 앵커(`sN.t0`, 어절)를 기준으로 쓴다.

내레이션 구간 시각(예상, s2 변경 전): s1 1.20-4.12 / s2 4.92-7.73 / s3 8.43-11.02 / s4 11.92-15.06 / s5 15.76-18.90 / s6 19.60-22.52 / s7 23.22-26.03 / s8 26.93-30.29.

## 동시 표시 점검 (자막은 해당 구간 t0~t1 동안 표시)
- 0.00-1.20: 없음. 1.20-4.12: s1 = 1.
- 4.92-7.73: s2 = 1.
- 8.43-9.97: s3 = 1. 9.97-11.02: L1 + s3 = 2. 11.02-11.52: L1 = 1 (S1은 11.62에 뜨므로 겹치지 않음).
- 강조 자막(emph)은 해당 어절이 자막 띠 안에서 커지는 효과이며 별도 글자로 세지 않는다. 따라서 자막 1 + 라벨 2 한도에 포함하지 않는다. 애니메이터는 강조 어절을 자막 띠(y 66~76%) 밖으로 따로 띄우지 않는다.
- 11.62-11.92: S1 = 1. 11.92-12.58: S1 + s4 = 2. 12.58-13.30: S1 + L2 + s4 = 3 (상한). 13.30-13.35: L2 + s4 = 2. 13.35-14.12: L2 + L3 + s4 = 3 (상한). 14.12-15.00: L3 + L4 + s4 = 3 (s4는 15.06까지). 15.00-15.06: L4 + s4 = 2. 15.06-15.62: L4 = 1.
- 15.76-17.08: s5 = 1. 17.08-18.90: L5 + s5 = 2. 18.90-19.60: L5 = 1.
- 19.60-20.26: L5 + s6 = 2. 20.26-20.60: L5 + L6 + s6 = 3 (상한). 20.60-20.70: L6 + s6 = 2. 20.70-22.52: L6 + L7 + s6 = 3 (상한). 22.52-22.70: L6 + L7 = 2.
- 23.22-26.03: s7 = 1 (라벨 없음). 26.93-30.29: s8 = 1 (라벨 없음). 30.29-30.99: 없음.
- 어느 시점도 3개를 넘지 않는다.

## 라벨 규칙 점검
- 라벨 6자 이내(공백 포함): 밀기 없음 5, 팔의 무게 5, 회전축 3, 퍼짐 2, 도는 양 4(공백 포함), 속도 2. 표지 10자 이내: 위에서 본 모습 8(공백 포함).
- 노출 1.5초 이상: L1 1.55, S1 1.68, L2 1.54, L3 1.65, L4 1.50, L5 3.52, L6 2.44, L7 2.00. 전부 충족.
- 대상이 처음 그려진 뒤 1초 안에 팝인: L1 화살표 8.90 시작, X 9.97과 같은 순간 라벨 팝인(표시 성립 뒤), L2 추 scale-in 11.62 -> 12.58(0.96), L3 축 링 12.95 -> 13.35, L4 반지름 화살표 13.70 -> 14.12, L5 직사각형 16.64 -> 17.08, L6 가로 괄호 19.90 -> 20.26, L7 세로 괄호와 파랑 꼬리 호 20.40(첫 등장) -> 20.70.
- 라벨은 가리키는 단어가 발음되는 순간 팝인: L1 "아니에요"(X 찍힘), L2 "무게가", L3 "축에서", L4 "퍼져요", L5 "도는", L6 "퍼짐과", L7 "속도를".
- 한 윤곽에 이름 두 개 금지: "퍼짐"은 L4(초록 반지름 화살표)와 L6(초록 가로 괄호) 모두 같은 초록 색의 같은 개념이고 서로 다른 시각(L4 퇴장 15.62 뒤 L6 20.26)에 다른 윤곽을 가리킨다. 한 윤곽에 이름이 겹치지 않는다. "도는 양"은 보라 직사각형 하나만 가리킨다.
- 레이아웃 간격: 칩끼리·칩과 패널 테두리 20px 이상. 칩 최대 y 1206, 자막 띠(y 1250 이하)와 44px.

# 굼구미 시네마틱 c135 - 냄새를 오래 맡으면 안 느껴지는 이유 (9:16)

Canvas 1080x1920 (9:16), 30fps 출력, 그림은 on twos(2프레임마다 갱신), 휙 지나가는 순간(패널 자라남, 확대 전환, 패널 줄어듦)만 on ones. 본편만 다룬다 - 브랜드 인트로·제목카드·아웃트로는 엔진이 붙인다. 제목카드가 주제를 보여주므로 본편에서 주제 자막을 다시 띄우지 않는다.

예상 본편 길이 **약 36.73초**(구간 길이 = 글자수x0.11+0.72, gap 포함, 비트10 1.40초). 실제 TTS는 이보다 짧거나 길 수 있고 앵커 기준으로 만든다. 내레이션 9구간, 비트 10개. 설명 사슬은 훅 s1 + 의외성 s2 + 인과 고리 3(s3-s6, s7, s8) + 답 s9. 어절 앵커(`s7@"계속되면"` 등)가 우선이고 괄호 안 초 값은 예상치다.

V4 강조 자막(emph)은 구간 자막의 해당 어절을 키우는 방식이라 별도 글자 요소가 아니다(동시 글자 3개 상한에 더하지 않는다).

굼구미: 흰 몸, 잉크 `#252E3A`, 코랄 볼 `#FC876E`. 머리카락·옷·코·귀·손가락 묘사 없음. 빵집 장면(비트1·2·9·10)에서는 왼쪽(중심 x 216, 발 y 1180, 키 250, 몸 오른쪽 끝 약 316)에 선다. 도식 장면(비트3~8)에서는 패널 아래 왼쪽(중심 x 173, 발 y 1230, 키 168, 위 1062)에서 눈과 몸 방향으로 가리킨다(발은 자막 띠 1250과 20px, 위는 패널 아래 1037과 25px). 도식 속 알갱이·세포·신호·뇌에 손대지 않는 관찰자·안내자다. 코가 없으므로 냄새는 노란 줄무늬 앞에서 들뜨고 멍해지는 몸짓(들썩, 눈 `eyeOpen` 변화, 고개 기울임)으로만 보인다. 코·뇌는 굼구미 몸이 아니라 "사람 머리 단면" 도식과 뇌 아이콘으로만 그린다.

## 과장 명시 (비트3~8)

냄새 알갱이(지름 64)와 세포 크기, 머리 단면 대비 알갱이 크기, 신호 점(지름 60) 개수와 속도는 개념을 보이려는 크기·단순화이며 실제 척도가 아니다. 알갱이가 눈에 보이는 크기라는 뜻이 아니다. 그래서 S1 "과장해 그림"을 비트3 시작(7.71)부터 비트9 복귀가 끝나는 31.53까지 계속 띄운다. 시간 규모를 뜻하는 글자는 화면에 쓰지 않고 시계 그림만 쓴다.

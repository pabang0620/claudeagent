# c34 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("바다가 파랗게 보이는 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

|---|---|---|---|---|---|
| S1 | 스케일 표지 (D.scaleBadge) | 9.70-11.90 | 물속으로 확대 | Zoom into the water | 그림 무대 위쪽 |

## 동시 표시 점검
- 0.00-1.30: 없음(훅 세팅, 내레이션 시작 전).
- 1.30-5.12: 자막(s1)만 = 1개.
- 5.12-5.62: 없음(전환 간격).
- 5.62-9.70: 자막(s2)만 = 1개.
- 9.70-10.10: S1만 = 1개(진입 A 비트, 무음 전환).
- 10.10-10.50: S1만 = 1개(도식 그려지기 시작, s3 시작 전).
- 10.50-11.90: 자막(s3) + S1 = 2개.
- 11.90-13.80: 자막(s3)만 = 1개(S1 종료).
- 13.80-14.20: 없음(고리1→고리2 전환 간격, 그림은 이미 그려지는 중).
- 14.20-14.25: 자막(s4)만 = 1개(L1 시작 전).
- 14.25-17.89: 자막(s4) + L1 = 2개.
- 17.89-18.29: 없음(고리2→고리3 전환 간격, L1 이미 종료).
- 18.29-18.34: 자막(s5)만 = 1개(L2 시작 전).
- 18.34-21.85: 자막(s5) + L2 = 2개.
- 21.85-22.25: L2만 = 1개(전환 간격, 자막 없음).
- 22.25-25.55: 자막(s6) + L2 = 2개.
- 25.55-26.15: 없음(복귀 전환 간격, L2 종료).
- 26.15-30.10: 자막(s7)만 = 1개(일상 장면으로 복귀, 라벨 없음).
- 30.10-31.30: 없음(반전 비트, 자막·라벨 없음).
- 어느 시점도 상한(자막1+라벨2=3)을 넘지 않는다. 이번 판은 최대 동시 2개로 여유 있게 유지된다.

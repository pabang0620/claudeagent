# c110 화면 글자 (내레이션 자막 제외 - 자동 표시)

한 화면 동시 최대: 내레이션 자막 1 + 라벨/표지 2 (퇴장·팝인 겹침 포함). V4 강조 자막은 내레이션 자막이 튀는 표현이라 자막 1개로 센다. 애니메이터는 아래 3개인 구간(4.05-6.21, 7.94-8.20, 15.70-16.50, 25.28-27.00, 28.07-29.95)에서 강조 자막이 라벨을 추가로 만들어 4개가 되지 않는지 렌더 때 확인한다. 제목은 브랜드 제목카드가 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다.

시각은 `narration-ko.json` 기준 예상 절대 초(글자수x0.11, gap_before 반영, 검토용)다. 실제 값은 TTS 후 확정하고 애니메이터는 앵커를 쓴다.

내레이션 구간 시각(예상): s1 1.00-3.31 / s2 4.01-6.21 / s3 6.91-9.77 / s4 10.67-13.42 / s5 14.12-16.65 / s6 17.35-19.88 / s7 20.58-23.66 / s8 24.36-27.00 / s9 27.70-30.23 / s10 31.13-34.43.

**라벨 팝인은 가리키는 어절 시작보다 0.4초 먼저**이고, 가리키는 대상은 그보다 먼저(또는 같은 시각에 시작해 팝인 전에) 그려진다.

라벨 칩 폭은 공백 포함 글자수x54+40px, 높이 약 70px. 지시선은 칩 끝에서 대상의 해당 부위로. 표지(S)는 상단 중앙 x 540 기준, y 270-340.

## 라벨 규칙 점검
- 라벨 6자 이내(공백 포함): 같은 양 4, 쏠림 2, 가려는 쪽 5, 벽의 힘 4, 미는 힘 4, 무거운 쪽 5, 방향 바뀜 5, 통의 움직임 6. 표지 10자 이내: 확대, 떨림 과장 9, 한 덩어리만 보기 9, 과장해 그림 6.
- 노출 1.5초 이상: S1 4.49, L1 2.50, L2 2.40, S2 1.63, L3 1.66, L4 1.57, L5 1.60, L6 1.62, S3 8.33, L7 2.02, L8 1.88. 전부 충족.
- 라벨은 대상이 그려진 뒤 1초 안에 팝인(대상은 팝인 시각 이전에 그려지기 시작): L1 두 통과 6덩이(3.85 그려짐, 4.05), L2 보라 링(7.60 시작, 7.90 완성, 7.94), L3 호박색 화살표(11.61 시작, 12.10 완성, 12.14), L4 초록 화살표(14.65 시작, 15.10 완성, 14.93), L5 빨강 화살표(15.40 시작, 15.75 완성, 15.70), L6 쌓인 덩어리(17.39 이동 시작, 18.67 쌓임 완성, 18.93), L7 네 위치 화살표(24.80 첫 화살표 시작, 25.28), L8 유령 점선 통 윤곽(27.30 시작, 28.57 완성, 28.07).
- 라벨 팝인은 가리키는 어절보다 0.4초 먼저: L1 "많아서만"(4.45), L2 "쏠린"(8.34), L3 "날아가려"(12.54), L4 "눌리고"(15.33), L5 "되밀어요"(16.10), L6 "무거워요"(19.33), L7 "방향도"(25.68), L8 "이쪽저쪽"(28.47).
- 한 윤곽에 이름 두 개 금지: L2 "쏠림"은 비트3 보라 링에, L6 "무거운 쪽"은 비트6에서 새로 쌓인 덩어리에 붙는다. L2는 10.34에 퇴장하고 L6은 18.93에 처음 뜬다. 초록 화살표는 L4 "벽의 힘"만, 빨강 화살표는 L5 "미는 힘"만(비트7 이후 빨강 화살표는 이미 이름이 붙은 같은 개념이라 라벨을 다시 달지 않음), 호박색 화살표는 L3 "가려는 쪽"만 받는다.
- 통(세탁기 속 통)은 훅에서 세탁기 창으로 먼저 보이는 일상 사물이라 별도 라벨을 달지 않는다. 처음 나오는 과학 대상(같은 양, 쏠린 덩어리, 화살표 3종, 무거운 쪽, 방향 바뀜, 통의 움직임)마다 라벨이 있다.
- 레이아웃 간격: 칩끼리·칩과 굼구미·칩과 패널 테두리 20px 이상(좌표는 04-storyboard.md). 칩 위쪽 줄은 y 371-441로 패널 윗변 461과 20px, 표지 270-340과 31px. 칩 아래쪽 줄은 y 1060-1130으로 패널 아랫변 1037과 23px, 자막 띠(y 1250 이하)와 120px.

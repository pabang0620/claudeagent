# c29 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("눈썹이 안 자라는 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

## 동시 표시 점검
- 0.0-1.2: 없음(훅 시작 전 정적).
- 1.2-5.4: s1 자막 단독 = 1개.
- 5.4-6.0: 없음(간격).
- 6.0-9.8: s2 자막 단독 = 1개.
- 9.8-10.5: S1 단독 = 1개(진입 비트, 내레이션 없음).
- 10.5-11.9: S1 + s3 자막 = 2개.
- 11.9-13.4: L1 + s3 자막 = 2개(S1 소멸 후).
- 13.4-14.6: L1 + L2 + s3 자막 = 3개(상한과 정확히 일치, 초과 아님).
- 14.6-15.0: L2 단독 = 1개(s3 종료, s4 시작 전 간격).
- 15.0-18.8: L3 + L4 + s4 자막 = 3개(상한과 정확히 일치).
- 18.8-19.2: 없음(간격, L3·L4 소멸).
- 19.2-22.7: L1 + L3 + s5 자막 = 3개(상한과 정확히 일치).
- 22.7-23.1: 없음(간격).
- 23.1-25.0: L4 + s6 자막 = 2개(L2 재등장 전).
- 25.0-26.4: L4 + L2 + s6 자막 = 3개(상한과 정확히 일치).
- 26.4-27.0: 없음(간격).
- 27.0-30.1: s7 자막 단독 = 1개(복귀, 라벨 없음).
- 30.1-30.6: 없음(간격).
- 30.6-34.8: L3 + L4 + s8 자막 = 3개(상한과 정확히 일치).
- 34.8-35.8: 없음(반전 버튼, 자막·라벨 없음).

## 숫자(N)
화면 숫자 없음. `01-fact.md`에서 버린 사실(성장기 길이의 정확한 연·주 수치)은 대본 규칙에 따라 화면에 쓰지 않는다. "몇 년씩"/"몇 주 만에"라는 정성적 표현과 타임라인 바의 상대적 길이 차이만으로 비교를 보여준다.

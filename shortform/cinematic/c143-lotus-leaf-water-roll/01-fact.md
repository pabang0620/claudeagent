# c143 사실 정리 - 연잎 위 물방울이 구르는 이유

주제: 비 온 뒤 연잎 위 물방울이 동글동글 굴러다니는 현상. 분야: 풀·나무·잎(잎 표면). 겹침 확인: c85 빛 쪽으로 휨, c107 솔방울, c120 버섯, c136 단풍 씨앗, c39 나이테, c40 선인장 가시, c57 은행 노랑과 다른 질문이다. "연잎/물방울 구름"은 cinematic 폴더 전수와 episodes에 없다(연잎·연꽃 검색 결과 0건).

종 한정: 연잎(과 토란잎처럼 비슷한 표면을 가진 잎)에 해당한다. 모든 잎이 아니다. 내레이션은 "연잎"으로만 말한다.

## 핵심 사실

| # | 사실 | 등급 | 근거 |
|---|---|---|---|
| F1 | 연잎 표면은 매끈하지 않고 아주 작은 돌기가 빽빽하다 | A | 연잎 효과, 교과서·대중과학 수준 합의 |
| F2 | 돌기 위는 왁스 성분으로 덮여 물과 잘 어울리지 않는다(소수성) | A | 표면 왁스 결정, 합의 |
| F3 | 물은 서로 끌어당기는 힘 때문에 어울리지 않는 표면 위에서 둥글게 뭉친다 | A | 표면장력, 교과서 |
| F4 | 뭉친 물방울은 돌기 끝에만 얹히고 돌기 사이 틈에는 공기가 낀다 | A | 연잎 효과의 핵심 설명(공기층 위에 얹힘) |
| F5 | 닿는 면이 적을수록 표면이 물방울을 붙잡는 힘이 약하다 | A (정성) | 접촉 면적과 붙는 힘의 관계. 수치 없음 |
| F6 | 붙잡는 힘이 약해서 아주 조금만 기울어도 물방울이 굴러간다 | A | 연잎 효과 |

## 인과 고리 후보와 등급

| 고리 | 내용 | 등급 | 근거 |
|---|---|---|---|
| 1 s3 | 연잎 표면은 작은 돌기로 오돌토돌하다 | A | F1 |
| 2 s4 | 돌기 위 왁스는 물과 안 어울려 물끼리 뭉친다(물끼리 끌어당기기 때문) | A | F2, F3 |
| 3 s5 | 뭉친 물방울은 돌기 끝에만 얹히고 아래는 공기다 | A | F4 |
| 4 s6 | 연잎은 매끈한 면보다 닿는 곳이 적어 덜 붙잡는다 | A (정성) | F5 |
| 답 s7 | 그래서 연잎 위 물방울은 살짝만 기울어도 구른다 | A | F6 |

## 버린 사실과 이유

| 버린 것 | 이유 |
|---|---|
| 접촉각 수치(150도 이상 등), 돌기 크기 수치 | 출처별 표기 차이(B). 숫자 없음 |
| 굴러가며 먼지를 씻어내는 자정 작용 | 고리가 늘고 다음 질문이 됨. 6고리 미만 유지 |
| 나노 왁스 결정의 이중 구조 | 설명이 길어짐. "작은 돌기 + 왁스"로 단순화 |
| 모든 잎이 물을 튕긴다는 일반화 | 틀림. 연잎으로 종 한정 |
| 연꽃이 진흙에서 깨끗이 피는 상징 이야기 | 과학 인과가 아님 |

## 비유 오류 점검표

| 비유·그림 | 시청자가 받을 인상 | 실제 메커니즘 | 맞는가 |
|---|---|---|---|
| 돌기 5개를 높이 100, 폭 100으로 확대해 그림 | 잎 표면에 작은 돌기가 있다 | 실제는 훨씬 작고 빽빽함 | 맞음. S1 "확대해 과장해 그림"을 단다 |
| 돌기 위 연노랑 얇은 막 = 왁스 | 돌기가 왁스로 덮여 있다 | 맞음 | 맞음 |
| 작은 물방울 3개(지름 150)가 합쳐져 큰 방울(폭 460 x 높이 147) | 물이 모여 둥글게 뭉친다. 총량은 같다 | 작은 방울이 합쳐짐, 부피 보존 | 맞음. 합치기 전후 면적을 약 53,000으로 맞춰 "양이 늘어난다"로 읽히지 않게 함. 방울이 닿을 때 가운데 목이 생겨 물끼리 끌려 합쳐지는 모습으로 "물끼리 끌어당김"을 보임. 개수는 과장(S1) |
| 장면의 방울 3개(지름 70)가 합쳐져 지름 120 | 같은 양이 하나로 모임 | 면적 3 x 35^2 = 지름 120 원 | 맞음(비트1, 비트7 방울과 일관) |
| 방울이 돌기 끝 3곳에만 닿고 아래 틈은 공기 | 닿는 곳이 적고 아래는 비어 있다 | 맞음 | 맞음 |
| 분홍 고리 = 닿는 곳 | 닿는 지점의 표시 | 맞음 | 맞음 |
| 매끈한 면의 점선 유령(길게 닿는 선) | 매끈하면 방울 바닥 전체가 닿는다 | 같은 왁스의 매끈한 면에서는 닿는 면이 넓고 더 잘 붙음 | 정성적으로 맞음. "더 붙잡는다" 수준이며 "안 구른다"는 말은 하지 않는다 |
| 주황 화살표 = 붙잡는 힘(실선 3개, 점선 4개는 매끈한 면 유령 묶음으로 같은 시각에 그려지고 라벨 "매끈한 면"에 속함) | 닿는 곳이 많을수록 붙잡는 힘이 크다 | 접촉 면적에 비례하는 정성 관계 | 맞음. 개수는 정성 비교용 |
| 굼구미가 잎 가장자리를 살짝 들어 기울임 | 기울이는 실험 | 기울기는 원인(조건)이고 굼구미는 조건만 바꿈 | 맞음. 구르는 힘은 중력 |

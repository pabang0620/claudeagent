# c127 설명 사슬 - 수도꼭지 물줄기가 아래로 갈수록 가늘어지는 이유

## 질문
수도꼭지에서 나온 물줄기는 왜 아래로 갈수록 가늘어질까.

## 의외성
"물이 줄어서 가늘어진다"고 생각하기 쉽지만 물의 양은 그대로다. 달라지는 건 물이 내려가는 빠르기다.

## 인과 고리 (3개 + 답)

| 고리 | 내레이션 (ko) | 봐야 하는 그림 | 피해야 할 오해 |
|---|---|---|---|
| 훅 s1 | 수도꼭지 물줄기는 아래로 갈수록 가늘어져요. | 주방 싱크대 수도꼭지, 위는 굵고 아래는 가는 물줄기 (설명 없음) | - |
| 의외성 s2 | 물이 줄어서 가늘어지는 게 아니에요. | 생각 풍선 속 물이 옆으로 빠져나가는 줄어듦 + X | 물이 줄지 않는다는 말이 줄기가 안 가늘어진다는 읽힘 |
| 1 s3 | 같은 시간에 지나가는 물의 양은 어디서나 같아요. | 옆모습 도식(납작한 띠, 옆면 면적이 같은 조각 4개: 위는 짧고 굵고 아래는 길고 가늚, 같은 색). 물줄기를 같은 양의 물 조각으로 나눔. 위 선과 아래 선이 동시에 깜빡이고 "=" | 조각이 실제로 끊겨 내려간다는 인상 (라벨 "물 조각"과 흐르는 연속 표현으로 완화) |
| 1 s4 | 중간에 물이 쌓이거나 사라지지 않으니까요. | 두 선 사이 "중간" 괄호. 쌓임·새어나감 점선 윤곽에 X | 물줄기 중간에서 물이 새는 그림으로 읽힘 |
| 2 s5 | 떨어지는 물은 중력 때문에 점점 빨라져요. | 빨간 중력 화살표, 위에서 아래로 길어지는 주황 빠르기 화살표 | 위 물은 가만히 있다는 인상 |
| 3 s6 | 아래는 빨라서 폭이 좁아도 같은 양이 지나가요. | 위 조각이 아래로 내려가며 길고 가늘어짐(유령 윤곽), 보라 폭 표시, "=" | 폭이 줄어드니 양도 줄어든다는 인상 |
| 답 s7 | 그래서 물줄기는 빨라진 만큼 가늘어져요. | 실제 싱크대 물줄기 위에 주황·보라 표시 겹침 | - |

## 답 1문장
물줄기는 아래로 갈수록 빨라지고, 같은 양이 지나가야 하니 그만큼 가늘어진다.

## "그래서?" 점검
1. 물이 줄지 않는다면 왜 가늘어지지? -> 어디서나 같은 시간에 지나가는 양이 같아서 폭이 달라진다.
2. 왜 양이 같지? -> 중간에 쌓이거나 사라지지 않는다.
3. 그런데 왜 폭이 달라지지? -> 떨어지며 빨라지기 때문이다.
4. 빨라지면 왜 좁아도 되지? -> 빠른 곳은 좁아도 같은 양이 지나간다.
5. 결론 -> 빨라진 만큼 가늘어진다. 비약 없음.

## 과학 정확성 점검

- 연속의 원리를 "같은 시간에 지나가는 양이 같다"로 푼 것은 오해가 없다. 정상 흐름 조건은 S2 "끊김 없는 물줄기"가 밝히고, 표면장력으로 끊기는 구간은 다루지 않아 부정확한 설명이 나오지 않는다.
- 조각이 늘어나며 가늘어지는 그림의 치수는 원기둥 부피(폭의 제곱 x 길이)로 맞다. P1 150x150x40 = 900k, P5 75x75x160 = 900k. 그러나 옆에서 보면 면적은 6000 대 12000이라 시청자 눈에는 아래 조각이 2배 커 보인다. 고칠 것 1번 참고.

## 고칠 것

1. (H, 비트 3과 6) 위 조각(150x40, 면적 6000)과 아래 조각(75x160, 면적 12000)을 옆에서 보면 아래가 2배로 커 보이는데, 내레이션과 "="는 "같은 양"이라고 한다. 치수는 부피로는 맞지만 시청자는 면적으로 본다. 둘 중 하나를 고른다. (a) 조각 치수를 옆면 면적이 같게 바꾼다(예: 폭 150x길이 80 대 폭 75x길이 160). 실제 변화는 더 작으므로 "과장해 그림" 표지로 충분하다. (b) 치수는 두고 조각을 가로로 퍼진 둥근 마디(캡슐 모양, 입체 음영)로 그려 원통임을 보여준다. 어느 쪽이든 비트 6의 주황 화살표 길이(60, 120, 170)도 조각 길이 비율과 맞춘다.
2. (C, 비트 6) "위 조각 (300, 500)과 아래 조각 (300, 855)을 점선으로 연결, 중앙 '=' (300, 680)"의 좌표 x 300은 물줄기(중심 x 482, 왼쪽 가장자리 407 이상)보다 한참 왼쪽이라 허공을 가리킨다. 점선 시작점을 P1의 왼쪽 가장자리(407, 500)와 P5의 왼쪽 가장자리(445, 855)로 고쳐 적고, "=" 위치와 L5 칩 영역(x 90-238, y 470-540)이 겹치지 않는지도 다시 확인한다.
3. (C, 비트 6) 유령 윤곽을 P2, P3, P4 "자리"에 그린다고 했는데 그 자리에는 이미 비트 3부터 같은 모양의 조각이 흐르고 있어 윤곽이 구분되지 않는다. P1 하나만 밝은 테두리나 하이라이트로 표시하고, 그 하나가 내려가며 늘어나는 모습을 보인다고 바꿔 적는다.
4. (E, 비트 1, 03-text L1) 앵커 "s1@물줄기는-0.40"을 1.37로 적었는데 "물줄기는"은 s1 시작 + 5글자 x 0.11 = 1.55초에 나온다. 0.4초 전은 1.15다. 지금은 선행이 0.18초뿐이다. L1 등장을 1.15로 당기고 03-text와 04의 표기를 같이 고친다(물줄기는 0.90에 이미 나와 있어 1초 안 조건은 충족). s1 글자 수도 24자인데 25자로 적혀 있어 같은 비트의 3.09 앵커도 약 3.0으로 맞춘다.
5. (E, 비트 6) 내레이션 순서는 "빨라서"(22.09) -> "폭이"(22.53) -> "좁아도"(22.86) -> "같은 양이"인데 그림 순서는 폭 표시(22.13) -> 조각 늘어남(22.60-23.40) -> "="(23.56)다. 빨라서 늘어나는 그림이 "빨라서"보다 0.5초 뒤에 시작해 "좁아도" 뒤에야 끝난다. 조각 늘어남을 s6.t0 근처(21.85)에 시작해 "빨라서" 직후인 22.5 전후에 끝나게 당기고, 폭 표시는 22.13을 유지한다. 그러면 말과 그림 순서가 같아진다.

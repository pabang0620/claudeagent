# 굼구미 시네마틱 c127 - 수도꼭지 물줄기가 아래로 갈수록 가늘어지는 이유 (9:16)

Canvas 1080x1920 (9:16), 30fps 출력, 그림은 on twos(2프레임마다 갱신), 휙 지나가는 순간(줌 전환, 폴짝)만 on ones. 본편만 다룬다 - 브랜드 인트로·제목카드·아웃트로는 엔진이 붙인다. 제목카드가 주제를 보여주므로 본편에서 주제 자막을 다시 띄우지 않는다.

예상 본편 길이 **약 30.95초**(구간 길이 = 글자수x0.11+0.80, gap 포함, 비트8 1.40초). 실제 TTS는 이보다 짧을 수 있고 앵커 기준으로 만든다. 내레이션 7구간, 비트 8개. 설명 사슬은 의외성 1 + 인과 고리 3(s3+s4, s5, s6) + 답(s7).

V4 강조 자막(emph)은 구간 자막의 해당 어절을 키우는 방식이라 별도 글자 요소가 아니다(동시 글자 3개 상한에 더하지 않는다).

굼구미: 흰 몸, 잉크 `#252E3A`, 코랄 볼 `#FC876E`. 머리카락·옷·코·귀·손가락 묘사 없음. 굼구미는 물을 틀지도 만지지도 않는 관찰자·안내자다(수도꼭지는 처음부터 물이 나오도록 틀어진 상태이며 물줄기가 흐르고 가늘어지는 일은 굼구미와 상관없다). 도식 장면의 굼구미는 y 1250(65%) 위, 패널 아래 1037 아래에 있고 x 85% 이후에 들어가지 않으며 모든 표시와 20px 이상 떨어진다.

## 과장 명시 (비트3~6)

도식은 물줄기를 옆에서 본 납작한 띠 그림이다. 물 조각은 옆면 면적이 모두 같게(폭 x 길이 = 12000) 그려서 "같은 양"이 눈에 보이게 했고, 폭 변화(위 150에서 아래 75)와 길이 변화(80에서 160)는 실제 수도꼭지 물줄기보다 훨씬 크게 그렸다(실제 둥근 물줄기는 폭이 덜 변한다). 그래서 도식이 보이는 8.64부터 25.93까지 S1 "과장해 그림"을 계속 띄운다. 조건("끊기지 않은 물줄기")은 S2가 도식 시작에 밝힌다.

- 설명 사슬이 모두 E 비트로 있고 순서가 같다: 훅(비트1, s1) -> 의외성 s2(비트2) -> 고리1 같은 양과 쌓임·사라짐 없음(비트3~4, s3+s4) -> 고리2 점점 빨라짐(비트5, s5) -> 고리3 빨라서 좁아도 됨(비트6, s6) -> 답(비트7, s7). 인과 고리 3개(첫 고리는 두 구간).

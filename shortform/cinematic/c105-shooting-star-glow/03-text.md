# c105 화면 글자 (내레이션 자막 제외 - 자동 표시)

한 화면 동시 최대: 내레이션 자막 1 + 라벨/표지 2 이하(퇴장·팝인 겹침 포함). 제목은 브랜드 제목카드가 보여주므로 본편에서 주제 자막을 다시 띄우지 않는다.

## 동시 표시 점검
- 0.00-1.20: 없음. 1.20-4.23: s1 = 1. 4.23-4.83: 없음.
- 4.83-5.27: s2 = 1. 5.27-7.00: L1 + s2 = 2. 7.00-7.20: s2 = 1.
- 7.60-7.90: S1 = 1. 7.90-9.30: S1 + s3 = 2. 9.30-9.33: s3 = 1.
- 9.33-11.37: L2 + s3 = 2. 11.37-11.67: L2 = 1.
- 12.07-13.39: S2 + s4 = 2. 13.39-13.60: S2 + L7 + s4 = 3(상한). 13.60-13.83: L7 + s4 = 2.
- 13.83-15.40: L7 + L3 + s4(15.43까지) = 3(상한). 15.40-15.43: L3 + s4 = 2. 15.43: 없음.
- 16.13-18.33: s5 = 1. 18.33-19.82: L4 + s5 = 2. 19.82-20.12: L4 = 1.
- 20.52-22.17: s6 = 1. 22.17-23.33: L5 + s6 = 2. 23.33-23.75: L5 = 1.
- 24.03-27.17: s7 = 1 (라벨 없음).
- 27.97-29.64: L6 + s8 = 2. 29.64-31.66: s8 = 1. 31.66-32.46: 없음.
- 어느 시점도 3개 이하.

## 라벨 규칙 점검
- 6자 이내: 별똥별 3, 과장해 그림 6, 우주 알갱이 6, 지구 2, 공기 2, 눌린 공기 4, 빛 1.
- 노출 1.5초 이상: L1 1.73, S1 1.70, L2 2.34, S2 1.53, L7 2.01, L3 1.60, L4 1.79, L5 1.58, L6 1.67. 전부 충족.
- 가리키는 단어가 발음되는 순간 팝인: L1 "별똥별은", L2 "모래알", L7 "지구의", L3 "공기에", L4 "눌려", L5 "빛을", L6 "별똥별은".
- 한 윤곽에 이름 하나: 줄에는 "별똥별"(L1, L6), 알갱이에는 "우주 알갱이"(L2), 호에는 "지구"(L7).
- 04와 일치: 칩 좌표는 스테이지 안이라 굼구미(x 74%)와 20px 이상. L7은 호 윗선 1090px에서 20px 이상(1110px 시작).

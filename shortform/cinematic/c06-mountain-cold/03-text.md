# c06 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("산 위가 여름에도 추운 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

- 4.50-12.46 (s2, s3): 자막만 1개씩. 라벨 없음(아직 실사 장면, 도식 진입 전).
- 12.46-12.56: 전환 직후 잠깐 공백(자막 없음, 라벨 없음).
- 12.56-13.06: S1 + s4 자막 = 2개(L1 등장 전).
- 13.06-14.56: S1 + L1 + s4 자막 = 3개("공기는" 발음 시점부터, 상한과 정확히 일치, 초과 아님).
- 14.56-16.62: L1 + s4 자막 = 2개(S1 페이드 아웃 후, s4 끝까지).
- 16.62-17.02: 간격(고리1과 고리2 사이, 자막·라벨 없음).
- 17.02-21.10: L2 + s5 자막 = 2개("땅에" 발음 시점부터 s5 끝까지).

## 숫자(N)
화면 숫자 없음. `01-fact.md`의 A등급 숫자(기온감률 수치, 산 높이-태양 거리 비교 수치)는 대본 규칙(숫자는 화면이 읽지 않는다 + 이번 편은 정성적 설명에 집중하는 방향)에 따라 화면에 쓰지 않는다. "높이 올라갈수록"이라는 관계만 라벨(L3 "저기압")과 그림의 색 변화로 보여준다.

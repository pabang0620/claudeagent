# 굼구미 시네마틱 c129 - 밤에 유리창에 내 모습이 비치는 이유 (9:16)

Canvas 1080x1920 (9:16), 30fps 출력, 그림은 on twos(2프레임마다 갱신), 휙 지나가는 순간(줌 전환, 되감기, 폴짝)만 on ones. 본편만 다룬다 - 브랜드 인트로·제목카드·아웃트로는 엔진이 붙인다. 제목카드가 주제를 보여주므로 본편에서 주제 자막을 다시 띄우지 않는다.

예상 본편 길이 **약 34.88초**(구간 길이 = 글자수x0.11+0.72, gap 포함, 비트9 1.40초). 실제 TTS는 이보다 짧을 수 있고 앵커 기준으로 만든다. 내레이션 8구간, 비트 9개. 설명 사슬은 의외성 1 + 인과 고리 4(s3, s4, s5+s6, s7) + 답(s8).

V4 강조 자막(emph)은 구간 자막의 해당 어절을 키우는 방식이라 별도 글자 요소가 아니다(동시 글자 3개 상한에 더하지 않는다).

굼구미: 흰 몸, 잉크 `#252E3A`, 코랄 볼 `#FC876E`. 머리카락·옷·코·귀·손가락 묘사 없음. 굼구미는 창가 관찰자이고 실험자다. 거실에서는 스위치를 눌러 방 불을 끄는 실험자 역할만 하며(실제 원인인 전등 빛이 줄어드는 것은 스위치가 한다) 반사를 직접 만들거나 지우지 않는다. 도식(비트3~7)에서는 관찰자이자 "비치는 나"로 패널 왼쪽 방 안에 서서 줄을 맞는다.

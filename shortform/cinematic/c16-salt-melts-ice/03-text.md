# c16 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("얼음에 소금 뿌리면 빨리 녹는 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용, 글자수x0.13초+0.7초 공식 + 어절 비례 배분). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

| id | 종류 | 등장~퇴장(예상 초) | ko | en | 위치 |
|---|---|---|---|---|---|
| S1 | 스케일 표지 (D.scaleBadge) | 6.71-8.78 | 얼음 표면 확대 | Ice surface zoom | 그림 무대 위쪽 |
| L1 | 라벨 | 8.78-12.09 | 표면 물기 | Surface film | 표면 물기막 옆, 지시선 |
| L2 | 라벨 (2회 등장) | 11.69-13.69, 22.33-26.00 | 소금물 | Brine | 웅덩이 옆, 지시선 |
| L3 | 라벨 | 13.29-16.54 | 어는점차이 | Freezing gap | 두 어는점 표시선 사이, 지시선 |
| L4 | 라벨 | 16.14-19.50 | 지금 온도 | Current temp | "지금 온도" 표시선 옆, 지시선 |

## 동시 표시 점검
- 0.00-3.59: s1 자막 단독 = 1개.
- 3.59-4.19: 없음(간격).
- 4.19-6.71: s2 자막 단독 = 1개.
- 6.71-7.41: S1 단독 = 1개(진입 비트, 내레이션 없음).
- 7.41-8.78: S1 + s3 자막 = 2개.
- 8.78-9.18: S1(페이드 아웃 중) + L1(등장 중) + s3 자막 = 3개(상한과 정확히 일치, 크로스페이드 순간이라 초과 아님).
- 9.18-10.06: L1 + s3 자막 = 2개(S1 소멸 후).
- 10.06-11.69: L1 + s4 자막 = 2개(L2 등장 전).
- 11.69-12.09: L1(페이드 아웃) + L2(등장) + s4 자막 = 3개(크로스페이드).
- 12.09-13.11: L2 + s4 자막 = 2개(L1 소멸 후).
- 13.11-13.29: L2 + s5 자막 = 2개.
- 13.29-13.69: L2(페이드 아웃) + L3(등장) + s5 자막 = 3개(크로스페이드).
- 13.69-16.03: L3 + s5 자막 = 2개(L2 소멸 후).
- 16.03-16.14: L3 + s6 자막 = 2개.
- 16.14-16.54: L3(페이드 아웃) + L4(등장) + s6 자막 = 3개(크로스페이드).
- 16.54-19.08: L4 + s6 자막 = 2개(L3 소멸 후).
- 19.08-19.50: L4(페이드 아웃) + s7 자막 = 2개.
- 19.50-22.33: s7 자막 단독 = 1개(복귀, 새 라벨 없음).
- 22.33-26.00: L2(재등장, 작게) + s8 자막 = 2개.
- 26.00-27.10: 없음(반전 비트, 자막·라벨 없음).
- 어느 시점도 상한(3개, 크로스페이드 순간)을 넘지 않는다.

## 숫자(N)
화면 숫자 없음. `01-fact.md`에서 버린 사실(정확한 어는점 하락 폭, 공정점 등)은 대본 규칙(숫자는 화면이 읽지 않는다)에 따라 화면에도 쓰지 않는다. "어는점이 더 낮다"는 관계만 라벨(L3 "어는점차이")과 비교 그림(두 표시선)으로 보여준다.

# c44 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("화성이 빨갛게 보이는 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

|---|---|---|---|---|---|
| S1 | 스케일 표지 (D.scaleBadge) | 9.30-10.60 | 화성 표면으로 확대 | Zoom into Mars surface | 그림 무대 위쪽 |

## 동시 표시 점검
- 9.30-9.80: S1 단독 = 1개(줌 다이브 중, s4 자막 시작 전).
- 9.80-10.17: 없음(다음 자막 대기).
- 10.17-10.60: S1 + s4 자막 = 2개.
- 10.60-11.40: s4 자막 단독 = 1개(S1 페이드 아웃 후, L1 등장 전).
- 11.40-12.95: L1 + s4 자막 = 2개.
- 12.95-13.35: 없음(고리1→고리2 사이 간격).
- 13.35-14.00: s5 자막 단독 = 1개(L2 등장 전).
- 14.00-15.35: L2 + s5 자막 = 2개.
- 15.35-15.60: L2 + L3 + s5 자막 = 3개(상한과 정확히 일치, 초과 아님 - "산소"와 "산화철"이 한 문장 안에서 연달아 발음되는 구간).
- 15.60-16.52: L3 + s5 자막 = 2개(L2 퇴장 후, s5 자막은 16.52까지 유지).
- 16.52-16.92: L3 단독 = 1개(s5 자막 종료 후 L3 꼬리, s6 자막 시작 전).
- 16.92-19.70: s6 자막 단독 = 1개(라벨 없음, 빛 반사 클로즈업에만 집중).
- 19.70-20.10: 없음(간격).
- 20.10-23.01: s7 자막 단독 = 1개(라벨 없음, 줄아웃·행성 전체 장면).
- 23.01-23.61: 없음(반응 비트, 자막·라벨 없음).
- 23.61-23.95: s8 자막 단독 = 1개(L4 등장 전).
- 23.95-25.50: L4 + s8 자막 = 2개.
- 25.50-26.26: s8 자막 단독 = 1개(L4 페이드 아웃 후).
- 26.26-30.16: s9 자막 단독 = 1개(라벨 없음, 최종 답 정리).
- 어느 시점도 상한(3개)을 넘지 않는다.

## 숫자(N)
화면 숫자 없음. `01-fact.md`에서 버린 철분·산화철 함량 수치는 대본 규칙(숫자는 화면이 읽지 않는다 + B등급 수치는 아예 화면에 쓰지 않는다)에 따라 화면·내레이션 어디에도 노출하지 않는다.

# c101 화면 글자 (내레이션 자막 제외 - 자동 표시)

한 화면 동시 최대: 내레이션 자막 1 + 라벨/표지 2 (퇴장·팝인 겹침 포함). 제목은 브랜드 제목카드가 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다.

시각은 `narration-ko.json` 기준 예상 절대 초(글자수x0.11+문장끝 0.5, 검토용)다. 실제 값은 TTS 후 확정하고 애니메이터는 앵커를 쓴다.

## 동시 표시 점검 (자막은 해당 구간 t0~t1 동안 표시)
- 0.00-1.00: 없음. 1.00-2.10: s1 = 1. 2.10-3.59: S1 + s1 = 2. 3.59-4.00: S1 = 1. 4.00-4.59: 없음.
- 4.59-6.55: s2 = 1. 6.55-7.84: L1 + s2 = 2. 7.84-8.25: L1 = 1. 8.25-8.54: 없음.
- 8.54-8.87: s3 = 1. 8.87-10.57: L2 + s3 = 2. 10.57-10.91: s3 = 1.
- 11.11-11.81: S2 = 1. 11.81-12.81: S2 + s4 = 2. 12.81-13.46: s4 = 1. 13.46-15.17: L3 + s4 = 2. 15.17-15.20: L3 = 1.
- 15.87-17.52: s5 = 1. 17.52-19.01: L4 + s5 = 2. 19.01-19.21: L4 = 1.
- 19.71-20.26: s6 = 1. 20.26-22.00: L5 + s6 = 2. 22.00-22.63: s6 = 1.
- 23.33-23.66: s7 = 1. 23.66-24.32: L6 + s7 = 2. 24.32-26.20: L6 + L7 + s7 = 3 (상한과 일치). 26.20-26.47: s7 = 1.
- 27.17-28.82: s8 = 1. 28.82-30.50: L8 + s8 = 2. 30.50-30.86: s8 = 1.
- 31.56-32.00: s9 = 1. 32.00-33.44: L9 + s9 = 2. 33.44-33.73: L9 + L10 + s9 = 3 (상한과 일치). 33.73-34.59: L10 + s9 = 2. 34.59-34.98: L10 = 1.
- 35.59-38.62: s10 = 1 (라벨 없음, 복귀 비트). 38.62-39.32: 없음.
- 어느 시점도 3개를 넘지 않는다.

## 라벨 규칙 점검
- 라벨 6자 이내(공백 포함): 잔상 2, 빈 자리 4, 원뿔세포 4, 반응 세기 5, 흰 빛 3, 하트 자리 5, 나머지 3, 빨강보다 4, 보이는 색 5, 청록 2. 표지 10자 이내: 한 점만 보기 7, 눈 속 확대 6.
- 노출 1.5초 이상: S1 1.90, L1 1.70, L2 1.70, S2 1.70, L3 1.74, L4 1.69, L5 1.74, L6 2.54, L7 1.88, L8 1.68, L9 1.73, L10 1.54. 전부 충족.
- 라벨은 대상이 처음 그려진 뒤 1초 안에 팝인: L1 청록 하트(5.69 시작, 6.55), L2 점선 빈 윤곽(8.40 시작, 8.87), L3 첫 세포(12.58 시작, 13.46), L4 막대(16.90 시작, 17.52), L5 흰 벽 아이콘(19.50 시작, 20.26), L6 왼쪽 구역(22.93 시작, 23.66), L7 오른쪽 구역(24.00 시작, 24.32), L8 초록·파랑 막대 괄호(비트8 시작 26.77에 괄호가 서고 28.82에 팝인, 막대는 비트7에서 이미 라벨 없이 반응 세기로 설명됨), L9 색 창(31.46 시작, 32.00), L10 청록 하트 완성(33.44).
- 라벨이 가리키는 단어가 발음되는 순간 팝인: L1 "하트가", L2 "그림이", L3 "파랑", L4 "반응이", L5 "빛에는", L6 "자리에서는", L7 "빨강", L8 "빨강보다", L9 "파랑이", L10 "청록이에요".
- 한 윤곽에 이름 두 개 금지: 청록 하트는 L1 "잔상"(벽 위, 비트2~3)과 L10 "청록"(색 창, 비트9)로 서로 다른 대상이다. 색 창의 하트는 "보이는 색" 칩(L9) 아래 윤곽이고 L10은 색 이름을 가리킨다.
- 레이아웃 간격: 칩끼리·칩과 굼구미·칩과 패널 테두리 20px 이상(좌표는 04-storyboard.md). 자막 띠(y 1250 이하)에 칩 없음(최대 y 1130).

# c09 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("박하 먹으면 입이 시원한 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

| id | 종류 | 등장~퇴장(예상 초) | ko | en | 위치 |
|---|---|---|---|---|---|
| S1 | 스케일 표지 (D.scaleBadge) | 7.23-8.93 | 혀 신경 끝 확대 | Tongue nerve zoom | 그림 무대 위쪽 |
| L1 | 라벨 (2회 등장) | 8.13-13.76, 24.13-27.95 | 냉각 센서 | Cold sensor | 신경 끝 옆, 지시선 |
| L2 | 라벨 | 11.50-14.20 | 멘톨 | Menthol | 멘톨 분자 옆, 지시선 |

## 동시 표시 점검
- 0.00-3.98: s1 자막 단독 = 1개.
- 3.98-4.58: 없음(간격).
- 4.58-7.23: s2 자막 단독 = 1개.
- 7.23-7.93: S1 단독 = 1개(진입 비트, 내레이션 없음).
- 7.93-8.13: S1(페이드 아웃 중) + s3 자막 = 2개.
- 8.13-8.93: S1 + L1 + s3 자막 = 3개(상한과 정확히 일치, 초과 아님).
- 8.93-10.58: L1 + s3 자막 = 2개(S1 소멸 후).
- 10.58-11.50: L1 + s4 자막 = 2개(L2 등장 전).
- 11.50-13.76: L1 + L2 + s4 자막 = 3개(상한과 정확히 일치).
- 13.76-14.16: 없음(전환 간격, L1 소멸).
- 14.16-14.50: s5 자막 단독 = 1개(L3 등장 전).
- 14.50-17.59: L3 + s5 자막 = 2개.
- 17.59-17.99: 없음(간격, L3 소멸).
- 17.99-20.64: s6 자막 단독 = 1개(라벨 없음).
- 20.64-21.24: 없음(간격).
- 21.24-23.63: s7 자막 단독 = 1개(체온계 재확인, 새 라벨 없음).
- 23.63-24.13: 없음(간격).
- 24.13-27.95: L1(재등장, 작게) + s8 자막 = 2개.
- 27.95-28.95: 없음(반전 버튼, 자막·라벨 없음).
- 어느 시점도 상한(3개)을 넘지 않는다.

## 숫자(N)
화면 숫자 없음. `01-fact.md`에서 버린 사실(센서 활성화 온도 문턱 등)은 대본 규칙(숫자는 화면이 읽지 않는다 + 이번 편은 숫자 라벨 자체를 쓰지 않는 방향)에 따라 화면에 쓰지 않는다. "같은 신호"라는 관계만 라벨(L3 "신경 신호")과 비교 그림으로 보여준다.

# c33 화면 글자 (라벨 / 숫자 / 스케일 표지)

내레이션 자막은 자동 표시되므로 여기 적지 않는다. N(숫자) 시리즈는 없음 - 01-fact.md에서 A등급 수치를 확보하지 못해 화면 숫자를 쓰지 않는다.

## 동시 표시 점검
- 비트6(s5) 초반: S1(페이드아웃 중) + L1(팝인) + 자막(s5) = 최대 3, 상한(자막1+라벨2) 이내
- 비트7(s6): L1 + L2 + 자막(s6) = 3, 상한과 정확히 일치
- 비트8(s7) 초반: L1·L2 페이드아웃 겹침 + 자막(s7) = 최대 3(L3는 초반 이후 "펴져요" 시점에 팝인하므로 동시 노출은 최대 3 유지)
- 비트9(s8) 초반: L3 페이드아웃 + L2 재등장 + 자막(s8) = 최대 3
- 그 외 비트는 라벨 없이 자막만 표시되어 상한 이내

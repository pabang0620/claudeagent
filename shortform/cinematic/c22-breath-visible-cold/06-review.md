0. 제목카드: "입김이 하얗게 보이는 이유" - 주제 인지
1. (0-4.11s) 굼구미가 추운 마당에 서서 숨을 내쉬니 흰 뭉게구름이 잠깐 생겼다 사라진다 / s1 - "추운 날 숨쉬면 하얘지는구나" 일상 장면만, 설명 없음
2. (4.11-7.75s) 실내 쪽으로 몸을 기울여 숨을 내쉬니 옅은 점선 원만 생겼다 사라짐 / s2 "따뜻한 방 안에서도 수증기가 있어요" - 실내 숨에도 원래 수증기가 있다는 걸 앎
3. (7.75-11.16s) 다시 바깥 쪽으로 숨을 내쉬니 진한 흰 구름, 왼쪽엔 아까 실내 숨의 흐릿한 유령 윤곽이 남아 대비됨 / s3 "이상하게 밖에서만 하얗게 보여요" - 같은 숨인데 밖에서만 하얗다는 의문(반전) 확인
4. (11.16-13.76s) 휩 전환, dim, "숨 확대" 표지 / s4 "숨 속을 확대해서 볼게요" - 스케일 전환 인지
5. (13.76-17.30s) 따뜻한 주황 영역 안에 투명 입자들이 하나씩 생겨 라벨 "수증기" / s5 "숨은 데워지며 수증기를 머금어요" - 고리1(숨은 원래 수증기를 머금음)
6. (17.30-20.87s) 주황 영역이 파란 영역에 닿으며 파랗게 물들고 라벨 "찬 공기" / s6 "차가운 공기 만나면 순식간에 식어요" - 고리2(차가운 공기 만나면 식음)
7. (20.87-24.57s) 투명 입자들이 뭉쳐 불투명 흰 물방울로 변하고 라벨 "물방울" / s7 "수증기를 다 못 담아 물방울로 맺혀요" - 고리3(식으면 물방울로 응결)
8. (24.57-28.27s) 노란 광선이 물방울에 부딪혀 사방으로 갈라지며 전체가 흰 글로우 / s8 "물방울들이 빛을 흩어서 하얗게 보여요" - 고리4(물방울이 빛을 흩뜨려 하얗게 보임)
9. (28.27-31.94s) 현관으로 컷백, 방금 본 도식의 유령 윤곽이 잠깐 겹쳤다 사라진 뒤 다시 숨을 내쉬어 흰 구름 확인 / s9 "다시 마당에서도 여전히 하얘요" - 방금 배운 원리가 실제 장면에도 적용됨을 확인
10. (31.94-35.58s) 굼구미가 정면을 보고 웃음 / s10 "따뜻한 숨이 식어 물방울 되면 하얗게 보여요" - 답 확정
11. (35.58-36.58s) 굼구미가 유리창에 입김을 불어 웃는 얼굴을 그리고 씩 웃음(반전 개그, 새 정보 없음)

## 이해 판정
시뮬레이션 끝에서 시청자는 "따뜻한 숨의 수증기가 차가운 공기를 만나 식으면서 물방울로 맺히고, 그 물방울들이 빛을 사방으로 흩어서 하얗게 보인다"는 02-explain.md 답 문장을 스스로 말할 수 있다. 인과 고리 4개(수증기 머금음 → 냉각 → 응결 → 산란)가 순서대로 그림+라벨과 함께 제시되어 끊기는 지점 없음.

# 굼구미 시네마틱 c22 - 입김이 하얗게 보이는 이유 (9:16)

Canvas 1080x1920 (9:16), 30fps 출력, 그림은 on twos(2프레임마다 갱신) 기본. 본편만 다룬다 - 브랜드 인트로(약 2.3초)·제목카드(약 1.8초)·아웃트로(약 3.0초)는 `engine/brand/render_brand.sh`로 별도 렌더해 붙인다(새로 그리지 않음).

예상 본편 길이 **약 36.6초**(narration-ko.json 기준 추정치, 공백 제외 글자수x0.13초+0.7초 공식). 실제 값은 TTS 렌더 후 `timeline-ko.js`로 확정하고, 애니메이터는 절대 초가 아니라 아래 앵커를 쓴다.

굼구미: 흰 몸, 잉크 `#252E3A`, 코랄 볼 `#FC876E`. 팔다리·머리카락·옷·코·귀·손가락 묘사 없음(리그 그대로).

배경: 겨울 현관 장면 - 화면을 문틀이 가로질러 왼쪽 40%는 실내(따뜻한 방), 오른쪽 60%는 바깥 마당으로 나눈다. 이 하나의 장면을 훅부터 끝까지 유지한다. 도식 구간(비트4~8)에서는 같은 배경을 어둡게 dim(60~70%)해 초점을 만든다 - 장면 전환 없이 하나의 현관 세계 안에서 확대해 들어가는 느낌.

**제목카드가 이미 "입김이 하얗게 보이는 이유"를 보여주므로 본편 안에서 주제 자막(T)을 다시 띄우지 않는다.**

## 자체 점검
- 설명 사슬 4고리(숨의 정체/냉각/응결/산란)가 각각 비트5·6·7·8의 `E` 비트로 있고, 각 비트 내레이션 칸에 해당 고리의 내레이션 id(s5,s6,s7,s8)가 있다. 기대(s2)·반전(s3)은 비트2·3, 진입(s4)은 비트4, 복귀(s9)·답(s10)은 비트9·10에 있다.
- 훅(비트1)은 설명·비교·라벨 없이 마당으로 나와 숨을 내쉬는 장면만 보여주며 0.00-4.11(4.11초, 2.5초 이상)를 차지한다. 기대(비트2)와 반전(비트3)을 분리해 훅에 설명이 섞이지 않게 했다.
- 각 고리의 그림은 핵심 어절 발음 시작 0.4초 전부터 그려지기 시작해 해당 어절이 발음되는 순간 완성된다(비트5 `s5@"데워지며"-0.40`, 비트6 `s6@"차가운"-0.40`, 비트7 `s7@"못 담아"-0.40`, 비트8 `s8@"흩어서"-0.40`). 완성 후에는 각 비트 종료(t1)까지 hold가 남는다.
- 내레이션 10구간 전부 채널 프로필 3절을 지킨다: 첫 문장(s1)은 장면 묘사, 질문형 없음, 숫자를 읽지 않음, 마지막 문장(s10)은 핵심 사실이며 교훈 없음, 전문용어는 초등 수준 통용어인 "수증기" 하나만 쓰고 "응결"·"산란" 같은 어려운 말은 쓰지 않음, 친근한 대화체("~해요", "~거든요" 계열).
- 과학적 인과 칸이 "굼구미가 ~해서"로 시작하는 비트 없음(전부 숨/공기/물방울/빛이 주어). 굼구미는 숨을 내쉬어 보는 실험자(비트1~3), 도식을 가리키는 안내자(비트4~8), 다시 확인하는 실험자(비트9), 결과를 정리해 말해주는 안내자(비트10), 반전 개그를 벌이는 반응자(비트11)로만 등장한다.
- `A` 비트: 비트1 초반(1.20초, gap_before(s1)), 비트4 초반(0.30초, 전환 위시), 비트11(1.00초) - 전부 1.4초 이하.

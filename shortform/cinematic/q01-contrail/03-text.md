# q01 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨/표지 2 (퇴장·팝인 겹침 포함). 제목("비행기 뒤에 하얀 줄이 생기는 이유")은 브랜드 제목카드가 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다.

시각은 `narration-ko.json` 기준 예상 절대 초(글자수x0.11+문장끝 0.5, 검토용)다. 실제 값은 TTS 렌더 후 `timeline-ko.js`로 확정하고 애니메이터는 앵커를 쓴다. 04-storyboard.md와 같은 앵커와 값을 쓴다.

내레이션 구간 시각(예상): s1 0.60-3.74 / s2 4.34-7.70 / s3 8.40-11.87 / s4 12.57-15.27 / s5 15.97-19.00 / s6 20.10-23.13 / s7 23.73-26.65 / s8 27.35-30.71 / s9 31.31-34.78 / s10 35.48-39.17.

## 동시 표시 점검 (자막은 해당 구간 s0.t0~s0.t1 동안 표시)
- 0.00-0.60: 없음. 0.60-3.74: s1 = 1개. 3.74-4.34: 없음.
- 4.34-7.70: s2 = 1개. 7.70-8.10: 없음. 
- 8.10-8.40: S1 = 1개. 8.40-9.70: S1 + s3 = 2개.
- 9.70-9.72: s3 = 1개. 9.72-11.87: L1 + s3 = 2개. 11.87-12.17: L1 = 1개.
- 12.27-12.57: S3 = 1개. 12.57-13.34: S3 + s4 = 2개.
- 13.34-13.87: S3 + L2 + s4 = 3개 (상한과 일치, 초과 없음).
- 13.87-14.11: L2 + s4 = 2개. 14.11-15.27: L2 + L3 + s4 = 3개 (상한과 일치).
- 15.27-15.57: L2 + L3 = 2개. 15.57-15.67: L3 = 1개 (L2는 15.57에 퇴장 완료).
- 15.97-17.51: s5 = 1개. 17.51-19.00: L4 + s5 = 2개. 19.00-19.20: L4 = 1개.
- 19.25-20.10: S2 = 1개. 20.10-20.85: S2 + L5 + s6 = 3개 (상한과 일치).
- 20.85-21.75: L5 + s6 = 2개. 21.75-22.05: L5 + L6 + s6 = 3개 (상한과 일치).
- 22.05-23.13: L6 + s6 = 2개. 23.13-23.60: L6 = 1개.
- 23.73-26.65: s7 = 1개 (라벨 없음).
- 27.35-27.79: s8 = 1개. 27.79-30.71: L7 + s8 = 2개. 30.71-31.31: L7 = 1개.
- 31.31-31.75: L7 + s9 = 2개. 31.75-32.90: L7 + L8 + s9 = 3개 (상한과 일치).
- 32.90-34.78: L8 + s9 = 2개. 34.78-35.08: L8 = 1개.
- 35.48-39.17: s10 = 1개 (라벨 없음, 복귀 비트). 39.17-39.87: 없음.
- 어느 시점도 3개를 넘지 않는다.

## 라벨 규칙 점검
- 라벨 6자 이내(공백 포함): 수증기 3, 어는 선 4, 찬 공기 4, 얼음 알갱이 6, 비행운 3, 촉촉한 하늘 6, 건조한 하늘 6. 스케일 표지 10자 이내: 엔진 가까이 6, 높이 개념도 6, 확대해서 보면 7.
- 노출 1.5초 이상: L1 2.45, L2 2.23, L3 1.56, L4 1.69, L5 1.95, L6 1.85, L7 5.11, L8 3.33, S1 1.60, S2 1.60, S3 1.60. 전부 충족.
- 라벨은 대상이 처음 그려진 뒤 1초 안에 팝인한다: L4는 첫 결정이 맺힌 약 17.45초 직후, L5는 확대경 안 결정이 보이는 20.0초 직후.
- 라벨이 가리키는 단어가 발음되는 순간 팝인한다: L1 "수증기,", L2 "영하로", L3 "차갑거든요", L4 "순식간에"(첫 결정이 맺히는 순간), L5 s6 시작("얼음"), L6 "하얀", L7 "촉촉하면", L8 "건조하면".
- L6 "비행운"은 줄의 이름 표지이며 내레이션은 "하얀 줄"이라 한다. 한 윤곽(줄)에 이름 하나만 붙인다.
- 레이아웃 간격: 칩끼리·칩과 굼구미·칩과 패널 테두리·칩과 확대경 사이 20px 이상(좌표는 04-storyboard.md 각 비트에 있음). 자막 띠(y 1250 이하)에 칩 없음.

## 숫자(N)
화면 숫자 없음. 순항 고도, 기온, 알갱이 크기, 지속 시간 같은 수치는 01-fact.md에서 B등급이라 화면과 내레이션 어디에도 쓰지 않는다. 공기 기둥의 어는 선은 점선과 색으로만 표현하고 숫자를 달지 않는다.

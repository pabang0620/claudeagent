# 굼구미 시네마틱 q01 - 비행기 뒤에 하얀 줄이 생기는 이유 (9:16)

Canvas 1080x1920 (9:16), 30fps 출력, 그림은 on twos(2프레임마다 갱신), 휙 지나가는 순간만 on ones. 본편만 다룬다 - 브랜드 인트로·제목카드·아웃트로는 엔진이 붙인다(새로 그리지 않음). 제목카드가 주제를 보여주므로 본편에서 주제 자막을 다시 띄우지 않는다.

예상 본편 길이 **약 39.9초**(글자수x0.11+문장끝 0.5 공식 + 마지막 반전 0.7초. 실제 TTS는 이보다 짧을 가능성이 높다). 앵커 기준으로 만들고 절대 초는 검토용이다. 내레이션 10구간, 비트 11개.

굼구미: 흰 몸, 잉크 `#252E3A`, 코랄 볼 `#FC876E`. 머리카락·옷·코·귀·손가락 묘사 없음(리그 그대로). 굼구미는 얼음을 만들지 않는다. 확대경을 대고, 가리키고, 올려다보는 안내자다. 굼구미는 y 1250(65%) 아래, 오른쪽 UI(x 85% 이후)에 들어가지 않고 모든 표시와 20px 이상 떨어진다.

색의 흐름: 주황(뜨거운 배기) -> 하늘색 점선(수증기) -> 파랑(찬 공기와 섞임) -> 흰색(얼음). 이 흐름이 사슬 전체와 같다.

화풍: gumgumi-intro와 같은 손그림 라인 + 선 떨림(line boil). 하늘 풍경은 부드러운 면 위주의 수채 느낌 그라데이션, 과학 도식 부분(엔진 단면, 공기 기둥, 확대경, 두 패널)은 얇고 차분한 다이어그램 선으로 그려 풍경과 설명이 구분되게 한다.

## 공간 설계 (연출 여지의 기준)

세로 구도에서 "하늘이 높다"는 느낌이 이 편의 핵심 정서다. 아래 높이 지도를 모든 비트가 공유한다. 화면 %는 위에서 아래 기준.

- **지상 층**: 가까운 언덕 능선 60~64%, 굼구미와 풀이 서는 선. 쇼츠 UI와 자막 띠가 아래를 가리므로 지상 전경은 능선 아래 잘리는 구도(풀 덤불 일부만 프레임 아래로 넘침).
- **중간 층(낮은 구름층)**: 먼 뭉게구름 38~52%. 대비를 약하게 해 "그보다 훨씬 위"라는 깊이 기준으로만 쓴다.
- **비행기 고도 층**: 화면 20~36%. 비행기는 작게(날개폭 130px) 그려 멀다는 걸 보여준다. 비행기는 화면 왼쪽 밖(x -8%)에서 들어와 오른쪽 위(x 72~78%, y 26%)로 간다. 줄은 화면 왼쪽 가장자리(x 0%, y 32%)에서 비행기까지 이어지는 완만한 오르막(y 32% -> 26.5%)이다.
- **원근 규칙**: 구름은 먼 층일수록 작고 흐리고 푸르게. 줄은 비행기에서 멀어질수록(오래된 쪽) 조금 넓고 흐려진다.
- **광원**: 해는 화면 오른쪽 위 모서리 밖. 굼구미 오른쪽 가장자리에 `#FFF3C9` 림라이트, 풀 위 그림자는 왼쪽으로 짧게. 도식 구간은 dim 후 도식 자체 글로우만 광원.

**[기본] / [여지] 표기**: Picture 칸에서 `[기본]`은 5개 버전 공통으로 반드시 구현할 내용이다. `[여지]`는 카메라·조명 연출판과 3D 하이브리드판이 살릴 수 있는 선택 연출이며, 기준판은 생략해도 된다. `[3D]`는 3D 하이브리드판 후보 오브젝트다(비행기 몸체, 엔진 단면, 공기 기둥).

- 설명 사슬이 모두 E 비트로 있고 순서가 같다: 고리1 수증기(비트3, s3) -> 고리2 찬 하늘(비트4, s4) -> 고리3 식어서 얼어 알갱이(비트5, s5) -> 고리4 알갱이 무리가 줄(비트6, s6) -> 전제 금방 사라지는 날도 있다(비트7, s7) -> 고리5 촉촉하면 자람(비트8, s8) / 건조하면 수증기로 돌아감(비트9, s9) -> 답(비트10, s10). 훅(비트1, s1)과 의외성(비트2, s2)이 앞에 있다. 02-explain.md의 고리 5개 + 전제 + 답과 같다.
- 훅(비트1)은 설명·비교·라벨 없이 하늘과 비행기, 줄이 길게 자라는 일상 장면이며 0.00-3.94(3.94초, 2.5초 이상). 첫 0.6초는 앰비언스와 비행기 진입. "연기가"는 약 2.3초에 발음되어 3초 안에 닿는다.
- **시작 앵커는 비트2~5, 7~10이 "그 비트 내레이션 구간 시작(sN.t0) - 0.4초"다.** 비트6만 s6.t0-1.0이다(확대경과 결정이 "얼음 알갱이가"보다 먼저 보여야 하고 줌 백 A 0.5초가 앞에 붙기 때문이며 s6 gap_before를 1.1초로 두어 비트5 hold 1.0초 이상을 확보).
- 완성 앵커와 hold(전부 1초 이상): 비트2 6.6초(hold 1.4), 비트3 s3@"나와요" 10.93(1.24), 비트4 s4@"차갑거든요" 14.11(1.46), 비트5 s5@"얼어요" 18.06(1.04), 비트6 s6@"줄이에요" 22.08(1.25), 비트7 25.5(1.45), 비트8 s8@"자라요" 29.77(1.14), 비트9 s9@"돌아가요" 34.0(1.08), 비트10 s10@"촉촉한지"+0.2 37.9(1.27).
- **라벨 팝인은 가리키는 단어가 발음되는 순간이다**: L1 s3@"수증기,", L2 s4@"영하로", L3 s4@"차갑거든요", L4 s5@"순식간에", L5 s6 시작, L6 s6@"하얀", L7 s8@"촉촉하면", L8 s9@"건조하면". 비트 끝에 몰아서 띄운 라벨 없음. 라벨은 대상이 그려진 뒤 1초 안에 뜬다.
- 비유 정확도: 수증기를 점선·투명으로 그려 "연기가 하얀 줄이 된다"로 오해되지 않게 했다. 맺히는 순간은 폭발이 아니라 조용히 맺히는 것, 자라는 것은 몽글이가 알갱이에 붙는 것, 사라지는 것은 알갱이가 몽글이로 풀리는 것으로 지정했다(01-fact 비유 점검표). 건조한 하늘도 몽글이를 0개로 그리지 않는다.
- 내레이션이 비유를 과장하지 않는다: "식어 순식간에 얼어요", "수증기를 붙여 자라요", "수증기로 돌아가요" 수준이지 정확히 맞아떨어진다는 표현은 없다.
- 과학적 인과 칸에 "굼구미가 ~해서"로 시작하는 비트 없음(주어는 전부 배기·수증기·찬 공기·얼음 알갱이·하늘). 굼구미는 올려다보는 관찰자(비트1~2), 가리키는 안내자(비트3~5, 7~10), 확대경을 대는 안내자(비트6)로만 등장한다.
- `A` 구간: 비트1 앞 0.6 + 비트3 0.5 + 비트4 0.3 + 비트6 0.5 + 비트10 0.4 + 비트11 0.7 = 약 3.0초, 각각 1.4초 이하. 나머지 약 36.9초가 E로 **전체의 약 92%**(55% 이상).
- 내레이션 없는 구간은 연속 3초 이하(최대 비트1 앞 0.6초, 구간 사이 gap은 모두 1.1초 이하).
- 처음 등장하는 과학 대상(수증기, 어는 선, 찬 공기, 얼음 알갱이, 비행운, 촉촉한 하늘, 건조한 하늘)마다 라벨이 있고 모두 1.5초 이상.
- 비교가 필요한 고리: 고리3은 점선 유령 윤곽(수증기)과 결정을 같은 자리에 겹쳐 보여 주고, 고리4는 확대경 안/밖을 같은 화면에, 전제와 고리5는 좌우 두 패널을 같은 화면에 나란히 둔다(왼쪽 줄은 실선 유지, dim만 50%).
- 도식은 실제 대상에서 자라 나온다: 엔진 단면은 하늘의 비행기가 커져서(비트3), 공기 기둥은 엔진 단면이 작은 비행기로 줄어들어(비트4), 결정은 하늘의 줄과 겹쳐(비트6), 확대 원은 패널의 줄에서(비트8·9). 하늘로 돌아올 때 말("그런데", "줄이 오래 남는지")로 잇는다.

# c89 설명 사슬 - 달 모양이 바뀌는 이유

## 질문

달 모양은 왜 초승달에서 반달, 보름달로 바뀔까.

## 의외성

달이 이지러지는 건 지구 그림자가 가려서라고 믿기 쉽다. 실제로는 달이 늘 해 쪽 절반이 밝고, 우리가 보는 방향이 달라질 뿐이다. (s2가 "지구 그림자가 달을 가려서가 아니에요"라고 말로 뒤집고, 풍선 속 그림 위 X가 같은 뜻이다. 이어서 s3이 진짜 원인 쪽으로 시선을 옮긴다.)

답 1문장: 달은 늘 해 쪽 절반이 밝고, 달이 지구를 도는 동안 우리가 보는 밝은 쪽의 정도가 달라져 모양이 바뀐다.

## "그래서?" 점검

s1 모양이 바뀐다 -> 지구 그림자 때문? s2 아니다 -> 그럼 뭔가? s3 달은 늘 해 쪽 절반이 밝다 -> 그런데 왜 모양이 바뀌나? s4 달이 지구를 돈다 -> 돌면? s5-s7 지구를 향한 쪽과 밝은 쪽이 겹치는 만큼, 달이 있는 자리마다 우리 눈에 밝은 쪽이 가늘게 / 절반 / 다 보인다 -> 그래서? s8 도는 동안 보이는 정도가 달라진다. 비약 없음.

연결(이전 결과어가 다음 주어):
- s5-s7은 "지구를 향한 쪽(보라 호)과 밝은 쪽(오른쪽)이 겹치는 만큼 보인다"를 그림으로 보인다(새 사실 아님).
- s2 -> s3: 풍선과 X를 지우고 "달은 늘 ... 밝아요"로 진짜 원인(햇빛)을 말함.
- s3 밝아요 -> s4: "달은 ... 돌아요"로 받아 위치가 바뀐다는 전제.
- s4 돌아요 -> s5: "달이 해 쪽에 가까우면"으로 돌다 보면 자리마다 달라짐을 이음. 시선 선과 "지구에서" 라벨로 보는 자리를 밝힘.
- s5-s7: 같은 문형("달이 ~면 밝은 쪽이 ~ 보여요")이고 가늘게 -> 절반 -> 다로 커짐. 훅(s1)의 순서와 같다.
- s7 -> s8: 세 자리의 결과를 한 문장으로 닫음.

용어 풀이: 별도 어려운 용어 없음. "초승달, 반달, 보름달"은 일상어. "밝은 쪽"이 "해를 향한 쪽 절반"을 받는다.

## 그림 일관 규칙 (04와 동일)

- 대상: 굼구미 1, 창 1(훅, 밤 창문), 달(창 안 1, 풍선 1, 카드 안 1 + 유령 2), 해 1, 햇빛 화살표 3, 지구 1(머리 아이콘 포함), 점선 고리 1, 보라 시선 선 1(마지막 장면 3), 아래 창 1(마지막 장면 3), 풍선 1과 X 1, 풍선 속 지구 1과 그림자 1.
- 색: 달 밝은 쪽 노란 크림, 달 어두운 쪽 남회색, 해와 햇빛 노랑, 지구 파랑, 시선 선과 아래 창 테두리 진보라, 고리 회색 점선.
- 방향: 밝은 쪽은 카드 안에서 항상 오른쪽(해 쪽). 아래 창의 모양은 커지는 순서(오른쪽이 밝음).
- 화살표는 햇빛에만. X는 "아니다" 한 가지.

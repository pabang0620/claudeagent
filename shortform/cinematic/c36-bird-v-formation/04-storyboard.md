# 04-storyboard: 새들이 V자로 줄지어 나는 이유 (본편)

- 캔버스: 1080x1920 (9:16), 30fps 출력, 기본 on twos(2프레임마다 갱신), 급한 순간만 on ones
- 팔레트:
  - 하늘 그라데이션: 상단 `#7EC8E3`(낮 하늘) -> 하단 `#F3B562`(노을 능선)
  - 언덕 실루엣: `#2B3A55`
  - 굼구미: 흰 몸, 잉크 `#252E3A`, 코랄 볼 `#FC876E` (전 구간 동일, 흑백 연출 없음)
- **색 약속 표**

| 개념 | 색 | 설명 |
|---|---|---|
| 날개 끝 소용돌이(와류) | 보라 `#6C63FF` | 날갯짓마다 생기는 공기 소용돌이 |
| 상승기류(도움 되는 바람 자리) | 골드 글로우 `#FFD83A` | 소용돌이 뒤·바깥쪽의 위로 뜨는 공기 |
| 일반 공기 / 배경 새(무리) | 회청 `#B9C4D0` / 남색 실루엣 `#2B3A55` | 상승기류 혜택이 없는 보통 자리 |
| 혜택 받는(뒤따르는) 새 | 코랄 `#FC876E` | 상승기류 자리에 들어간 새 강조 |
| 대형 안내선 | 흰 점선 `#FFFFFF` | V자 윤곽 가이드 |

- 화풍: 손그림 느낌 2D 벡터, 잉크 아웃라인 + 플랫 컬러, `gumgumi-intro` 팔레트 B와 동일 화풍
- 예상 본편 길이: 약 43초 (브랜드 인트로 2.3초 + 제목카드 1.8초 + 본편 43.15초 + 아웃트로 3.0초 = 총 약 50.3초, 60초 상한 이내)
- 9:16 세로 배치: 스케일 표지 14~22% / 그림 무대 24~64% / 내레이션 자막 66~76% 고정

## 자체 점검 메모

- 설명 사슬 5개 고리 전부 비트 5~11에 `E`로 존재, 각 비트에 해당 내레이션 id 기입 완료
- 훅(비트1~2, 0~4.5초)은 설명·비교·도식 없이 장면만 보여줌(4.5초, 2.5초 이상 충족)
- 그림 시작 앵커는 전부 `sN.t0-0.3~0.4초`(핵심 어절 기준 아님), 완성만 핵심 어절(`@"..."`) 기준
- 라벨 L1/L2/L3는 각 대상 단어가 실제 발음되는 순간(`s3@"소용돌이"`, `s4@"위로"`, `s8@"맨 앞자리"`)에 팝인
- "상승기류 자리를 탄다" 표현은 01-fact.md 비유 점검표대로 정성적 수준("힘을 덜 쓴다")만 쓰고 "완전히 힘이 안 든다"는 과장을 쓰지 않음
- 굼구미는 전 비트에서 가리키기·비교하기·확대경 동작만 하고, 소용돌이·상승기류를 직접 만들지 않음(과학적 인과 칸이 굼구미로 시작하는 행이 없음)
- A 비트(1, 4)는 각각 1.2초, 0.7초로 1.4초 이하
- E 비트 합계 약 37.6초 / 전체 43.15초 = 약 87% (55% 이상 충족)
- 소용돌이·상승기류·맨 앞자리 모두 첫 등장 시 라벨 있음
- 비트 3(의외성)·비트 7(날갯짓 크기)에서 같은 화면 나란히 비교 배치
- 동시 표시 최대 내레이션 자막 1 + 라벨 1(L1/L2/L3는 겹치지 않게 순차 배치)
- 화면 숫자 없음(N 라벨 미사용)
- 굼구미에게 머리카락·옷·코·귀·손가락 묘사 없음

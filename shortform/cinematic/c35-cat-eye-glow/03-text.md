# c35 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("고양이 눈이 밤에 빛나는 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

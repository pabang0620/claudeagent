# c35 굼구미 설명 리뷰 (1라운드)

## 판정: PASS

## 시청 시뮬레이션 요약

1. 제목카드: "고양이 눈이 밤에 빛나는 이유" - 주제 확정.
2. 비트1(0.00-4.50, s1): 캄캄한 마당에 고양이가 앉아 있고 굼구미는 꺼진 손전등을 들고 있다. "고양이가 캄캄한 마당에 앉아 있어요." -> 설명 없는 순수 장면 설정.
3. 비트2(s2): 손전등을 켜자 눈이 확 연두빛으로 번쩍인다. "손전등을 비추면 눈이 확 빛나요." -> 익숙한 현상(기대) 확인.
4. 비트3(s3): 손전등을 끄자 눈이 다시 짙은 초록으로 돌아가 안 빛난다. "근데 빛이 없으면 안 빛나요." -> 반전: 스스로 빛나는 게 아니다.
5. 비트4(s4): 휩 전환으로 눈 속으로 확대, 스케일 표지 "눈 속 단면 확대". "눈 속으로 확대해서 볼게요." -> 진입.
6. 비트5(L1 "망막", s5): 동공에서 들어온 노란 화살표가 분홍 망막 막을 지나간다. "들어온 빛은 망막을 통과해요." -> 고리1.
7. 비트6(L2 "반사층", s6): 망막 뒤 청록 반사막에 화살표가 닿아 꺾인다. "반사층이 그 빛을 튕겨내요." -> 고리2.
8. 비트7(s7): 되돌아간 화살표가 망막을 반대 방향으로 다시 지나간다(하이라이트 펄스). "튕긴 빛이 망막을 다시 지나가요." -> 고리3 전반.
9. 비트8(s8): 감지 세포 점들이 밝아지고, 어둠 속 사물이 살짝 또렷해지는 인셋 비교. "그래서 어두운 곳도 더 잘 보여요." -> 고리3 효과.
10. 비트9(s9): 화살표가 동공 밖으로 빠져나가며 노랑->연두로 색이 바뀐다. "반사된 빛 일부는 눈 밖으로 나가요." -> 고리4.
11. 비트10(s10): 마당으로 컷백, 도식 유령 윤곽이 고양이 눈에 겹쳤다 사라진다. "그 빛이 바로 우리가 보는 반짝임이에요." -> 도식과 실제 현상을 연결.
12. 비트11(s11): 굼구미가 카메라를 보며 정리. "빛이 있어야만 고양이 눈이 빛나 보여요." -> 답 확정(비트3의 반전과 정확히 맞물림).
13. 비트12: 굼구미가 손전등을 딸깍딸깍 깜빡여 장난치고 고양이가 살짝 투덜댄다 -> 새 정보 없는 반전 코다.

이해 판정: 시뮬레이션 끝에서 시청자는 02-explain.md의 답 문장("반사층이 빛을 튕겨 망막을 한 번 더 지나가게 하고, 그 빛 일부가 다시 나오기 때문에 빛나 보인다 - 단 빛이 있을 때만")을 스스로 말할 수 있다. 4개 고리 전부 대응 그림이 있고 끊긴 고리 없음.

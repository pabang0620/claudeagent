## 동시 표시 점검 (자막은 해당 구간 t0~t1 동안 표시)
- 0.00-1.00: 없음. 1.00-1.04: s1 = 1. 1.04-3.04: L1 + s1 = 2. 3.04-3.84: L1 = 1. 3.84-4.04: L1 + s2 = 2. 4.04-6.54: s2 = 1.
- 7.24-9.83: s3 = 1. 9.51-9.83: S1 + s3 = 2. 9.83-10.53: S1 = 1. 10.53-11.01: S1 + s4 = 2.
- 11.01-13.45: L2 + L2b + s4 = 3 (상한과 일치, S1은 11.01에 퇴장). 13.45-13.55: L2 + L2b = 2. 13.55-13.95: L2 + L2b + S2 = 3 (상한과 일치). 13.95-14.35: S2 = 1. 14.35-15.27: S2 + s5 = 2.
- 15.27-16.15: L3 + s5 = 2. 16.15-17.93: L3 + L4 + s5 = 3 (상한과 일치). 17.93-18.23: L3 + L4 = 2.
- 18.63-19.77: s6 = 1. 19.77-22.21: L5 + s6 = 2. 22.21-22.51: L5 = 1.
- 22.51-22.91: L6 = 1 (L5는 22.51에 퇴장). 22.91-23.83: L6 + s7 = 2. 23.83-26.16: L6 + L7 + s7 = 3 (상한과 일치). 26.16-26.46: L6 + L7 = 2.
- 26.86-30.11: s8 = 1.
- 30.61-31.01: S3 = 1. 31.01-32.21: S3 + s9 = 2. 32.21-34.26: s9 = 1. 34.26-35.66: 없음(비트10, 1.40초).
- V4 강조 자막(emph)은 구간 자막의 해당 어절을 키우고 색을 바꾸는 방식이며 별도 글자 요소가 아니다. 위 동시 개수에 더하지 않는다.
- 어느 시점도 3개를 넘지 않는다.

## 라벨 규칙 점검
- 라벨 6자 이내(공백 포함): 우유 2, 물 1, 단백질 3, 막 1, 수증기 3. 표지 10자 이내: 같은 불로 비교 7, 과장해 빨리 감기 9, 다시 냄비로 6.
- 노출 1.5초 이상: L1 3.00, S1 1.50, L2/L2b 2.94, S2 1.72, L3 2.96, L4 2.08, L5 2.74, L6 3.95, L7 2.63, S3 1.60. 전부 충족.
- 라벨은 대상이 처음 그려진 뒤 1초 안에 팝인: L1 우유 붓기 0.60 시작에서 1.04, L2/L2b 두 냄비 10.53 자리 잡음에서 11.01(0.48초), L3 알갱이 15.27 등장과 동시, L4 막 합쳐지기 15.82 시작에서 16.15(0.33초), L5 방울 19.44 등장에서 19.77, L6 물 쪽 22.51 등장과 동시, L7 우유 쪽 단면 22.51 등장에서 23.83(1.32초이나 이 우유는 L1·L2b에서 이미 이름이 붙은 대상이고 이번 비교를 위해 다시 붙인다).
- **라벨 팝인은 가리키는 어절 0.4초 전이다**: L1 s1@"우유를"-0.40, L2/L2b s4@"물은"-0.40, L3 s5@"단백질이"-0.40, L4 s5@"막이"-0.40, L5 s6@"수증기"-0.40, L6 s7@"물은"-0.40, L7 s7@"우유는"-0.40. 비트 끝에 몰아서 띄운 라벨 없음.
- 한 윤곽에 이름 두 개 금지: 막(호박색 층)과 단백질(막이 되기 전 알갱이)은 다른 윤곽이고, L7은 막이 아니라 막 아래 우유 몸통을 가리킨다.
- 레이아웃 간격: 칩끼리 20px 이상(L3 x 600-802와 L4 x 200-294, L6 x 120-214와 L7 x 640-788, L2 x 130-224와 L2b x 640-788), 칩과 도식 카드 테두리(x 65-900, y 461-1037) 20px 이상, 자막 띠(y 1250 이하)에 칩 없음. 비트7 수증기 줄기(x 300-420, 위쪽 끝 y 600)는 L6 칩(y 570까지)과 30px, L6 지시선(x 200)과 100px 떨어진다. 비트5 표면 김(위쪽 끝 y 600)은 L3·L4 칩과 30px 떨어진다.

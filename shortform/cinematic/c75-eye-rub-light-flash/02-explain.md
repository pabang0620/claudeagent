# c75 설명 사슬 - 눈을 비비면 빛이 번쩍이는 이유

## 질문

불 끈 방에서 눈을 비비면 왜 빛무늬가 보일까.

## 의외성

눈을 감았고 방도 캄캄한데 빛이 보이니 "틈으로 빛이 샌 것"이라고 믿기 쉽다. 실제로는 밖의 빛이 아니다. (s3이 "새어 들어온 게 아니에요"라고 말로 뒤집고, 창에서 눈으로 오던 점선 빛 위 X가 "밖의 빛이 아님"을 뜻한다. 이어서 s4가 "진짜 원인은 눈 안쪽 벽"으로 시선을 옮긴다.)

답 1문장: 눈을 비비면 눌린 망막 세포가 빛 없이도 신호를 내고, 뇌가 그 신호를 빛으로 읽어서 빛무늬가 보인다.

## "그래서?" 점검

s1 비볐다 -> s2 빛무늬가 보인다 -> 빛이 샌 건가? s3 아니다 -> 그럼 어디서? s4 눈 안쪽 망막 -> 망막이 뭘 하나? s5 빛을 받으면 신호를 낸다 -> 비비면? s6 망막이 눌린다 -> 눌리면? s7 빛이 없어도 신호를 낸다 -> 그 신호는? s8 시신경으로 뇌에 간다 -> 뇌는? s9 빛으로 읽어서 무늬가 보인다. 비약 없음.

연결(이전 결과어가 다음 주어):
- s3 -> s4: "빛이 새어 든 게 아니다"에서 "진짜 원인은 눈 안쪽"으로 시선을 옮기고 카드가 굼구미 눈에서 자람.
- s4 망막 -> s5: "망막이에요"를 "망막 세포는"으로 받음.
- s5 신호 -> s6: s6은 "이 망막이 눌려요"로 방금 본 망막으로 돌아가 눈 비비는 동작을 연결(패널은 흐려지고 눈 단면이 밝아짐).
- s6 눌려요 -> s7: "눌리면"으로 받고 패널이 다시 밝아짐.
- s7 신호를 내요 -> s8: "신호는"으로 받음.
- s8 시신경 -> s9: "눈의 신호를", 뇌가 주어.
- s9 -> 복귀: 도식의 노랑 무늬가 굼구미 풍선의 무늬로 이어짐(같은 노랑 고리+별).

용어 풀이: 망막(s4 "눈 안쪽 벽의", s5 "빛을 받으면 신호"로 기능 풀이), 시신경(s8 "눈에서 뇌로 가는"). 2개.

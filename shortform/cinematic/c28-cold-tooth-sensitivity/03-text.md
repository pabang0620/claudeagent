# c28 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨(스케일 표지 포함) 2 이하. 제목("찬물 마시면 이가 시린 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

## 동시 표시 점검
- 11.20-11.50: S1 단독 = 1개(s4 자막 시작 전).
- 11.50-13.89: S1 + s4 자막 = 2개.
- 13.89-14.39: 없음(S1 페이드 아웃, 고리1 등장 전 간격).
- 14.39-15.49: s5 자막 + L1 = 2개.
- 15.49-16.19: s5 자막 + L1 + L2 = 3개(L1이 곧 페이드아웃되는 짧은 겹침 구간).
- 16.19-17.30: s5 자막 + L2 = 2개(L1 페이드 아웃 후).
- 17.30-17.60: L2 단독 = 1개(간격, L2 꼬리만 남음).
- 17.60-17.70: 없음(L2도 페이드 아웃, s6 시작 전).
- 17.70-18.20: s6 자막 단독 = 1개(L4 등장 전).
- 18.20-19.40: s6 자막 + L4 = 2개.
- 19.40-19.70: s6 자막 + L4 + L3 = 3개("신경까지 이어진 관이" 구간에서 두 라벨이 짧게 겹침).
- 19.70-21.00: s6 자막 + L3 = 2개(L4 페이드 아웃 후).
- 21.00-21.40: 없음(L3 페이드 아웃, 고리2 등장 전 간격).

- 22.40-23.90: s7 자막 + L5 = 2개.
- 23.90-24.31: s7 자막 단독 = 1개(L5 페이드 아웃 후).
- 24.31-27.75: s8 자막 단독 = 1개(새 라벨 없음, 자극 장면).

# c40 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("선인장에 가시가 있는 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

|---|---|---|---|---|---|
| S1 | 스케일 표지 | 8.27-9.97 | 잎 표면 확대 | Leaf surface zoom | 그림 무대 위쪽 |
| L1 | 라벨 | 10.97-12.40 | 물 구멍 | Water pore | 구멍 옆, 지시선 |

| L4 | 라벨 | 23.92-24.93 | 물 저장 | Water storage | 줄기 안쪽층 옆, 지시선 |

## 동시 표시 점검
- 0.00-4.50: s1 자막 단독 = 1개(라벨 없음, 훅 비트).
- 4.50-5.10: 없음(간격).
- 5.10-8.27: s2 자막 단독 = 1개.
- 8.27-8.97: S1 단독 = 1개(진입 비트, 내레이션 없음).
- 8.97-9.97: S1(페이드 아웃 중) + s3 자막 = 2개.
- 9.97-10.97: s3 자막 단독 = 1개(S1 소멸 후, L1 등장 전).
- 10.97-12.40: L1 + s3 자막 = 2개.
- 12.40-12.80: 없음(간격, L1 소멸).
- 12.80-16.10: s4 자막 단독 = 1개(라벨 없음).
- 16.10-16.50: 없음(간격).
- 16.50-18.90: s5 자막 단독 = 1개(L2 등장 전).
- 18.90-20.32: L2 + s5 자막 = 2개.
- 20.32-20.72: 없음(간격, L2 소멸).
- 20.72-22.02: s6 자막 단독 = 1개(L3 등장 전).
- 22.02-23.92: L3 + s6 자막 = 2개(L4 등장 전).
- 23.92-24.93: L3 + L4 + s6 자막 = 3개(상한과 정확히 일치, 초과 아님).
- 24.93-25.53: 없음(간격, L3·L4 소멸).
- 25.53-28.96: s7 자막 단독 = 1개(라벨 없음).
- 28.96-29.46: 없음(간격).
- 29.46-33.54: s8 자막 단독 = 1개(라벨 없음).
- 33.54-34.54: 없음(반전 비트, 자막·라벨 없음).
- 어느 시점도 상한(3개)을 넘지 않는다.

## 숫자(N)
화면 숫자 없음. `01-fact.md`에서 버린 사실(수분 손실 비율 등)은 대본 규칙(숫자는 화면이 읽지 않는다)에 따라 화면에도 쓰지 않는다. "구멍이 많다 -> 줄었다"는 관계만 그림(구멍 개수 변화)과 라벨로 정성적으로 보여준다.

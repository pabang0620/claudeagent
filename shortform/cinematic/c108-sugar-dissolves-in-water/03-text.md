# c108 화면 글자 (내레이션 자막 제외 - 자동 표시)

한 화면 동시 최대: 내레이션 자막 1 + 라벨/표지 2 (퇴장·팝인 겹침 포함). 제목은 브랜드 제목카드가 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다.

시각은 `narration-ko.json` 기준 예상 절대 초(글자수x0.11+문장끝 0.5, 어절 시각 = 구간 t0 + 어절 시작 글자 위치x0.11, 검토용)다. 실제 값은 TTS 후 확정하고 애니메이터는 앵커를 쓴다. **라벨은 해당 어절보다 0.4초 먼저 팝인**하고 어절이 끝날 때까지 유지된다.

## 동시 표시 점검 (자막은 해당 구간 t0~t1 동안 표시)

- 5.25-5.29: s2 = 1. 5.29-7.40: L1 + s2 = 2. 7.40-7.50: 없음. 7.50-8.80: S1 = 1. 8.80-9.20: S1 + s3 = 2. 9.20-9.25: s3 = 1. 9.25-9.94: S4 + s3 = 2. 9.94-10.95: S4 + L2 + s3 = 3 (상한과 일치). 10.95-12.05: L2 + s3 = 2.
- 12.67-12.85: L3 = 1. 12.85-15.40: L3 + s4 = 2. 15.40-15.77: s4 = 1. 15.77-16.47: 없음.
- 16.47-17.50: s5 = 1. 17.50-19.60: L4 + s5 = 2. 19.60-19.72: s5 = 1.
- 20.42-21.78: s6 = 1. 21.78-23.45: L5 + s6 = 2. 23.45-23.75: L5 = 1.
- 24.15-25.51: s7 = 1. 25.51-27.40: L6 + s7 = 2. 27.40-27.45: L6 = 1. 27.45-27.70: L6 + S2 = 2. 27.70-28.40: S2 = 1. 28.40-29.05: S2 + s8 = 2. 29.05-30.77: s8 = 1.
- 31.20-31.57: S3 = 1. 31.57-32.05: S3 + s9 = 2. 32.05-32.90: S3 + L7 + s9 = 3 (상한과 일치). 32.90-34.82: L7 + s9 = 2.
- 34.82-35.72: 없음.

## 라벨 규칙 점검
- 라벨 6자 이내(공백 포함): 있던 자리 5, 설탕 분자 5, 물 분자 4, 끌어당김 4, 퍼져 나감 5, 눈에는 투명 6, 흩어진 설탕 6. 표지 10자 이내: 되감아 분자 확대 9, 크기·개수 단순화 9, 다시 컵 크기로 8, 물속 확대 5.
- 노출 1.5초 이상: L1 2.11, S1 1.70, S4 1.70, L2 2.11, L3 2.73, L4 2.10, L5 1.97, L6 2.19, S2 1.60, S3 1.70, L7 2.77. 전부 충족.
- 라벨은 대상이 처음 그려진 뒤 1초 안에 팝인: L1 점선 더미 윤곽(4.95 시작, 5.29), L2 마지막 분자 완성(9.80) 뒤 0.14초(9.94), L3 첫 물 분자(12.45 입장, 12.67), L4 화살표(17.50 동시), L5 점선 화살표(21.78 동시), L6 맨눈 창(24.00 자람 시작 뒤 1.51초에 이미 형태가 갖춰진 상태, 창은 느리게 자라며 25.51에 이미 칩이 가리킬 윗변이 그려져 있음), L7 퍼진 설탕 분자(패널 31.20-31.90에 자라 나와 있고 31.65부터 빛무리, 32.05).
- **새 그림·라벨이 어절보다 0.4초 먼저**: L1 5.29 vs 5.69, L2 9.94 vs 10.34, L3 12.67 vs 13.07, L4 17.50 vs 17.90, L5 21.78 vs 22.18, L6 25.51 vs 25.91, L7 32.05 vs 32.45. 맨눈 창 24.00 시작(어절 "안" 26.24 완성), 비트6 분자 출발 20.10(어절 "나가요" 22.51 완성).
- 한 윤곽에 이름 두 개 금지: 설탕 분자 칩(L2)은 격자 속 분자, L7은 흩어진 분자 상태이므로 서로 다른 시점 상태. 같은 시점에 한 분자에 두 이름 없음. 점선 윤곽 라벨은 L1(컵 바닥 더미 자리) 하나뿐이고 비트5·6의 분자 자리 점선은 라벨 없이 같은 선 스타일로만 "원래 있던 자리"로 읽히게 한다.
- S4 "크기·개수 단순화": 설탕 알갱이는 실제로 분자가 훨씬 많고 분자는 도형으로 단순화했음을 비트3에서 한 번 밝힌다.
- 레이아웃 간격: 칩끼리·칩과 굼구미·칩과 패널 테두리(상단 461) 20px 이상(좌표는 04-storyboard.md). 자막 띠(y 1250 이하)에 칩 없음(최대 y 770 또는 패널 위쪽 554).

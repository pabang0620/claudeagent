# c77 설명 사슬 - 시소가 가벼운 쪽과 균형을 잡는 이유

## 질문

무거운 쪽이 내려가는 시소에서, 가벼운 아이는 어떻게 무거운 쪽과 균형을 잡을까.

## 의외성

"무거운 쪽이 무조건 내려간다"고 믿기 쉽다. 실제로는 무게 말고 받침점까지의 거리도 같이 작용한다. s2가 "무게만으로 내려갈 쪽이 정해지는 건 아니에요"라고 말로 뒤집고, 말풍선 안 작은 시소가 포대 그대로인데 수평인 모습을 보여준다(반박 그림은 같은 포대의 다른 자리). 이어서 s3-s6이 거리라는 빠진 변수를 채운다.

## 인과 고리 (내레이션은 narration-ko.json)

| 고리 | 내레이션(ko) | 봐야 하는 그림 | 피해야 할 오해 |
|---|---|---|---|
| 훅 s1 | 시소에 무거운 포대와 앉으면 포대 쪽이 쿵 내려가요. | 놀이터 시소, 굼구미 오른쪽 위, 포대 왼쪽 아래(둘 다 받침점에서 같은 거리). 설명·도식 없음 | 굼구미가 포대를 누름 |
| 의외성 s2 | 무게만으로 내려갈 쪽이 정해지는 건 아니에요. | 말풍선: 작은 시소에 포대는 받침점 가까이, 굼구미는 멀리, 수평 | 무게가 무관하다 |
| 진입 A | (없음) | 말풍선 사라지고 굼구미 눈이 받침점으로 | - |
| 고리1 s3 | 시소는 가운데 받침점을 중심으로 돌아요. | 받침점에 노란 돌아가는 고리 + 라벨 "받침점" | 시소가 위아래로 평행 이동 |
| 고리2 s4 | 같은 무게도 받침점에서 멀수록 돌리는 힘이 커져요. | 굼구미 자리까지 파랑 거리 띠, 끝 자리에 유령 굼구미와 긴 띠, 보라 힘 막대(실선 짧음, 점선 연장). 라벨 "거리", "돌리는 힘" | 몸이 무거워짐 / 힘이 센 쪽 사람이 바뀜 |
| 고리3 s5 | 굼구미가 끝으로 가면 돌리는 힘이 점점 커져요. | 굼구미가 끝으로 이동하며 띠와 막대가 따라 자람. 이동이 끝나면 포대 쪽 막대 자리(점선)와 포대 쪽 거리 띠가 미리 나타남(s6 연결용) | 굼구미가 시소를 밀어 기울임 |
| 고리4 s6 | 포대 쪽 돌리는 힘과 같아지면 시소가 수평이 돼요. | 왼쪽 포대 막대가 자라 오른쪽 막대와 같은 길이가 되고, 시소가 수평으로 올라옴 | 같은 무게일 때만 수평 |
| 답 s7 | 무거워도 받침점 가까이 앉으면 균형이 맞아요. | 포대 쪽 짧은 파랑 띠(가까움), 굼구미 쪽 긴 띠(멀다), 수평 유지 | 포대가 가벼워짐 |
| 반전 A | (없음) | 굼구미가 두 팔을 옆으로 벌려도 시소는 수평 | 굼구미가 받치고 있음 |

답 1문장: 시소를 돌리는 힘은 무게와 받침점까지의 거리로 정해져서, 무거워도 받침점 가까이 앉으면 가벼운 쪽과 균형이 맞는다.

## "그래서?" 점검

s1 포대 쪽이 내려간다 -> 무거워서만? s2 무게만으로 정해지지 않는다 -> 또 뭐가 있나? s3 시소는 받침점을 중심으로 돈다 -> 돌리는 크기는? s4 멀수록 돌리는 힘이 커진다 -> 그래서? s5 굼구미가 끝으로 가면 커진다 -> 어디까지? s6 포대 쪽과 같아지면 수평 -> 결론? s7 무거워도 가까이면 균형. 비약 없음.

연결(이전 결과어가 다음 주어):
- s1 "내려가요" -> s2 "내려갈 쪽".
- s3 "돌아요" -> s4 "돌리는 힘".
- s4 "돌리는 힘이 커져요" -> s5 "돌리는 힘이 점점 커져요"(굼구미 적용).
- s5 "커져요" -> s6 "같아지면"(포대 쪽 힘과 비교). 포대는 s1에서 이미 나온 말.
- s6 "수평이 돼요" -> s7 "균형이 맞아요".

용어 풀이: "받침점"(s3, 그림 + 라벨이 가운데 고정 지점임을 보여줌), "돌리는 힘"(s3 "돌아요" 바로 뒤 s4에서 같은 뜻). 두 개.

## 그림 일관 규칙 (04와 동일)

- 대상: 굼구미 1, 포대 1(굼구미 2배 무게, 굼구미 몸보다 폭이 크게 그림), 시소판 1, 받침점 삼각대 1, 말풍선 1(작은 시소 1, 큰 포대 아이콘 1, 작은 굼구미 아이콘 1), 유령 굼구미 1, 거리 띠(굼구미 쪽 1, 포대 쪽 1), 힘 막대(오른쪽 1, 왼쪽 1)와 막대 끝 탭 2.
- 거리: 포대는 받침점에서 150 고정, 굼구미는 150에서 300으로 이동. 굼구미 높이 216(화면 폭의 20%).
- 색: 거리 파랑, 돌리는 힘 보라, 받침점 노랑 고리, 유령은 회색 점선.

# c05 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("달 무늬가 항상 똑같은 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

|---|---|---|---|---|---|
| S1 | 스케일 표지 (D.scaleBadge) | 11.00-12.50 | 지구-달 확대 | Earth-Moon zoom | 그림 무대 위쪽 |
| L1 | 라벨 (2회 등장) | 12.80-14.41, 18.74-22.30 | 자전 | Spin | 달 옆, 자전 화살표 지시선 |

## 동시 표시 점검
- 11.00-11.50: S1 단독 = 1개(s4 자막 시작 전).
- 11.50-12.50: S1 + s4 자막 = 2개.
- 12.50-12.80: s4 자막 단독 = 1개(S1 페이드 아웃 후).
- 12.80-14.41: L1 + L2 + s4 자막 = 3개(상한과 정확히 일치, 초과 아님).
- 14.41-14.91: 없음(고리1 등장 전 간격).
- 14.91-18.34: L3 + s5 자막 = 2개.
- 18.34-18.74: 없음(간격).
- 18.74-22.30: L1(재등장) + s6 자막 = 2개.
- 22.30-22.70: 없음(간격).
- 22.70-26.39: s7 자막 단독 = 1개(라벨 없음, 지구-부풀림 상호작용에만 집중).
- 26.39-26.79: 없음(간격).
- 26.79-29.96: L4 + s8 자막 = 2개.
- 29.96-30.46: 없음(간격).
- 30.46-32.59: L5 + s9 자막 = 2개.
- 32.59-33.19: L5 단독 = 1개(s9 자막 종료 후 짧은 꼬리).
- 33.19-36.75: s10 자막 단독 = 1개(라벨 없음, 밤하늘로 복귀).
- 36.75-37.75: 없음(반전 버튼, 자막·라벨 없음).
- 어느 시점도 상한(3개)을 넘지 않는다.

## 숫자(N)
화면 숫자 없음. `01-fact.md`의 A등급 숫자(자전·공전 주기 일수)는 대본 규칙(숫자는 화면이 읽지 않는다 + 이번 편은 숫자 라벨 자체를 쓰지 않는 방향)에 따라 화면에 쓰지 않는다. "자전=공전"이라는 관계만 라벨(L4 "동주기")로 보여준다.

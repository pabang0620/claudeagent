# 굼구미 시네마틱 c123 - 스위치를 누르면 전구가 바로 켜지는 이유 (9:16)

Canvas 1080x1920 (9:16), 30fps 출력, 그림은 on twos(2프레임마다 갱신), 휙 지나가는 순간만 on ones. 본편만 다룬다 - 브랜드 인트로·제목카드·아웃트로는 엔진이 붙인다. 제목카드가 주제를 보여주므로 본편에서 주제 자막을 다시 띄우지 않는다.

예상 본편 길이 **약 35.34초**(구간 길이 = 글자수x0.11+0.72, gap 포함, 비트9 1.40초). 실제 TTS는 이보다 짧을 수 있고 앵커 기준으로 만든다. 내레이션 8구간, 비트 9개.

V4 강조 자막(emph)은 구간 자막의 해당 어절을 키우는 방식이라 별도 글자 요소가 아니다(동시 글자 3개 상한에 더하지 않는다).

굼구미: 흰 몸, 잉크 `#252E3A`, 코랄 볼 `#FC876E`. 머리카락·옷·코·귀·손가락 묘사 없음. 굼구미는 스위치를 누르고 가리키는 실험자·안내자이며 전자와 전선에 손대지 않는다. 굼구미는 y 1250 아래, x 85% 이후에 들어가지 않고 모든 표시와 20px 이상 떨어진다. **따라 할 위험 요소 없음**: 건전지 1개와 꼬마전구만 쓰고 콘센트·큰 전기·쇼트 장면은 그리지 않는다.

**전자 방향 방침**: 건전지는 마개 쪽이 양극(위), 아래쪽이 음극이다. 전자는 음극(아래)에서 나와 아래 전선은 오른쪽, 오른쪽 전선은 위, 위 전선은 왼쪽(양극 마개)으로 한 바퀴 돈다. 실험판 비트8의 점은 이 방향으로만 움직인다. 도식 카드(비트4~7)는 **아래 전선(건전지 음극과 스위치 사이)에서 자라 나오는 모식도**이므로 카드 안 점은 건전지 블록에서 멀어지는 오른쪽으로 움직여 같은 방향이 되며, 카드 안 건전지 블록에는 극성 표시(+/-)를 쓰지 않는다. 방향은 움직임으로만 보이고 글자로 말하지 않는다.

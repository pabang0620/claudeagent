# 굼구미 시네마틱 c107 - 솔방울이 비 오면 닫히는 이유 (9:16)

Canvas 1080x1920 (9:16), 30fps 출력, 그림은 on twos(2프레임마다 갱신), 휙 지나가는 순간만 on ones. 본편만 다룬다 - 브랜드 인트로·제목카드·아웃트로는 엔진이 붙인다. 제목카드가 주제를 보여주므로 본편에서 주제 자막을 다시 띄우지 않는다.

예상 본편 길이 **약 36.2초**(글자수x0.11+0.72). 실제 TTS는 이보다 짧을 수 있고 앵커 기준으로 만든다. 내레이션 9구간, 비트 10개.

V4 강조 자막(emph)은 구간 자막의 해당 어절을 키우는 방식이라 별도 글자 요소가 아니다(동시 글자 3개 상한에 더하지 않는다).

굼구미: 흰 몸, 잉크 `#252E3A`, 코랄 볼 `#FC876E`. 머리카락·옷·코·귀·손가락 묘사 없음. 굼구미는 비를 내리거나 솔방울을 움직이지 않는다. 우산을 쓰고 지켜보고, 손바닥을 내밀고, 가리키는 실험자·안내자다. 굼구미는 y 1250(65%) 아래, x 85% 이후에 들어가지 않고 모든 표시와 20px 이상 떨어진다.

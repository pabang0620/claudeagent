# c48 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("피부가 햇볕에 타는 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

| id | 종류 | 등장~퇴장(예상 초) | ko | en | 위치 |
|---|---|---|---|---|---|
| S1 | 스케일 표지 (D.scaleBadge) | 10.96-12.46 | 피부 속으로 확대 | Zoom into the skin | 그림 무대 위쪽 |
| L1 | 라벨 | 11.81-15.33 | 자외선 | UV Rays | 화살표 옆, 지시선 |
| L2 | 라벨 | 16.72-19.02 | 색소 | Pigment | 알갱이 옆, 지시선 |
| L3 | 라벨 | 19.02-23.93 | 세포핵 | Nucleus | 핵 옆, 지시선 |
| L4 | 라벨 | 27.68-29.70 | 화상 | Sunburn | 패널 옆, 지시선 |

라벨 팝인 시점은 전부 해당 단어가 실제로 발음되는 순간이다: L1은 s4의 "자외선이", L2는 s5의 "색소를", L3는 s6의 "세포핵", L4는 s8의 "화상이"가 발음되는 순간 팝인한다.

## 동시 표시 점검
- 0.00-1.20: 없음(훅 settle, A).
- 1.20-3.85: s1 자막만 = 1개.
- 3.85-4.25: 없음(전환 간격).
- 4.25-6.77: s2 자막만 = 1개.
- 6.77-7.27: 없음(전환 간격).
- 7.27-10.96: s3 자막만 = 1개.
- 10.96-11.76: S1 단독 = 1개(s4 자막 시작 전, 확대 전환 A 구간).
- 11.76-11.81: s4 자막 + S1 = 2개.
- 11.81-12.46: s4 자막 + S1 + L1 = 3개(상한과 정확히 일치, 초과 아님).
- 12.46-14.93: s4 자막 + L1 = 2개.
- 14.93-15.33: L1 단독 = 1개(s4 종료, s5 시작 전 간격).
- 15.33-16.72: s5 자막만 = 1개.
- 16.72-18.11: s5 자막 + L2 = 2개.
- 18.11-18.51: L2 단독 = 1개(s5 종료, s6 시작 전 간격).
- 18.51-19.02: s6 자막 + L2 = 2개.
- 19.02-21.55: s6 자막 + L3 = 2개(L2가 L3로 교대).
- 21.55-21.95: L3 단독 = 1개(전환 간격).
- 21.95-23.93: s7 자막 + L3 = 2개.
- 23.93-24.47: s7 자막만 = 1개(L3 종료).
- 24.47-25.07: 없음(컷백 A 구간).
- 25.07-27.68: s8 자막만 = 1개.
- 27.68-28.50: s8 자막 + L4 = 2개.
- 28.50-29.70: L4 단독 = 1개(반전 버튼, 자막 없음).
- 어느 시점도 상한(3개)을 넘지 않는다.

화면 숫자 없음. `01-fact.md`에서 다루지 않기로 한 수치(자외선 파장, 자외선지수, 멜라닌 생성량)는 화면·내레이션 어디에도 쓰지 않는다.

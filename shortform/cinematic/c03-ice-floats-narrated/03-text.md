# c03 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("얼음이 물에 뜨는 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

## 동시 표시 점검
- 8.87-9.07: S1+L1 = 2개(내레이션 자막 아직 시작 전, S1은 캡션 시작 전 종료).
- 9.17-10.87: L1+s3 자막 = 2개.
- 13.26-13.80: s4 자막 단독 = 1개.
- 13.80-15.80: L2+s4 자막 = 2개.
- 16.79-20.26: L3+L4+s5 자막 = 3개(상한 "자막1+라벨2"와 정확히 일치, 초과 아님).
- 20.36-23.70: L3+L4+s6 자막 = 3개(동일).
- 24.00-28.25: 라벨 없음, s7 자막만 = 1개.

## 숫자(N)
화면 숫자 없음. `01-fact.md`의 A등급 숫자(밀도값 0.92/1.00 g/cm³, 부피 증가율, 수면 노출비)는 30자 이내 자막 원칙과 분량 제약으로 이번 판에서도 화면에 쓰지 않는다(c01/c02와 동일 판단).

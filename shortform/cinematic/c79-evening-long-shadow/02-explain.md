# c79 설명 사슬 - 저녁에 그림자가 길어지는 이유

## 질문

저녁에는 왜 그림자가 길어질까.

## 의외성

해가 멀어져서 길어진다고 믿기 쉽다. 실제로는 해와의 거리가 아니라 해의 높이(빛이 들어오는 기울기)가 길이를 정한다. (s2가 "멀어져서 길어지는 건 아니에요"라고 말로 뒤집고 X가 그 뜻을 맡는다. s3이 "해의 빛은"으로 진짜 원인 쪽으로 시선을 옮긴다.)

## "그래서?" 점검

s1 길어진다 -> 해가 멀어져서? s2 아니다 -> 그럼 뭐가? s3 빛이 곧게 가다 막힌다 -> 그래서? s4 못 가는 뒤쪽이 그림자 -> 길이는? s5 끝은 머리끝 스친 빛이 닿는 곳 -> 그게 달라지나? s6 높으면 가까이 -> 낮으면? s7 낮으면 멀리 -> 결론 s8 저녁엔 길다. 비약 없음.

왜 위쪽 빛은 끝 너머, 아래쪽 빛은 막히나(s5): 머리끝보다 위로 지나간 빛은 막히지 않아 끝 너머 땅을 비추고, 아래쪽 빛은 몸에 막힌다. 그 경계가 머리끝을 스친 빛이다(그림에서 위·아래 광선으로 보임).
왜 낮으면 멀리 닿나(s7): 같은 높이를 내려오는 동안 비스듬한 빛이 옆으로 더 많이 가기 때문(그림에서 광선 기울기와 고리 이동으로 보임, 내레이션은 "비스듬히 와서").

연결(이전 결과어가 다음 주어):
- s2 -> s3: "해가" -> "해의 빛은"(이유를 해의 거리에서 빛으로 옮김).
- s3 막혀요 -> s4: "빛이 못 가는".
- s4 그림자 -> s5: "그림자 끝은".
- s5 닿는 곳 -> s6: "그 빛이 ... 가까이 닿아요".
- s6 -> s7: "해가 낮으면 그 빛이 ... 멀리 닿아요"(같은 문형 대비).
- s7 멀리 -> s8: "해가 낮은 저녁엔 ... 길어져요"(훅으로 복귀).

용어 풀이: 전문용어 없음. "그림자 끝", "머리끝"은 그림과 같이 일상어.

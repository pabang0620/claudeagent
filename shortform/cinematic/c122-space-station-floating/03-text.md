## 동시 표시 점검 (자막은 해당 구간 t0~t1 동안 표시)
- 0.00-0.60: 없음. 0.60-1.00: L1 = 1. 1.00-4.03: L1 + s1 = 2. 4.03-4.43: L1 = 1.
- 4.43-4.83: 없음 (L1 퇴장). 4.83-5.20: s2 = 1. 5.20-6.70: L2 + s2 = 2. 6.70-7.86: s2 = 1. 7.86-8.26: 없음.
- 8.26-8.66: S1 + L3 = 2. 8.66-9.76: S1 + L3 + s3 = 3. 9.76-10.02: S1 + s3 = 2. 10.02-12.46: S1 + L4 + s3 = 3. 12.46-12.76: S1 + L4 = 2.
- 12.76-12.86: S1 + L4 + S2 = 3 (L4 퇴장 직전). 12.86-13.26: S1 + S2 = 2. 13.26-14.26: S1 + S2 + s4 = 3. 14.26-15.76: S1 + L5 + s4 = 3 (S2 퇴장과 L5 팝인이 같은 순간). 15.76-16.95: S1 + s4 = 2. 16.95-17.35: S1 = 1.
- 17.35-17.75: S1 + L6 = 2. 17.75-18.85: S1 + L6 + s5 = 3. 18.85-19.00: S1 + s5 = 2. 19.00-21.66: S1 + L7 + s5 = 3. 21.66-21.85: S1 + L7 = 2. 21.85-22.06: L7 = 1.
- 22.06-22.46: S4 = 1 (L7 퇴장). 22.46-22.83: S4 + s6 = 2. 22.83-23.56: S4 + L8 + s6 = 3. 23.56-25.82: L8 + s6 = 2. 25.82-26.22: L8 = 1.

- 30.38-30.78: 없음. 30.78-34.25: s8 = 1. 34.25-35.65: 없음 (비트9 1.40초).
- V4 강조 자막(emph)은 구간 자막의 해당 어절을 키우고 색을 바꾸는 방식이며 별도 글자 요소가 아니다. 위 동시 개수에 더하지 않는다.

# c102 화면 글자 (내레이션 자막 제외)

한 화면 동시 최대: 자막 1 + 라벨/표지 2. 주제 자막은 제목카드가 보여주므로 본편에서 다시 띄우지 않는다. 숫자 없음.

**emph(강조 어절)는 자막 띠 안에서 그 어절만 색·크기로 튀는 효과이며 별도 글자 오버레이가 아니다.** 아래 동시 글자 수에 더하지 않는다.

내레이션 구간 시각(예상, 구간 시작 = 앞 구간 끝 + gap, 길이 = 글자수 x 0.11): s1 1.00-3.64 / s2 4.24-6.33 / s3 7.13-9.66 / s4 10.36-13.22 / s5 13.92-16.45 / s6 17.15-20.23 / s7 21.03-24.11 / s8 25.01-27.65. 실제는 TTS 후 앵커로 확정.

라벨 칩 폭 = 글자수(공백 포함) x54+40px, 높이 약 70px.

## 동시 표시 점검 (자막은 해당 구간 s0.t0~s0.t1 동안 표시)
- 1.00-3.64: s1 = 1. 4.24-6.33: s2 = 1.
- 6.73-7.13: S1 = 1. 7.13-8.12: S1 + s3 = 2. 8.12-8.23: S1 + L1 + s3 = 3. 8.23-8.56: L1 + s3 = 2.
- 8.56-9.66: L1 + L2 + s3 = 3. 9.66-10.06: L1 + L2 = 2. 10.06-10.16: L2 = 1.
- 10.36-10.91: s4 = 1. 10.91-13.22: L3 + s4 = 2. 13.22-13.52: L3 = 1.
- 13.92-16.45: s5 = 1. 17.15-19.02: s6 = 1. 19.02-20.23: L4 + s6 = 2. 20.23-20.63: L4 = 1.
- 21.03-21.13: s7 = 1. 21.13-23.02: L5 + s7 = 2. 23.02-23.12: s7 = 1.
- 23.12-24.11: L6 + S2 + s7 = 3 (상한). 24.11-24.72: L6 + S2 = 2. 24.72-24.80: L6 = 1.
- 25.01-27.65: s8 = 1 (라벨 없음).
- 3개 초과 지점 없음(emph는 자막 안 효과라 제외).

## 규칙 점검
- 라벨 글자수: 공기 2, 물 2, 근육 2, 소리 2, 음식 2, 빈 속 3(공백 포함), 표지 S1 7, S2 7(10자 이내).
- 노출 1.5초 이상: S1 1.50, L1 1.94, L2 1.60, L3 2.61, L4 1.61, L5 1.89, L6 1.68, S2 1.60.
- 라벨 팝인은 가리키는 단어 발음 순간: 공기(s3@"공기와"), 물(s3@"물이"), 근육(s4@"근육이"), 소리(s6@"소리가"), 음식(s7@"음식이"), 빈 속(s7@"비면").
- 배 속 단면 자체 이름은 S1 "위와 장 단면"이 담당(위/장 각각의 라벨 없음, 한 윤곽에 이름 둘 금지).
- 칩은 모두 y 1190px 위, 자막 띠(y 1250 이하)에 없음. L2 칩 하단 1018px과 굼구미 머리 윗변 1056px은 38px 간격.

# c102 메타

## 제목 (제목카드에 그대로 나옴)
**배에서 꼬르륵 소리가 나는 이유**

## 아웃트로 다음 편 힌트
- 한국어: 다음 편에서 알려줄게!

## 해시태그
#꼬르륵 #배에서소리 #소화 #과학상식 #굼구미

## 설명
```
배에서 나는 꼬르륵 소리는 굶주린 배가 우는 소리가 아니래요.
위와 장 근육이 오므라들면서 속의 공기와 물이 좁은 틈으로 밀려갈 때 나는 소리고, 속이 비어 있으면 더 잘 들려요.
```

## BGM
04_autumn_lofi - 조용한 교실의 나른하고 차분한 분위기에 맞는 로파이 곡이라 꼬르륵 효과음이 돋보이고, 내레이션 위에서 -12dB 덕킹되어도 방해되지 않는다.

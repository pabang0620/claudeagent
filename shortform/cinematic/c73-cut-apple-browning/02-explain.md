# c73 설명 사슬 - 자른 사과가 갈색이 되는 이유

## 질문

자른 사과 속살은 왜 갈색이 될까.

## 의외성

공기에 닿기만 하면 저절로 변한다고 믿기 쉽다. 실제로는 속살 세포 안의 효소와 재료가 섞여야 하고, 산소는 그 반응에 쓰인다. (s2가 "닿기만 하면 변하는 것은 아니에요"라고 말로 뒤집고, 풍선의 공기 -> 갈색 그림 위 X가 "공기만으로는 부족"을 뜻한다. 이어서 s3-s6이 빠진 조건을 채운다.)

## "그래서?" 점검

s1 갈색이 된다 -> 공기 때문 아닌가? s2 "닿기만 하면 변하는 것은 아니에요"(공기만으로는 부족) -> 무엇이 더 있나? s3 방마다 효소 -> 변할 재료는? s4 칸막이 너머에 따로 -> 그런데 왜 자르면? s5 칸막이가 터져 섞인다 -> 섞이면? s6 효소가 산소로 재료를 갈색으로 바꾼다 -> 그래서? s7 갈색 물질이 쌓여 갈색이 된다. 비약 없음.

연결(이전 결과어가 다음 주어):
- s2 -> s3: 확대 카드가 사과 단면에서 자라고 문장이 "속살의 작은 방"으로 시작.
- s3 효소 -> s4 재료: "효소가 있어요" 뒤 "갈색이 될 재료는 ... 따로".
- s4 칸막이 -> s5: "칸막이 너머"를 "칸막이가 터져"로 받음. "자른 자리"가 훅의 자름과 이어짐.
- s5 섞여요 -> s6: "섞인 효소가".
- s6 갈색으로 바꿔요 -> s7: "갈색이 된 재료가", "자른 사과가"로 실제 장면 복귀.

용어 풀이: 효소(s3 "반응을 돕는")만 풀이. 산소는 일상어로 둠.

# 굼구미 시네마틱 c133 - 파도가 해변에서 부서지는 이유 (9:16)

Canvas 1080x1920 (9:16), 30fps 출력, 그림은 on twos(2프레임마다 갱신), 휙 지나가는 순간(패널 자라남·줄어듦, 마루가 말려 떨어짐, 거품 터짐)만 on ones. 본편만 다룬다 - 브랜드 인트로·제목카드·아웃트로는 엔진이 붙인다. 제목카드가 주제를 보여주므로 본편에서 주제 자막을 다시 띄우지 않는다.

예상 본편 길이 **약 34.21초**(구간 길이 = 글자수x0.11+0.72, gap 포함, 비트8 1.40초). 실제 TTS는 이보다 짧거나 길 수 있고 앵커 기준으로 만든다. 내레이션 8구간, 비트 8개. 설명 사슬은 훅 s1 + 의외성 s2 + 반박 s3 + 인과 고리 4(s4, s5, s6, s7) + 답 s8.

효과음·파도 부서짐 시각은 절대 초가 아니라 어절 앵커에 묶는다(`s1@"부서져요"`, `s2@"부서져요"`, `s7@"넘어져요"`, `s8@"부서져요"`). **부서지는 그림(마루가 말려 넘어지고 거품이 생기는 동작)은 해당 어절보다 0.4초 먼저 시작해 어절 안에 완성한다.** 효과음은 완성 시각에 맞춘다. 아래 괄호 안 초는 예상치다.

V4 강조 자막(emph)은 구간 자막의 해당 어절을 키우는 방식이라 별도 글자 요소가 아니다(동시 글자 3개 상한에 더하지 않는다).

굼구미: 흰 몸, 잉크 `#252E3A`, 코랄 볼 `#FC876E`. 머리카락·옷·코·귀·손가락 묘사 없음. 해변 장면(비트1·2·7·8)에서는 모래 위 중심 x 820, 키 250, 발은 모래선 위, 몸 좌우 약 757-883. 도식 장면(비트3~6)은 패널 아래 왼쪽(중심 x 173, 발 y 1235, 키 173, 위 1062)에서 눈과 몸 방향으로 가리킨다. 파도·바닥·화살표에 손대지 않는 관찰자이고 모든 표시와 20px 이상 떨어지며 x 85% 안쪽, y 1250 위다.

## 과장 명시 (비트3~6)

바닥 비탈의 기울기(실제 해안은 훨씬 완만), 수심 대비 파도 높이, 마루가 앞으로 기우는 정도, 화살표 길이, 끌림 막대 크기는 개념을 보이려는 크기·단순화이며 실제 척도가 아니다. 그래서 비트3 시작 11.46부터 비트6 끝 28.83까지 S1 "과장해 그림"을 계속 띄운다. 비트7 해변 복귀에서는 실제 해변 비율이다.

## 공간 설계

- **해변 장면(비트1·2·7·8)**: 하늘 `#CFE3F0`~`#F3E9DC`, 바닷물이 왼쪽, 모래 비탈이 오른쪽. 파도는 왼쪽 먼바다에서 오른쪽 해안으로 온다. 굼구미는 오른쪽 모래 위, 깃대는 굼구미 왼쪽(깃발 끝까지 37px).
- **도식 장면(비트3~6)**: 해변이 `#14233A`로 어두워지고 부서지는 파도 자리(해변 (570,860))에서 패널이 자라 나온다. 굼구미는 패널 아래 왼쪽에서 가리킨다.
- 도식은 비트7에서 같은 자리로 줄어들며 해변으로 돌아간다.

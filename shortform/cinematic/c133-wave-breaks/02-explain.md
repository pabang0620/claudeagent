# c133 설명 사슬 - 파도가 해변에서 부서지는 이유

## 질문
바닷가에서 파도는 왜 하얗게 부서질까.

## 의외성
"지금 바람이 불어서 파도가 부서진다"고 생각하기 쉽다. 바람이 없는 날에도 먼 곳에서 온 파도는 해변에서 부서진다. 부서지는 건 바람 때문이 아니라 바다가 얕아지기 때문이다. 이 통념을 s3에서 말로 호명해 반박하고, s4에서 진짜 원인(얕은 바다) 쪽으로 시선을 옮긴다.

## 인과 고리 (4개)

| 고리 | 내레이션 (ko) | 봐야 하는 그림 | 피해야 할 오해 |
|---|---|---|---|
| 훅 s1 | 바닷가에서 파도가 밀려와 하얗게 부서져요. | 해변 옆모습. 먼바다의 잔잔한 물결이 밀려와 해안 가까이에서 마루가 말려 부서지고 거품이 모래를 적신다. 굼구미가 모래 위에서 바라봄. 설명 없음 | - |
| 의외성 s2 | 바람이 없어도 먼 곳에서 온 파도는 부서져요. | 같은 해변. 축 처진 깃발(바람 없음), 왼쪽 먼바다에서 파도가 이어져 오고 다시 부서짐 | 바람이 지금 불어서 부서진다는 통념. 바람 줄기를 그리지 않는다 |
| 반박 s3 | 바람 때문이 아니에요. | 깃발이 축 처진 채 hold, 굼구미가 고개를 가로저음 | 바람 줄기 그림으로 통념을 되살리지 않는다 |
| 1 s4 | 파도가 얕은 바다에 오면 아래쪽이 바닥에 끌려요. | 단면 도식. 바닥이 오른쪽으로 올라오는 비탈, 얕은 구간 보라 괄호, 바닥 위 주황 끌림 막대 3개가 파도 진행 반대(왼쪽)로 짧게 당겨짐 | 바닥이 파도를 밀어준다는 인상, 바닥에 부딪혀 멈춘다는 인상. 파도는 계속 간다 |
| 2 s5 | 그래서 파도 아래쪽이 느려지고 위쪽은 앞서가요. | 파도 마루 점과 아래쪽 점에서 나온 노란 화살표 둘(꼬리가 파도 윤곽에 붙음). 아래 화살표만 150에서 50으로 줄어듦 | 물속에서 물이 위는 빠르게 아래는 느리게 흘러간다는 인상, 파도 전체가 정지한다는 인상 |
| 3 s6 | 그러면 파도 꼭대기가 앞으로 기울어요. | 대칭 파도가 앞쪽 가파른 비대칭으로 변하고 원래 윤곽이 흰 점선 유령으로 남음 | 높이만 커진다는 인상 |
| 4 s7 | 기운 꼭대기는 버티지 못하고 앞으로 넘어져요. | 마루가 말려 넘어지고 흰 거품 | 위에서 누가 쳐서 부서진다는 인상 |
| 답 s8 | 그래서 파도는 바다가 얕아지는 곳에서 부서져요. | 단면이 해변 파도로 줄어들며 복귀. 보라 괄호가 바다가 얕아지는 곳에 걸리고 그 자리에서 파도가 부서짐 | - |

## 답 1문장
먼 곳에서 온 파도도 바다가 얕아지는 곳에서는 아래쪽이 바닥에 끌려 느려지고, 위쪽이 앞서가 꼭대기가 기울다 넘어져 부서진다.

## "그래서?" 점검
1. 바람이 없어도 부서진다면? -> 바람 때문이 아니다(s3).
2. 그럼 뭐 때문이지? -> 바다가 얕아지는 곳에 오면 아래쪽이 바닥에 끌린다(고리 1).
3. 끌리면 어떻게 되나? -> 아래는 느려지고 위는 앞서간다(고리 2).
4. 위가 앞서가면? -> 꼭대기가 앞으로 기운다(고리 3).
5. 기울면? -> 버티지 못하고 넘어져 부서진다(고리 4).
6. 결론 -> 바다가 얕아지는 곳에서 부서진다. 비약 없음.

## 색 연결 규칙
바닷물 파랑, 바닥 모래색, 속도 화살표 노랑, 끌림 막대 주황, 얕은 구간 보라, 거품과 유령 윤곽 흰색.

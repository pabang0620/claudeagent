# c86 설명 사슬 - 더운 날에도 우박이 내리는 이유

## 질문

더운 여름날에 얼음 덩어리(우박)가 왜 내릴까.

## 의외성

우박은 내려오다 언 빗방울이라고 믿기 쉽다. 실제로는 구름 속에서 얼음이 자란 것이다. (s2가 "우박은 내려오다 언 빗방울이 아니에요"라고 말로 뒤집고, 말풍선의 `우박 = 언 빗방울`에 X가 그 뜻을 맡는다. 이어서 s3이 진짜 장소인 구름 위쪽으로 시선을 옮긴다.)

## "그래서?" 점검

s1 더운 날에도 우박 -> 내려오다 언 빗방울인가? s2 아니다 -> 그럼 어디서 얼음이? s3 높은 구름 위쪽은 영하라 얼음이 생긴다 -> 왜 안 떨어지나? s4 센 바람이 받친다 -> 받쳐진 동안 뭐가? s5 영하인데 아직 안 언 물방울이(액체로 흔들리는 그림) 닿아 언다 -> 그래서? s6 층이 쌓여 커진다 -> 끝은? s7 무거워지면 바람이 못 받쳐 떨어진다 -> s8 그래서 구름 속에서 자란 얼음이 우박으로 내려온다. 비약 없음.

연결(이전 결과어가 다음 주어):
- s2 -> s3: 카드가 구름에서 자라 나오고 "높이 솟은 구름 위쪽"을 말함. "더워도"가 훅의 더위를 이음.
- s3 얼음 -> s4: "얼음이 생겨요" 뒤 "얼음 알갱이를".
- s4 알갱이 -> s5: "알갱이에 닿아".
- s5 얼어요 -> s6: "얼어붙은 층이".
- s6 알갱이가 커져요 -> s7: "무거워진 알갱이는".
- s7 떨어져요 -> s8: 카드가 닫혀 "구름 속에서"로 실제 장면 복귀, 땅 위 우박으로 연결.

용어 풀이: 새 전문용어 없음("상승기류" 대신 "아래서 위로 부는 센 바람", "과냉각 물방울" 대신 "영하에도 아직 안 언 물방울").

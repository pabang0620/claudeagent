# c130 화면 글자 (내레이션 자막 제외 - 자동 표시)

한 화면 동시 최대: 내레이션 자막 1 + 라벨/표지 2 (퇴장·팝인 겹침 포함). 제목은 브랜드 제목카드가 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다. S1이 도식 구간 내내 떠 있으므로 그 구간에서 라벨은 동시에 1개뿐이다.

시각은 `narration-ko.json` 기준 예상 절대 초(구간 길이 = 글자수x0.11+0.72, 글자 수는 공백·문장부호 포함, 어절 시작 = 구간 시작 + 앞 글자 수x0.11)다. 실제 값은 TTS 후 확정하고 애니메이터는 앵커를 쓴다. 소리 도착과 효과음은 절대 초가 아니라 어절 앵커에 묶는다(04 참조).

## 동시 표시 점검 (자막은 해당 구간 t0~t1 동안 표시)
- 0.00-1.00: 없음. 1.00-1.48: s1 = 1. 1.48-2.80: L1 + s1 = 2. 2.80-2.98: L1 + L2 + s1 = 3. 2.98-4.30: L2 + s1 = 2. 4.30-4.80: s1 = 1. 4.80-5.60: 없음.
- 5.60-8.30: s2 = 1. 8.30-8.70: 없음.
- 8.70-9.10: S1 + L3 = 2. 9.10-10.20: S1 + L3 + s3 = 3. 10.20-10.35: S1 + s3 = 2. 10.35-11.85: S1 + L4 + s3 = 3. 11.85-13.01: S1 + s3 = 2. 13.01-13.94: S1 = 1.
- 13.94-14.01: S1 + L5 = 2. 14.01-15.44: S1 + L5 + s4 = 3. 15.44-17.26: S1 + s4 = 2. 17.26-17.86: S1 = 1. 17.86-18.34: S1 + s5 = 2.
- 18.34-19.84: S1 + L6 + s5 = 3. 19.84-21.33: S1 + s5 = 2. 21.33-22.13: S1 = 1.
- 22.13-23.16: S1 + s6 = 2. 23.16-25.60: S1 + L7 + s6 = 3. 25.60-26.20: S1 + L7 = 2. 26.20-26.60: S1 = 1.
- 26.60-29.96: S1 + s7 = 2. 29.96-31.36: 없음.
- V4 강조 자막(emph)은 구간 자막의 해당 어절을 키우고 색을 바꾸는 방식이며 별도 글자 요소가 아니다. 위 동시 개수에 더하지 않는다.
- 어느 시점도 3개를 넘지 않는다.

## 라벨 규칙 점검
- 라벨 6자 이내(공백 포함): 번개 2, 천둥 2, 번개 길 3, 달궈짐 3, 빛 1, 소리 물결 5, 시간 차 3. 표지 10자 이내: 과장해 그림 6.
- 노출 1.5초 이상: L1 1.50, L2 1.50, S1 21.26, L3 1.50, L4 1.50, L5 1.50, L6 1.50, L7 3.04. 전부 충족.
- 라벨은 대상이 처음 그려진 뒤 1초 안에 팝인: L1 번개 1.48 동시, L2 소리 물결 창 밖 2.29에서 0.51초, L3 번개 길 8.70 동시, L4 공기 덩어리 9.69에서 0.66초, L5 빛줄기 13.61에서 0.33초, L6 소리 물결 17.46에서 0.88초, L7 위줄 막대 22.88에서 0.28초.
- **그림과 라벨은 가리키는 어절보다 0.4초 먼저**: L1 s1@"번쩍하면"(번개 그림도 같은 시각), L2 s1@"쾅", L3 s3@"번개가"(번개 길 점선도 같은 시각), L4 s3@"달궈져", L5 s4@"빛은", L6 s5@"소리는", L7 s6@"거리가". 모두 -0.40. 비트 끝에 몰아서 띄운 라벨 없음.
- 한 윤곽에 이름 두 개 금지: "번개"(창 속 번개 그림)와 "번개 길"(확대한 번개 길)은 다른 장면의 같은 대상이며 L3은 확대 때만 쓴다. 청록 호는 훅에서 L2 "천둥", 도식에서 L6 "소리 물결"로 불리며 같은 색이다. "시간 차"는 흰 막대 전용이다.
- 레이아웃 간격: 칩끼리 20px 이상(L1과 L2는 가로 42px, L3과 L4는 같은 시각에 함께 뜨지 않음). 칩과 패널 위 테두리(y 441): L3·L4 칩 y 560으로 119px, L7 칩 y 480으로 39px. L7 칩 x 600-802는 위줄 구름 x 340-580과 20px, 위줄 번개 오른쪽 끝 505와 95px. 칩과 자막 띠(y 1250 이하) 사이 모두 250px 이상. 굼구미(도식 장면 x 16%, 발 y 1235, 키 173px, 위 1062)와 칩 사이 400px 이상. 거실 복귀의 S1(y 340-410)과 창 윗틀(y 430)은 20px.

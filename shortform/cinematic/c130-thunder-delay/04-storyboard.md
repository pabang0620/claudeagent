# 굼구미 시네마틱 c130 - 번개가 친 뒤 천둥이 늦게 들리는 이유 (9:16)

Canvas 1080x1920 (9:16), 30fps 출력, 그림은 on twos(2프레임마다 갱신), 휙 지나가는 순간(패널 자라남, 당겨 빼기, 되감기, 번쩍, 폴짝)만 on ones. 본편만 다룬다 - 브랜드 인트로·제목카드·아웃트로는 엔진이 붙인다. 제목카드가 주제를 보여주므로 본편에서 주제 자막을 다시 띄우지 않는다.

예상 본편 길이 **약 31.36초**(구간 길이 = 글자수x0.11+0.72, gap 포함, 비트8 1.40초). 실제 TTS는 이보다 짧거나 길 수 있고 앵커 기준으로 만든다. 내레이션 7구간, 비트 8개. 설명 사슬은 훅 s1 + 의외성 s2 + 인과 고리 3(s3, s4+s5, s6) + 답 s7.

**소리 도착·효과음은 절대 초가 아니라 어절 앵커에 묶는다.** 애니메이터는 도착 앵커(`s1@"쾅"`, `s3@"쾅"`, `s5@"와요"`, `s7@"늦게"`)에서 거꾸로 소리 물결 시작 시각 = 도착 - 거리/200을 계산한다. 아래 괄호 안 초 값은 예상치다.

V4 강조 자막(emph)은 구간 자막의 해당 어절을 키우는 방식이라 별도 글자 요소가 아니다(동시 글자 3개 상한에 더하지 않는다).

굼구미: 흰 몸, 잉크 `#252E3A`, 코랄 볼 `#FC876E`. 머리카락·옷·코·귀·손가락 묘사 없음. 도식 장면(비트3~6)의 굼구미는 번개·빛·소리 물결·집에 손대지 않는 관찰자·안내자이며 패널 아래 왼쪽(중심 x 173, 발 y 1235, 키 173, 위 1062)에서 눈과 몸 방향으로 가리킨다(패널 아래 1037과 25px). 모든 표시와 20px 이상 떨어지고 x 85% 안쪽, y 1250 위다.

## 과장 명시 (비트3~7)

번개 길 둘레 공기 덩어리의 부풂, 번개와 집 사이 거리, 소리 물결 속도(초당 200px), 빛이 닿는 속도(한 프레임), 시간 막대 길이(초당 130px), 번개가 길 전체에서 한 프레임에 켜지는 모양(실제로는 위에서 아래로 뻗음)은 모두 개념을 보이려는 크기·단순화이며 실제 척도가 아니다. 그래서 8.70부터 비트7이 끝나는 29.96까지 S1 "과장해 그림"을 계속 띄운다(비트3~7 내내, 거실 복귀 포함). 소리 물결 속도는 비트1, 비트5, 비트6 두 줄, 비트7 모두 초당 200px로 같다.

## 같은 번개 표시 (번개가 두 번 쳤다는 오해 방지)

번개는 비트3에서 한 번 친다. 비트4 시작의 당겨 빼기는 **되감기**다: ◀◀ 기호(폭 70, 패널 오른쪽 위 x 800-870, y 470-510)가 13.01-13.61에 나타나고 화면이 35% 어두워지며 번개가 꺼지고 오른쪽으로 작아져 이동한다. 이동한 번개 자리에 흰 점선 유령 윤곽이 비트6 끝까지 남는다. 비트5 시작(17.16-17.46)과 비트6 시작(21.43-21.73)에도 같은 0.3초 되감기(◀◀, 어두워짐, 역재생 휙)를 쓴 뒤 같은 번개가 다시 켜진다.

## 자체 점검

- 설명 사슬이 모두 E 비트로 있고 순서가 같다: 훅(비트1, s1) -> 의외성 s2(비트2) -> 고리1 같은 순간 달궈져 부풀며 소리 남(비트3, s3) -> 고리2 빛은 곧바로, 소리는 느림(비트4~5, s4+s5) -> 고리3 멀면 소리가 갈 거리가 길어짐(비트6, s6) -> 답(비트7, s7). 인과 고리 3개, 본편 약 31.36초.
- 훅(비트1)은 설명·비교·도식 없이 거실의 번쩍, 한참, 쾅이며 0.00-5.20(5.2초, 2.5초 이상).
- **시작 앵커는 "그 비트 내레이션 구간 시작(sN.t0) - 0.4초"다.** 비트2·3·7은 s2.t0-0.40, s3.t0-0.40, s7.t0-0.40이다. 비트4·5·6은 시작에 0.3~0.6초 되감기 A가 있고 핵심 그림(번개 켜짐, 소리 물결 시작)은 s4.t0-0.40(13.61), s5.t0-0.40(17.46), s6.t0-0.40(21.73)이다. 새 그림은 모두 해당 어절보다 0.4초 먼저다(s1 번쩍하면, s3 번개가·공기가·달궈져·쾅, s4 빛은, s5 소리는, s6 거리가, s7 번개가). 라벨 L1~L7과 그림이 같은 시각 또는 그림이 먼저다.
- 완성 앵커와 hold: 비트1 s1@"쾅" 약 3.20(hold 2.0), 비트2 7.03(1.67), 비트3 약 11.63(1.38), 비트4 15.00(2.16), 비트5 약 20.28(1.15), 비트6 약 24.46~24.86(1.34), 비트7 약 28.47(1.49 + 비트8). 전부 1초 이상.

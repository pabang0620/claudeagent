# c25 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("뜨거운 걸 만지면 손이 먼저 떨어지는 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

## 동시 표시 점검
- 11.00-12.49: S1 + s4 자막 = 2개.
- 12.49-12.99: 없음(간격, S1 페이드 아웃 후 s5 시작 전).
- 12.99-13.20: s5 자막 단독 = 1개(L1 등장 전).
- 13.20-15.38: L1 + s5 자막 = 2개.
- 15.38-15.78: L1 단독 = 1개(간격, s6 시작 전).

- 18.43-18.83: L2 단독 = 1개(간격, s7 시작 전).

- 21.62-21.80: s8 자막 단독 = 1개(L4 등장 전).

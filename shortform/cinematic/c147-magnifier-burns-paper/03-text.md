# c147 화면 글자 (내레이션 자막 제외 - 자동 표시)

한 화면 동시 최대: 내레이션 자막 1 + 표지/라벨 2 (퇴장·팝인 겹침 포함). 제목은 제목카드가 보여주므로 본편에서 다시 띄우지 않는다. 안전 표지와 과장 표지는 **표지판 S2 한 장**(줄만 늘고 줆)으로 합쳐 한 개로 센다. 그래서 어느 시점에도 자막 + S2 + 라벨 1개 이하다.

시각은 `narration-ko.json` 기준 예상 절대 초(구간 길이 = 글자수x0.11+0.72, 어절 시작 = 구간 시작 + 앞 글자 수x0.11)다. 애니메이터는 앵커를 쓴다.

글자 수(공백·부호 포함): s1 26, s2 23, s3 23, s4 27, s5 29, s6 25, s7 29, s8 29.
내레이션 구간(예상): s1 1.00-4.58 / s2 5.28-8.53 / s3 9.23-12.48 / s4 13.28-16.97 / s5 17.77-21.68 / s6 22.48-25.95 / s7 26.75-30.66 / s8 31.66-35.57. 비트9 35.57-36.97.

라벨 칩 폭은 공백 포함 글자수x54+40px, 높이 70px. 도식 패널 x 65-900, y 441-1037.

## 라벨 규칙 점검
- 라벨 6자 이내(공백 포함): 돋보기 3, 꺾임 2, 직진 2, 느려짐 3, 기울기 3, 한 점 3, 열기 2. 표지판 줄은 각 10자 이내. 칩 폭: 2자 148, 3자 202, 10자 580.
- 노출 1.5초 이상: L1~L7 모두 1.50(L6은 두 번 각각 1.50).
- 대상이 처음 그려진 뒤 1초 안에 팝인: L2 0.62, L6 0.80(점선 10.15 기준), L3 0.47, L4 동시, L5 동시, L6(비트7) 동시, L7 0.37. 흰 점선은 첫 등장 0.80초 뒤 "직진"으로 이름이 붙는다(비트4 점선은 같은 뜻을 이미 안다).
- 라벨은 가리키는 어절보다 0.4초 이상 먼저(L2는 "길을" 10.55보다 1.10 먼저, L3 "느려져" 15.37-0.40, L4 "기울어" 19.53-0.40, L5 "점에" 24.46-0.40, L7 "뜨거워져요." 29.28-0.40). 비트 끝에 몰아 띄운 라벨 없음.
- 한 윤곽에 이름 두 개 없음: 꺾인 빛 L2, 직진 점선 L6, 렌즈 L1, 빨간 점 L7, 모이는 자리 L5.
- 레이아웃: 장면 L1 칩은 빛줄기 오른쪽 670과 30, 렌즈 위 40. L2·L6 칩 x 710-858은 오른쪽 점선 x 670과 40, 종이 위 1110과 40. 패널 L3 칩 x 150-352는 쐐기 왼쪽 420과 68, 패널 왼쪽 65와 85. L4 칩 x 85-287은 가장 왼쪽 빛줄기 x 380과 93, 패널 왼쪽과 20. L5 칩 x 640-842는 패널 오른쪽 900과 58, y 850-920은 종이 위 940과 20, 가장 바깥 꺾인 빛(y 850에서 x 약 594)과 46. L6(비트7) 칩 x 90-238은 점선 x 380과 142. L7 칩 x 730-878은 오른쪽 점선 x 700과 30, 패널 오른쪽 900과 22, 종이 위 940과 20. 칩 모두 자막 띠(y 1250 이하)와 멀다. 지시선이 점선·빛줄기를 가로지르는 것은 허용(칩·표시 상자끼리만 20px 규칙).

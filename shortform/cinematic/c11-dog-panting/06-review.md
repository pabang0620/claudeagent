## 시청 시뮬레이션 요약 (비트당 한 줄)

1. 제목카드: "개가 더울 때 혀 내밀고 헐떡이는 이유" - 주제 인지.
2. 비트1(s1, 0-5.02s): 마당에서 강아지가 헐떡임, 굼구미는 부채질. 설명 없음. -> "더운 날 강아지가 헥헥거린다"만 앎.
3. 비트2(s2, 5.02-8.92s): 굼구미가 털을 만져봄, 물기 없이 뽀송함. -> "헐떡이는데 땀은 안 난다"는 의외성 인지.
4. 비트3(A, 8.92-9.62s): 발바닥 속으로 확대 전환, 스케일 표지. -> 이제 발바닥 안을 볼 거라는 예고.
5. 비트4(s3, 9.62-12.53s): 발바닥 패드 안 파란 땀샘 아이콘이 "발바닥에만" 어절에 완성, 라벨 "땀샘". -> "열 식히는 땀샘이 발바닥에만 있다" 앎.
6. 비트5(s4, 12.53-15.97s): 발바닥(있음) vs 몸통 실루엣(없음, X표시) 나란히 대비. -> "그래서 온몸으로는 땀 못 낸다" 앎.
7. 비트6(s5, 15.97-19.80s): 물웅덩이 증발 + 열 물결선 빠짐, 라벨 "증발냉각". -> "물 마르면 열도 같이 빠진다"는 일반 원리 앎.
8. 비트7(s6, 19.80-23.50s): 혀·입 안에 침 층 형성, 라벨 "침". -> "혀·입을 침으로 적셔놓는다" 앎.
9. 비트8(s7, 23.50-27.10s): 벌어진 입 위 공기 화살표 왕복, 침 층이 점점 얇아짐, 라벨 "헐떡임". -> "헐떡여서 그 침을 빨리 말린다" 앎.
10. 비트9(s8, 27.10-30.74s): 마당으로 복귀, 여전히 뽀송한 털. -> 방금 배운 원리가 실제 강아지에 적용됨을 재확인.
11. 비트10(s9, 30.74-35.32s): 땀샘·침 라벨 재등장 + 초록 글로우로 정리. -> 답 문장 확정.
12. 비트11(A, 35.32-36.42s): 굼구미가 장난스럽게 헐떡임 흉내, 반전 마무리.

**이해 판정**: 시뮬레이션 끝에서 시청자가 02-explain.md의 답 문장("땀샘이 발바닥에만 있어 온몸으로 땀을 못 내서, 대신 혀·입을 침으로 적셔놓고 헐떡여 그 침을 빨리 증발시켜 열을 날린다")을 스스로 말할 수 있음. 끊긴 고리 없음.

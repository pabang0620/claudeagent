# c11 화면 글자 (내레이션 자막 제외 - 자동 표시되므로 여기 기재하지 않음)

한 화면 동시 최대: 내레이션 자막 1 + 라벨 2. 제목("개가 더울 때 혀 내밀고 헐떡이는 이유")은 브랜드 제목카드에서 이미 보여주므로 본편 안에서 주제 자막을 다시 띄우지 않는다(0-3절).

시각은 `narration-ko.json` 기준 예상 절대 초로 적었다(검토용). 실제 값은 TTS 렌더 후 `timeline-ko.js`의 단어 타임스탬프로 재확인한다.

## 동시 표시 점검
- 0.00-1.20: 없음(훅 정지 프레임, 내레이션 시작 전).
- 1.20-5.02: s1 자막 단독 = 1개.
- 5.02-5.62: 없음(간격).
- 5.62-8.92: s2 자막 단독 = 1개.
- 8.92-9.62: S1 단독 = 1개(진입 비트, 내레이션 없음).
- 9.62-9.92: S1(페이드아웃 중) + L1(팝인) + s3 자막 = 3개(상한과 정확히 일치, 초과 아님).
- 9.92-12.53: L1 + s3 자막 = 2개(S1 소멸 후).
- 12.53-15.97: L1 + s4 자막 = 2개(발바닥 vs 몸통 비교 구간).
- 15.97-16.37: 없음(간격, L1 소멸).
- 16.37-19.80: L2 + s5 자막 = 2개.
- 19.80-20.20: 없음(간격, L2 소멸).
- 20.20-23.50: L3 + s6 자막 = 2개.
- 23.50-23.80: 없음(간격, L3 잠시 소멸).
- 23.80-27.10: L4 + s7 자막 = 2개.
- 27.10-27.70: 없음(간격).
- 27.70-30.74: s8 자막 단독 = 1개(라벨 없음, 복귀 장면).
- 30.74-31.24: 없음(간격).
- 31.24-35.32: L1(재등장, 작게) + L3(재등장, 작게) + s9 자막 = 3개(상한과 정확히 일치, 초과 아님).
- 35.32-36.42: 없음(반전 비트, 자막·라벨 없음).
- 어느 시점도 상한(3개)을 넘지 않는다.

## 숫자(N)
화면 숫자 없음. `01-fact.md`에서 버린 사실(분당 헐떡임 횟수)은 대본 규칙(숫자는 화면이 읽지 않는다)에 따라 이번 편은 숫자 라벨 자체를 쓰지 않는다. "빠르게"라는 정성적 표현과 화살표 왕복 속도로만 보여준다.

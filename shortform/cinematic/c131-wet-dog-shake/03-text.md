한 화면 동시 최대: 내레이션 자막 1 + 라벨/표지 2 (퇴장·팝인 겹침 포함). 제목은 브랜드 제목카드가 보여주므로 본편에서 주제 자막을 다시 띄우지 않는다.

시각은 narration-ko.json 기준 예상 절대 초(구간 길이 = 글자수x0.11+0.72, 글자 수는 공백·문장부호 포함, 어절 시작 = 구간 시작 + 앞 글자 수x0.11)다. 실제 값은 TTS 후 확정하고 애니메이터는 앵커를 쓴다.

글자 수: s1 27, s2 17, s3 21, s4 27, s5 20, s6 23, s7 27 (공백·부호 포함 직접 계산).

## 동시 표시 점검 (자막은 해당 구간 t0~t1 동안 표시)
- 0.00-1.00: 없음. 1.00-2.14: s1 = 1. 2.14-3.64: L1 + s1 = 2. 3.64-4.69: s1 = 1. 4.69-5.49: 없음.
- 5.49-8.08: s2 = 1. 8.08-8.48: 없음.
- 8.48-8.88: S1 = 1. 8.88-9.36: S1 + s3 = 2. 9.36-10.86: S1 + L2 + s3 = 3. 10.86-11.91: S1 + s3 = 2. 11.91-12.71: S1 = 1.
- 12.71-13.85: S1 + s4 = 2. 13.85-15.35: S1 + L3 + s4 = 3. 15.35-16.40: S1 + s4 = 2. 16.40-17.20: S1 = 1.
- 17.20-17.90: S1 + s5 = 2. 17.90-19.40: S1 + L4 + s5 = 3. 19.40-20.12: S1 + s5 = 2. 20.12-20.72: S1 = 1.
- 20.72-23.97: S1 + s6 = 2. 23.97-24.37: S1 = 1. S1 퇴장 24.37.
- 24.37-24.77: 없음. 24.77-28.46: s7 = 1. 28.46-29.86: 없음.
- V4 강조 자막(emph)은 구간 자막의 해당 어절을 키우고 색을 바꾸는 방식이며 별도 글자 요소가 아니다. 위 동시 개수에 더하지 않는다.
- 어느 시점도 3개를 넘지 않는다.

## 라벨 규칙 점검
- 라벨 6자 이내(공백 포함): 물방울 3, 붙잡는 힘 5, 털 움직임 5, 가려는 쪽 5. 표지 10자 이내: "털 확대·단순화" 8(털, 공백, 확, 대, ·, 단, 순, 화).
- 노출 1.5초 이상: L1 1.50, L2 1.50, L3 1.50, L4 1.50, S1 15.89. 전부 충족.
- 라벨은 대상이 처음 그려진 뒤 1초 안에 팝인: L1 0.19초, L2 동시, L3 0.44초, L4 0.55초.
- 그림과 라벨은 가리키는 어절보다 0.4초 먼저: L1 s1@"물이", L2 s3@"달라붙어", L3 s4@"털도", L4 s5@"그대로" 모두 -0.40. 핵심 어절은 라벨 노출 안에 들어온다(물이 2.54, 달라붙어 9.76, 털도 14.25와 휙 14.91, 그대로 18.30과 가려 18.74).
- 한 윤곽에 이름 두 개 금지: 파란 물방울은 훅에서 L1 "물방울"로 한 번만 이름 붙이고 도식에서는 같은 색 같은 모양이라 다시 붙이지 않는다. 흰 화살표는 "털 움직임", 주황 화살표는 "가려는 쪽", 노란 끈은 "붙잡는 힘" 전용.
- 레이아웃 간격: L2 칩 y 540-610과 S1 y 340-410은 130px, 칩과 패널 위 테두리(441) 84px 이상, 칩과 패널 왼쪽 테두리(65) 25px. L3 칩 y 525-595, L4 칩 y 600-670은 같은 시각에 뜨지 않음. 칩 오른쪽 400과 노출 중 털·화살표 왼쪽 끝은 L3 61px 이상, L4 26px 이상. 피부 조각 y 450-500은 L3 칩 위 25px. L1 칩은 개 윗끝(y 890)과 240px. 칩과 자막 띠(y 1250 이하) 사이 580px 이상. 굼구미(도식 장면 x 16%, 발 y 1235, 키 173, 위 1062)와 칩 사이 400px 이상.

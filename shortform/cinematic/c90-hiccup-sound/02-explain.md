# c90 설명 사슬 - 딸꾹 소리가 나는 이유

## 질문

딸꾹질을 할 때 "딸꾹" 소리는 왜 날까.

## 의외성

"딸꾹"은 뭔가 내쉬는 소리라고 믿기 쉽다. 실제로는 공기가 들어오는 중이고, 들어오던 공기가 막히는 소리다. (s2가 "숨을 내쉬는 소리가 아니에요"라고 말로 뒤집고, 풍선의 입 -> 내쉬는 화살표 위 X가 "그것이 아니다"를 뜻한다. 이어서 s3-s6이 진짜 원인을 채운다.)

## "그래서?" 점검

s1 몸이 들썩인다 -> 소리는 내쉬는 소리? s2 아니다 -> 그럼 무슨 소리? s3 가로막이 당겨진다 -> 그래서? s4 폐가 늘고 공기가 들어온다 -> 그런데 왜 소리? s5 그 순간 성문이 닫힌다 -> 닫히면? s6 들어오던 공기가 막혀 소리가 난다. 비약 없음.

연결(이전 결과어가 다음 주어):
- s2 -> s3: 카드가 굼구미 몸에서 자라고 표지 "단순하게 그린 몸속"으로 시점 전환.
- s3 "당겨져요" -> s4 "당겨진 만큼": 같은 단어를 받음.
- s4 "공기가 빨려 들어와요" -> s5 "그 순간": 들어오는 중에 닫힘.
- s5 "닫혀요" -> s6 "닫힌 성문": 같은 단어를 받음. "들어오던 공기"는 s4의 공기를 받음.
- s6 끝 -> 반전: 카드가 닫혀 굼구미 몸으로 복귀, 같은 구조가 몸속에 겹쳐 보임.

용어 풀이: 가로막(s3 "숨 근육"), 성문(s5 "목 안의 문")만 풀이. 폐·공기는 일상어. 2개 이내.

## 그림 일관 규칙 (04와 동일)

- 대상: 굼구미 1, 소파 1, 풍선 1(입 아이콘 1, 내쉬는 화살표 1, X 1), 카드 1 안에 숨길 1과 폐 1(숨길은 폐 윗면에 이어진 한 윤곽, 라벨은 폐에만), 가로막 1(+처음 위치 유령 윤곽 1), 폐 처음 크기 유령 윤곽 1, 공기 공 3(A1, A2는 폐 안, A3는 성문 위), 성문 막대 2, 소리 호 2(카드) + 반전의 소리 호 2, 닫힘 순간 번쩍 선 6, 반전의 유령 가로막 1과 유령 성문 막대 2.
- 색: 공기 하늘색, 가로막(근육) 붉은색, 폐 분홍, 성문 보라, 소리 노랑, 숨길 벽 회색.
- 화살표는 풍선 안 하나(내쉬는 방향), X는 "아니다" 한 가지.

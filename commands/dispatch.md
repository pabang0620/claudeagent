# Dispatch

dispatcher 스킬을 실행해 요청을 분류한다. 라우팅 SSOT는 `rules/agents.md`(STEP 0-1 수단 선택, STEP 1 담당 표)이고 이 커맨드는 그 표를 적용한 결과를 보여줄 뿐이다.

출력(10줄 이내):
- 요청 요약과 유형
- 수단: 메인 직접 / fork / Explore / 전문 에이전트 이름 / 스킬 이름 (근거 한 줄)
- 스폰이 필요하면 프롬프트에 넣을 경로·완료 기준·보고 상한

에이전트 체인은 여러 파일에 걸친 신규 기능·큰 리팩토링에만 제안한다. 리뷰 단계는 넣지 않는다.

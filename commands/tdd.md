# TDD

tdd-guide 에이전트를 호출한다. tdd-guide는 실패 테스트를 쓰고 "올바른 이유로 실패"하는지 확인한 뒤 보고하고 멈춘다(구현은 하지 않는다).

흐름:
1. RED: tdd-guide가 테스트 파일·테스트명·실패 출력 첫 줄을 보고한다.
2. GREEN: 메인이 직접 최소 구현을 하거나, 여러 파일이면 fork / react-specialist / express-engineer에 위임한다.
3. 통과 확인: 메인이 테스트를 실행한다. 필요하면 tdd-guide를 재스폰해 통과·리팩토링을 확인한다.
4. 커버리지: 측정했을 때만 수치를 적는다. 80%는 "테스트 맡길게" 인수 게이트에서만.

테스트 종류(유닛·통합·E2E)와 범위는 Claude 재량이다(`rules/testing.md`). E2E 스위트는 `/e2e`.

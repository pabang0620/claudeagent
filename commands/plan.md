# Plan

planner 에이전트를 호출해 계획 문서를 받는다. 코드는 쓰지 않는다.

계획에 들어갈 것: 요구사항 재정리, 단계별 분해(단계마다 파일·완료 조건), 의존성, 위험. 시간·기간 견적과 리뷰 단계는 넣지 않는다.

계획을 받으면 메인이 사용자에게 보여주고 확인을 기다린다. "진행해"류 확인 후에만 구현을 시작한다. 수정 요청이 오면 planner를 재호출하지 말고 메인이 계획을 고친다.

구현 수단은 `rules/agents.md` STEP 0-1(메인 직접 / fork / 전문 에이전트)로 정한다.

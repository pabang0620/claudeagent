# Build and Fix

build-error-resolver 에이전트에 위임한다. 스폰 프롬프트에 빌드 명령(package.json scripts 실측)과 대상 디렉토리 절대경로를 적는다.

에이전트는:
1. 빌드를 실행해 에러를 파일별로 묶는다.
2. 한 번에 하나씩 최소 diff로 고치고 재빌드한다. 같은 에러 코드·같은 패턴이 여러 개면 일괄 수정할 수 있다.
3. 수정으로 새 에러가 생기거나 같은 에러가 3회 지속되면 멈추고 보고한다.
4. 보고(15줄 이내): 고친 에러 / 남은 에러 / 새로 생긴 에러.

리팩토링·재설계는 하지 않는다. 리뷰 단계를 붙이지 않는다.

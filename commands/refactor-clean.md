# Refactor Clean

refactor-cleaner 에이전트에 위임한다. 스폰 프롬프트에 대상 프로젝트 절대경로를 적는다.

1. knip·depcheck(TS면 ts-prune)로 후보를 모은다.
2. 1단계: 아무것도 지우지 않고 후보를 등급별 표(안전/주의/위험)로 보고하고 멈춘다.
3. 메인이 사용자 승인 목록을 받아 2단계를 재스폰한다: 승인 목록만 제거하고 종류별로 빌드·테스트를 돌리며, 실패하면 그 변경만 되돌린다.
4. 보고: 제거한 항목 / 되돌린 항목 / 남은 후보.

승인 목록에 없는 항목은 삭제하지 않는다. `git stash`·`git reset`·`rm -rf`는 쓰지 않는다.

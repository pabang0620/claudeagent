## 인스타 DM 규칙 (공식 API 실측, 재조사 불필요)
- Private Reply는 **댓글 1건당 1회, 댓글 후 7일 이내**. 다른 게시물 댓글엔 또 보낼 수 있다
- 24시간 대화창은 상대가 **답장해야** 열린다. 그래서 **첫 메시지가 자료를 그 자체로 다 담아야 한다**. "답장하시면 보내드릴게요" 식 티저는 실패한다
- 첫 메시지에 링크를 넣으면 전달률이 떨어진다. 비팔로워 DM은 요청함으로 가므로 공개 답글로도 "DM 확인해주세요" 안내
- 새 팔로워에게 먼저 DM 보내기, 콜드 DM, 자동 팔로우·좋아요는 불가(정책 위반)
- 키워드는 한 단어, 띄어쓰기·이모지 없이, 영상 안에서도 말로 한 번 말한다("댓글에 자동화 라고 남겨주세요")

## 리드마그넷 설계 (MAGNET)
- **한 대상, 한 문제, 한 번의 빠른 성과**. "AI 활용 가이드"는 넓어서 아무도 안 받는다. "녹취록 넣으면 회의록 나오는 프롬프트 1개"처럼 좁게
- **유료 상품과 이어져야 한다**: 마그넷이 푸는 문제를 유료 상품도 푼다. 연결이 없으면 팔로워만 늘고 매출은 안 는다
  - 외주(kingkle): 자동화 진단 체크리스트, 업무별 AI 도입 가능 여부 자가진단 → 무료 진단 상담
  - 전자책: 맛보기 28쪽, 1주차 실습 결과물 → 구매
- **바로 쓸 수 있는 결과물**이 PDF 장문보다 낫다(템플릿, 계산기, 자가진단, 실제 프롬프트). 긴 가이드 PDF는 AI 답변이 대체해서 약하다
- **결과로 이름 붙이기**: "가이드"가 아니라 "주간 보고를 15분으로 줄이는 템플릿"
- **양식은 짧게**: 이메일 하나(또는 이메일+이름). 항목 하나마다 5~10%씩 떨어진다
- **후속 연락까지 설계**: 받은 직후 페이지(다음 단계 안내) → 전달 → 3~5회 후속(전달, 빠른 성과, 사례, 부드러운 제안). 초반에 팔지 않는다

## DM·오픈채팅 대화 (WARMS)
- 상대가 먼저 신호를 줬을 때만(댓글, 스토리 답장, 먼저 DM). 콜드 발송 금지
- 빨리, 사람처럼. 짧게, 질문은 하나, 다음 단계는 분명하게
- 가치 먼저, 판매는 나중. 신호마다 메시지를 다르게(같은 문장 대량 발송은 차단 사유)
- 관심이 큰 사람은 사람(원호님)에게 넘긴다. 연락처를 받아 플랫폼 밖(이메일·카톡 채널)으로 옮긴다
- 숫자(전환율, 응답률)는 도구에서 실제로 나온 것만 쓴다

## 수익원 구성 (STACK)
- 한 방 바이럴이 아니라 여러 수익원을 쌓는다. 팔로워 대비 실제 매출 전환은 몇 % 수준이라는 게 원문 자료의 전제다(약속이 아니라 범위 감각)
- 순서: 내 채널(연락처 목록) 확보 → 반복 수익 하나 → 마진 높은 디지털 상품 하나 → 맞는 협찬만 선별 → 플랫폼 수익은 덤
- 원호님 현재 수익원 대응: 외주(kingkle·크몽) = 주력 / 전자책 = 디지털 상품 / 쿠팡 파트너스·애드센스(calc·timer) = 덤 / AI 음악 BGM = 디지털 상품
- 수익원 하나가 안정된 뒤 다음을 붙인다. 동시에 다 벌이지 않는다
- 수익을 약속하는 문구·예측을 만들지 않는다. 협찬·제휴는 광고 표기(쿠팡 파트너스 고지 문구 포함)

## 결과물 형식
1. 대상·문제·빠른 성과 한 줄
2. 마그넷 형식과 이름, 이어지는 유료 상품
3. 연결 경로(채널 → 받는 곳 → 후속 연락), 각 단계 문구 초안
4. 볼 지표(받은 수, 문의 전환, 매출)와 어디서 보는지

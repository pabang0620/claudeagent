# mkt-launch: 출시 순서와 채널

출시는 하루짜리 행사가 아니라 단계를 밟아 쌓는 과정이다. 기능 추가, 개정판, 가격 변경도 다시 알릴 기회다.

## 먼저 확인
- 대상의 현황 문서: 전자책은 메모리 `project_ebook_bijeongongja`(가격 확정, 남은 일은 채널 등록·저자 검수), 레포 `ebook-ai-dev-job/판매전략.md`
- 확정된 가격·채널 판단은 다시 하지 않는다

## 출시 가능 판정 (SLC)
- **단순**: 한 가지 일을 한다
- **아끼게 됨**: 참고 쓰는 게 아니라 고르고 싶은 것이다. 없어지면 아쉬워할 사람이 있나
- **완결**: 그 한 가지가 구멍 없이 끝까지 된다
- 통과했는데 계속 다듬고 있으면 숨어 있는 것이다. 바로 낸다
- 범위를 계속 늘리고 있으면 "기능 하나만 더" 상태다. SLC까지 잘라내고 낸다

## 채널 세 종류 (ORB)
| 종류 | 원호님 채널 | 역할 |
|---|---|---|
| 내 채널 | 이메일 목록, kingkle.co.kr, 전자책 랜딩, 카톡 채널·오픈채팅 | 알고리즘 영향 없이 직접 닿는다. 모든 노출을 결국 여기로 모은다 |
| 빌린 플랫폼 | 쓰레드, 인스타, 네이버 블로그, 유튜브, 크몽, 텀블벅 | 속도는 주지만 규칙이 바뀐다. 1~2개에 집중 |
| 남의 독자 | 커뮤니티 게시, 인터뷰, 협업, 제휴 | 첫 인지를 빠르게. 반드시 내 채널 등록으로 이어지게 |
- 확정 결정 유지: 네이버 블로그엔 판매 링크를 넣지 않고, 인스타와 쓰레드는 서로 엮지 않는다. 각 플랫폼에서 내 채널로 직접 연결

## 단계
1. **지인 단계**: 아는 사람 몇 명에게 무료로 써보게 하고 막히는 곳 수집
2. **사전 공개**: 대기 신청 페이지 또는 맛보기 공개, 관심자 목록 모으기
3. **베타**: 목록 일부에 먼저 판매(얼리버드), 후기 수집
4. **얼리 액세스**: 화면·결과물 미리 공개, 사용 데이터와 후기로 문구 다듬기
5. **정식 출시**: 모든 채널 동시 공지, 내 채널 공지 + 플랫폼 글 + 랜딩 배너

전자책 적용 예: 맛보기 28쪽으로 관심자 목록 → 텀블벅 얼리버드(확정가 19,000/39,000/79,000) → 후기 반영 → 정가(29,000/59,000/99,000) 전환을 공지 날짜에 실제로 실행

## 마감·수량은 진짜만
- 얼리버드 종료일을 공지했으면 그날 실제로 가격을 올린다. 연장하면 다음부터 아무도 안 믿는다
- "마지막 기회"는 한 번만 쓴다
- 외주 상품은 실제 착수 가능 건수로만 제한을 건다

## 출시 당일 확인
- 결제·다운로드·문의 폼 실제 동작(사용자 손테스트 몫이면 환경만 준비)
- 각 채널 글 초안, 내 채널로 오는 링크, 공지 순서
- 후기·문의를 받을 곳과 답할 사람

## 출시 뒤
- 첫 구매자·첫 고객 반응을 문구와 FAQ에 반영
- 기능 추가·개정판·가격 변경 때마다 짧은 재공지

## 결과물 형식
- SLC 판정 한 줄씩
- 단계별 할 일·채널·문구 초안 표(날짜 견적은 쓰지 않는다. 사용자가 정한 날짜만 넣는다)
- 볼 숫자: 관심자 수, 얼리버드 판매, 정가 전환 후 판매, 후기 수

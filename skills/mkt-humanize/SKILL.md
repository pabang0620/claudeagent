# mkt-humanize: 한국어 AI티 제거

목적은 탐지기를 속이는 게 아니라 **읽는 사람이 광고·기계 글로 느끼고 넘기지 않게** 하는 것이다. "탐지 안 됨"을 약속하지 않는다. 짧은 글일수록 상투어 한 줄의 비중이 커서 더 티 난다.

## 기계적으로 고치는 것 (자동 치환 가능)
- **em-dash(U+2014) 전면 금지**: 쉼표나 하이픈(-)으로. en-dash(U+2013)도 하이픈으로. 프로젝트 전역 규칙
- 보이지 않는 문자 삭제: 폭 없는 공백(U+200B~200D), 단어 결합자(U+2060), BOM(U+FEFF), 소프트 하이픈(U+00AD), 유니코드 태그 문자, 줄바꿈 없는 공백(U+00A0)은 일반 공백으로
- 둥근 따옴표("" '')는 곧은 따옴표로, 말줄임 문자(…)는 마침표 셋으로, 글머리 기호(•)는 하이픈으로
- 상투어 치환·삭제: `references/ko-slop.md` 목록

## 사람이 판단해서 고치는 것 (자동 치환 금지, 표시 후 다시 쓰기)
- "단순히 A가 아니라 B입니다", "A가 아닙니다. B입니다", "A뿐만 아니라 B까지" → B를 이유와 함께 바로 말한다
- 셋씩 묶는 나열 습관("빠르고, 쉽고, 정확하게") → 실제로 중요한 하나나 둘
- 스스로 묻고 답하기: "결과는? 3배 빨라졌습니다", "핵심은 바로 ~입니다" → 그냥 말한다
- 부정 나열: "설치 없이, 가입 없이, 비용 없이" → 실제로 일어나는 일을 말한다
- 문장 끝 꼬리 덧붙이기: "~할 수 있습니다, 별도 작업 없이, 추가 비용 없이" → 주장에서 끊는다
- 같은 종결어미 연속: "~습니다." 문장이 4개 이상 이어지면 길이와 끝맺음을 섞는다
- 모든 문장 길이가 비슷함 → 짧은 문장과 긴 문장을 섞는다
- 구체 요소 없음: 숫자·이름·장면이 없는 문단 → 사실을 넣거나 문단을 뺀다(사실을 지어내지 않는다)
- 이모지 글머리 목록, 연속 강조(볼드 남발), 해시태그 벽
- 영상 서두: "이번 영상에서는 ~를 보여드리겠습니다" → 삭제하고 본론부터
- 반응 구걸: "좋아요와 팔로우 부탁드려요", "공감되면 저장", "친구 태그하세요"
- 깔끔한 교훈형 마무리: "결국 중요한 건 ~입니다", "~의 시대, 이제는 ~해야 할 때입니다"

## 순서
1. 기계 치환(위 첫 블록)
2. 판단 항목 표시 → 의미를 지키며 손으로 다시 쓰기
3. 다시 읽기: 소리 내어 읽어 걸리는 문장, 20단어(한국어 40자) 넘는 문장 점검
4. 동의어로 바꾸기만 하면 새 상투어가 생긴다. 사실에서 다시 쓴다
5. 두 번 고쳐도 기계 같으면 초안 자체가 공식으로 쓰인 것이다. 고치기를 반복하지 말고 새로 쓴다

## 자동 생성 파이프라인에 넣을 때
- 생성 프롬프트에 금지 목록을 넣는 것만으로는 부족하다. 생성 뒤에 코드로 검사한다(정규식 매칭, em-dash·보이지 않는 문자 제거, 같은 종결어미 연속 수 계산)
- 걸리면 치환 가능한 건 치환, 구조 문제는 재생성 또는 폐기
- 사용자 고유 표현이 목록에 걸리면 목록에서 뺀다(목록은 고쳐 쓰라고 있는 것)

## 결과물
다듬은 글 + 바뀐 곳 요약(무엇을 왜). 점수만 주지 않는다.

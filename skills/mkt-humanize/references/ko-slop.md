# 한국어 AI 상투어 목록

형식: 상투어 -> 처리. "삭제"는 빼도 뜻이 남는 경우. 사용자가 실제로 즐겨 쓰는 표현이면 이 목록에서 지운다.
정규식 게이트로 옮길 때는 왼쪽 표현의 어간만 쓴다(예: `알아보겠습니다`, `살펴보겠습니다`).

## 서두·안내
- 오늘은 ~에 대해 알아보겠습니다 -> 삭제, 본론 첫 문장으로 시작
- 이번 시간에는 / 이번 글에서는 / 이번 영상에서는 -> 삭제
- ~를 살펴보겠습니다 / 함께 살펴볼까요 -> 삭제
- 여러분, ~하신 적 있으신가요? -> 대상을 구체적으로 지목하거나 삭제
- 안녕하세요 (캡션·쓰레드 첫 줄) -> 삭제
- 많은 분들이 궁금해하시는 -> 삭제

## 과장·유행어
- 혁신적인 / 획기적인 / 압도적인 -> 실제 차이(숫자)로
- 게임 체인저 / 판도를 바꿀 -> 무엇이 어떻게 바뀌는지
- 한 단계 업그레이드 / 차원이 다른 -> 구체 개선점
- 역대급 / 미쳤다 / 충격 / 대박 (사실 근거 없을 때) -> 삭제 또는 사실로
- 놓치지 마세요 / 꼭 확인하세요 / 저장 필수 -> 삭제 또는 이유 한 줄
- 꿀팁 대방출 / 총정리 끝판왕 -> 무엇을 몇 개 정리했는지
- 새로운 시대가 열렸습니다 / ~의 시대 -> 삭제

## 번역투·공문서투
- 다양한 / 여러 가지 -> 실제 개수나 예시
- 효과적으로 / 효율적으로 -> 무엇이 얼마나
- 활용하다 -> 쓰다
- 제공하다 -> 주다, 있다
- 진행하다 (진행했습니다) -> 했다
- 중요한 역할을 합니다 / 핵심적인 역할 -> 무엇을 하는지
- ~하는 것이 중요합니다 / ~할 필요가 있습니다 -> 하라고 바로 쓰거나 이유를 쓴다
- ~라고 할 수 있습니다 / ~라고 볼 수 있습니다 -> ~입니다
- ~에 있어서 / ~에 대한 -> 조사 하나로
- 원활한 / 체계적인 / 최적의 / 강력한 / 손쉽게 / 매끄럽게 -> 사실로 대체
- 시너지 / 인사이트 / 솔루션 / 니즈 (일반 독자 대상) -> 우리말 또는 구체어

## 구조 상투
- 단순히 ~가 아니라 ~입니다 -> B만 이유와 함께
- ~뿐만 아니라 ~까지 -> 둘 중 중요한 것
- 결과는? / 비결은? / 이유는 바로 -> 바로 서술
- 핵심은 바로 ~입니다 -> 서술
- 그렇다면 ~는 어떨까요? -> 삭제
- 결론적으로 / 요약하자면 / 정리하자면 (짧은 글) -> 삭제
- 결국 중요한 건 ~입니다 -> 삭제 또는 구체 행동
- 이제는 ~해야 할 때입니다 -> 삭제

## SNS 반응 구걸
- 좋아요와 팔로우 부탁드려요 / 구독 좋아요 알림설정
- 공감되면 저장 / 도움 됐다면 공유
- 친구 태그하세요 / 필요한 사람에게 보내주세요 (근거 없이 반복될 때)
- 끝까지 보세요 / 마지막에 반전
- 댓글로 의견 남겨주세요 (구체 질문 없이)
-> 요청이 필요하면 하나만, 구체적으로(키워드 댓글, 저장 이유)

## 문장부호·기호
- em-dash(U+2014), en-dash(U+2013) -> 쉼표 또는 하이픈
- 느낌표 연속, 물음표+느낌표 -> 하나 또는 삭제
- 이모지 글머리 (체크, 불꽃, 로켓 등) -> 하이픈 또는 번호
- 볼드 남발 -> 한 문단에 하나 이하
- 해시태그 6개 이상 -> 5개 이하

# gumgumi-cinematic

2026-09-26 Opus가 코드로만 만든 8초 샘플(`/home/lee/project/claude-animation/gumgumi-intro/`)을 사용자가
"퀄리티 미쳤네"로 평가한 뒤 만든 스킬이다. 커뮤니티에서 "Claude Opus drew every frame in JavaScript"로
알려진 방식과 같다. 목표는 **Sonnet 에이전트로도 같은 퀄리티**를 내는 것이다.

## 과학 설명 설계 원칙 (2026-09-27 개정)

c01 8초판 피드백("퀄리티는 괜찮은데 너무 빨라서 설명하기엔 부적절", "설명이 적재적소에 잘 들어가야 한다")으로 설계를 바꿨다.

- **설명 사슬이 먼저, 그림은 그 다음**: 질문 -> 의외성 -> 인과 고리 3~5개 -> 답. 고리마다 설명 자막 1개와 그 고리를 이해시키는 그림을 붙인다.
- **두 템포**: 액션(A)은 빠르게, 설명(E)은 2~4초에 hold. E가 55% 이상. 권장 25~45초.
- **굼구미는 실험자·안내자**: 실제 원인(온도, 빛 등)을 조작하고 가리킨다. 물리적 원인을 대신하지 않는다.
- **내레이션이 설명을 이끈다**(2026-09-27 "TTS가 없는 건 문제"): 채널 목소리 TTS, 자막은 내레이션 문장 그대로, 굼구미 입이 맞춰 움직인다. 스토리보드 타이밍은 내레이션 구간 앵커로 적는다.
- **채널 인트로·제목카드·아웃트로를 그대로 붙인다**("기존 인트로·아웃트로는 그대로"): Remotion 브랜드 자산을 렌더해 앞뒤에 붙인다. 제목카드가 주제를 먼저 알려준다.
- **훅은 설명 없는 일상 장면부터**("처음에 갑자기 설명 들어가니까 헷갈림").
- **작성자와 검토자 분리**: 쓴 에이전트가 아닌 리뷰어가 시청자 시점으로 이해 가능 여부를 판정한다.

## 절차

### 1. 기획

`gumgumi-cinematic-planner`를 스폰한다(model: sonnet). 프롬프트에 다음을 적는다.
- 주제(있으면)
- 비율(기본 9:16)
- "보고 15줄 이내"

돌아오면 `ls`로 파일 7개가 실제로 있는지만 확인한다.

### 2. 설명 검토 (최대 2라운드)

`gumgumi-explain-reviewer`를 스폰한다(model: sonnet, 기획 폴더 경로 전달).
- `PASS`면 3단계로 간다.
- `FIX`면 같은 planner에 SendMessage로 "수정 모드, 06-review.md 지적만 고쳐라"를 보내고, 리뷰어를 새로 스폰해 다시 판정한다.
- 2라운드 뒤에도 `FIX`면 남은 지적을 사용자 승인 단계에 함께 보여준다. 3라운드 이상 돌리지 않는다.

### 3. 정지점: 스토리보드 승인

사용자에게 다음을 보여주고 승인을 받는다.
- `05-meta.md` 제목
- `02-explain.md` 설명 사슬(질문, 고리, 답)과 한국어 내레이션 전문
- `04-storyboard.md` 표 전체
- 리뷰 판정과 남은 지적

수정 요청은 같은 planner에 SendMessage로 되돌린다. 승인 전에 애니메이터를 돌리지 않는다.

### 4. 애니메이션

`gumgumi-animator`를 스폰한다. 프롬프트에 다음을 모두 적는다(서브에이전트는 대화 이력을 모른다).
- 기획 폴더 절대경로
- 비율
- 작업 폴더
- 출력 경로(위 경로 규칙의 `shorts/ko/[C<N>] <한국어 제목>.mp4` 실제 파일명)
- "보고 15줄 이내"

**모델**: 기본 `sonnet`이다. 사용자가 결과를 보고 퀄리티가 부족하다고 하면, 그 에피소드에 한해 `model: opus`로 다시 돌린다. 이 상향은 2026-09-26 사용자가 이 스킬에 대해 미리 승인했으므로 다시 묻지 않는다. 다시 돌릴 때는 기존 작업 폴더를 덮어쓰지 않도록 `c<NN>-<slug>-opus`처럼 새 작업 폴더를 준다.

### 5. 보고

사용자에게 다음을 알린다.
- 최종 파일 절대경로
- ffprobe 수치
- 애니메이터가 단순화하거나 못 한 비트

스크린샷이나 영상 캡처로 품질을 자체 판정하지 않는다(메모리 `feedback_no_visual_verification`). 애니메이터의 정지컷 점검은 제작 과정의 일부라 예외다. 영상은 사용자가 본다.
